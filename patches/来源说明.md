这两份补丁改编自 [Zcode](https://github.com/zai-org/ZCode) 快照 `c5904686e` 的
`patches/@extend-ai__react-xlsx@0.16.0.patch` 和 `patches/@aiden0z__pptx-renderer@1.2.4.patch`。
上游采用 Apache License 2.0，完整条款见本目录 `Zcode-LICENSE`；版权声明保留上游内容。
本项目只调整补丁路径和 npm patch-package 格式，分别保留外链宿主管理接口和图表提示文字转义。

`npm install` 的 postinstall 自动应用，失败终止安装；升级对应依赖必须重核接口及补丁。
构建同时携带本说明、上游许可证和渲染依赖发布包内的许可证。
