# 设计素材库

保存项目长期维护的原创设计素材、配色和可独立打开的预览。每套素材在自己的目录说明来源、规格、状态映射及生成方式。

| 素材 | 内容 | 入口 |
| --- | --- | --- |
| 文件状态徽章 | 七种文件变化状态，文字与图形两种形态，深浅两套配色 | [规格与用法](change-badges/README.md) · [交互预览](change-badges/预览.html) |

`resources/design-assets/` 不作为整个目录加入安装包。应用由消费组件明确导入所需 SVG，交给 Vite 输出本地构建资源；素材源文件与预览继续在这里维护。文件状态徽章目前仅导入深浅两套文字版。
