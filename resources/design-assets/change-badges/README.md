# 文件状态徽章

本项目原创素材，覆盖 `ChangeKind` 的七种文件变化状态。确认版采用水平底板、粗斜体字形，新增标签为 `NEW`，不带感叹号。

## 目录与规格

- `light/label/`、`dark/label/`：文字徽章，各七个 SVG。画布 48 × 28，底板 43 × 20，圆角 5。
- `light/icon/`、`dark/icon/`：图形徽章，各七个 SVG。画布 28 × 28，底板 22 × 21，圆角 6，图标使用 1.65px 圆头线条。
- [配色与语义.json](配色与语义.json)：中文名称、文字标签及深浅配色。颜色数组依次为底色、描边、前景色。
- [预览.html](预览.html)：自包含交互预览，可直接用浏览器打开，切换文字、图形和深浅配色。

文字使用 `Arial, Helvetica, sans-serif`，字号 10.5、字重 800、斜体；SVG 保留可编辑文字，不随素材附带字体文件。画布留白用于对齐，缩放时保持宽高比。

## 状态映射

| 文件名 / ChangeKind | 文字 | 中文语义 | 色系 | 图形 |
| --- | --- | --- | --- | --- |
| `added` | NEW | 新增 | 绿色 | 加号与星芒 |
| `modified` | EDIT | 修改 | 蓝色 | 铅笔 |
| `deleted` | DEL | 删除 | 珊瑚红 | 减号 |
| `renamed` | REN | 重命名，包含路径变化 | 紫色 | 转向箭头 |
| `type-changed` | TYPE | 文件类型变化 | 暖砂色 | 方形与圆形 |
| `mode-changed` | MODE | 权限变化 | 灰蓝色 | 锁 |
| `eol-or-encoding` | TEXT | 换行或编码变化 | 灰紫色 | 代码符号 |

## 使用与维护

本轮改动列表通过 `ChangeKindBadge` 消费文字版 SVG，按应用主题切换深浅素材，并保留完整中文 Tooltip 和无障碍名称。组件使用 44 × 20 的占位及 48 × 28 的居中背景，裁掉画布透明留白，底板保持原尺寸 43 × 20，不撑高文件行。图形版保留在素材库供紧凑场景复用。

在仓库根运行 `node scripts/generate-change-badges.mjs`，会重新生成 28 个 SVG、配色元数据和预览。唯一生成源为 [generate-change-badges.mjs](../../../scripts/generate-change-badges.mjs)，修改造型、文字或配色时先修改它，再重新生成；不要手改生成文件。README 独立维护。

这套徽章由本项目设计会话制作，未引入第三方徽章素材。仓库保留可直接使用的 SVG 与生成源，不另存重复 ZIP 或聊天临时路径。
