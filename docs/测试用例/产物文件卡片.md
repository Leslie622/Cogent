# ② 产物文件卡片验收

功能事实见[模块](../模块/产物文件卡片.md)。本册只验②，①保留原验收结论；整体布局整改另排，③尚未开工。
每条记录“通过/失败/未测”，失败附模型实际工具调用和现象；模型没申报不等于卡片渲染故障。

## 准备与固定样本

请从本工作树启动用户自己的开发窗口，桌面主仓运行的窗口不会自动包含本分支代码：

```powershell
Set-Location 'C:\Users\u\.codex\worktrees\body-file-links\Cogent'
npm run dev
```

另开 PowerShell 创建独立测试目录；记下输出的“项目目录”，在 Cogent 中选它新建聊天：

```powershell
$outputCaseRoot = Join-Path $env:TEMP ('Cogent产物验收-' + [guid]::NewGuid().ToString('N'))
$outputCaseProject = Join-Path $outputCaseRoot '项目'
$outputCaseOut = Join-Path $outputCaseProject 'out'
New-Item -ItemType Directory -Path $outputCaseOut -Force | Out-Null
[IO.File]::WriteAllText((Join-Path $outputCaseProject '参考.txt'), '仅供读取的参考资料')
[IO.File]::WriteAllText((Join-Path $outputCaseProject '源码.ts'), 'export const value = 1')
[IO.File]::WriteAllText((Join-Path $outputCaseOut '报告 A #%.txt'), "申报版本A`r`n第二行", [Text.UTF8Encoding]::new($true))
[IO.File]::WriteAllText((Join-Path $outputCaseOut '数据.csv'), "姓名,数值`r`n甲,10")
[IO.File]::WriteAllText((Join-Path $outputCaseOut '说明.md'), "# 说明`n`n![图片](图片.png)`n`n[未随附](未随附.txt)")
[IO.File]::WriteAllText((Join-Path $outputCaseOut '未随附.txt'), '该文件存在，但不申报')
[IO.File]::WriteAllBytes((Join-Path $outputCaseOut '图片.png'), [Convert]::FromBase64String('iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAQAAAC1HAwCAAAAC0lEQVR42mP8/x8AAwMCAO+aZ/0AAAAASUVORK5CYII='))
Compress-Archive -LiteralPath (Join-Path $outputCaseProject '参考.txt') -DestinationPath (Join-Path $outputCaseOut '已有.zip')
[IO.File]::WriteAllText((Join-Path $outputCaseRoot '根外.txt'), '允许读取并明确交付的根外文件')
Write-Host "项目目录：$outputCaseProject"
Write-Host "根外文件：$(Join-Path $outputCaseRoot '根外.txt')"
```

除专门测试“同轮替换”的用例外，每条建议新建聊天，避免旧轮卡片影响观察。
`report_outputs` 是模型工具，不是在输入框执行的斜杠命令；提示词明确要求模型调用。

## 1. 不申报就没有正式卡

提示词：`读取参考.txt并总结一句话；只用正文链接引用，不调用report_outputs，不交付独立文件。`

预期：能看到正文/工具文件链接，没有“交付文件”卡片。再用新聊天请求“仅修改源码.ts中的value为2，不交付独立文件”，同样没有卡。
纯聊天也不应凭空出卡。这条检验“写过文件”和“交付文件”没有混为一谈。

## 2. 最基本交付与卡片操作

提示词：`在out/新报告.txt写三行测试结论，使用report_outputs把它作为本轮唯一交付文件，说明写“测试报告”，再结束。`

步骤：观察模型工具成功；等本轮完成；点击“预览交付副本”。
预期：终答下、用量上出现一张卡，文件名/类型/大小/说明正确；预览显示三行内容并标“交付副本”。
“另存为”选择新的目录，检查内容相同；取消另存不报错。更多菜单能复制原路径、定位、系统打开、编辑当前原文件。

## 3. 交付既有文件与未知预览类型

提示词：`不要修改out/已有.zip，直接使用report_outputs交付这个已有文件，说明“现成压缩包”。`

预期：未修改的ZIP仍有卡；点预览可明确提示此类型无内嵌查看器，另存/系统打开仍可用。
没有内嵌预览不能导致整张卡消失。可另选本机已有PDF/Word/表格/幻灯片/媒体文件重复本条，不把未测格式写为通过。

## 4. 多文件与展开

提示词：`在一次report_outputs中交付out/报告 A #%.txt、out/数据.csv、out/说明.md、out/图片.png，各给一句说明。`

预期：首屏3项，显示总数4；展开能看到第4项，收起保留完整清单。中文、空格、#和%是字面文件名，不能被拆成位置或重复解码。
每项独立预览，不误开同名文件或另一张卡。

## 5. 同一轮完整替换与失败保留

提示词：`严格在同一轮依次调用：先report_outputs申报["out/报告 A #%.txt","out/数据.csv"]；再申报["out/数据.csv","out/已有.zip"]；最后故意申报["out/不存在.txt"]。最后一次失败后不要修复或重新申报，直接结束。`

预期：最终只有数据.csv、已有.zip，原报告卡不在；失败候选不出卡，失败不能抹掉上一份有效清单。
观察过程工具卡应能确认三次独立调用；只看模型口头说“替换了”不能算通过。

## 6. 明确空清单撤回

提示词：`同一轮先用report_outputs申报out/数据.csv；再用report_outputs({"deliverables":[]})明确清空；不要再申报，终答仍可提到数据.csv。`

预期：本轮没有产物卡，刷新/重启也不补卡。正文若已有read/write词表仍可链接，那是①的正常行为。
下一条用户消息是新回合；它的空清单不应删掉上一轮的历史卡。

## 7. 申报后又改写，交付收尾版本

提示词：`同一轮在out/版本.txt写“版本A”，用report_outputs申报；然后把它改成“版本B”，不再次申报，最后结束。`

预期：正式卡预览“版本B”，另存也是B；不能拿首次申报副本A冒充最终版。

## 8. 删除原件仍能看交付版本，当前原件动作独立

先执行用例2或7，确认卡片存在。关闭预览，用文件管理器删除对应原件，再点卡片。

预期：交付预览和另存仍成功；“预览当前原文件/编辑当前原文件/在原目录定位”应报原件缺失，不偷偷使用副本冒充原件。
退出并重开本工作树的Cogent，再打开该聊天：卡片和保存内容仍在。

## 9. 当前原件与交付副本分开

交付out/版本.txt后，手动将原件改成“版本C”。

预期：卡片默认仍显示交付B；更多菜单“预览当前原文件”显示C；正文里的普通文件链接也打开C。
系统打开交付副本后尝试在外部编辑器保存修改，再点卡片，仍是B。此条真实外部编辑器行为需手测，自动脚本只模拟系统入口。

## 10. 申报后源文件在收尾前被删除

提示词：`写out/中途删除.txt，内容“确认版本A”；申报它；再删除原件，不清空、不重新申报，结束。`

预期：保留已确认A，卡片明确提示“最终版未确认/保留最近确认版本”及原因。不能静默消失，也不能声称最终原件仍可用。

## 11. ask_user等待、停止与无终答

提示词：`申报out/数据.csv后调用ask_user问我是否继续，然后等待回答。`

步骤：在提问面板保持等待，观察正式卡；再点击停止。
预期：等待期间不新挂正式卡；停止结束后显示已确认文件，注明“回合已停止”。即使没有最终正文也能看到卡，不永久busy。
允许提前查看时，模型应提供①正文链接，不靠提前挂正式卡。

## 12. Markdown依赖隔离

提示词：`只申报out/说明.md与out/图片.png，不要申报out/未随附.txt。`

完成后删除源图片，再预览说明.md。
预期：图片来自同清单交付副本，仍显示；点击“未随附”提示依赖未保存，不能自动读取当前原件混入交付预览。
可从卡片独立“预览当前原文件”检查当前Markdown来源。HTML/脚本始终以源码显示。

## 13. 归属、根外与删除聊天

在两个不同测试目录放同名out/报告.txt，分别写A与B；各自聊天申报后切换/刷新，预览分别对应A/B。
用样本脚本输出的绝对根外路径明确申报：可访问普通文件允许交付，目录应失败并提示先打包。
删除其中一个测试聊天：对应卡和受管数据释放，另一聊天和两个原件不受影响；归档/恢复则保留卡。

## 14. 大文件降级（可选，单独记结果）

```powershell
$outputLargePath = Join-Path $outputCaseOut '大文件.bin'
$outputLargeStream = [IO.File]::Open($outputLargePath, 'Create')
try { $outputLargeStream.SetLength(101 * 1024 * 1024) } finally { $outputLargeStream.Dispose() }
```

申报该文件。预期：卡仍出现，明确“仅当前原文件，未保存交付副本”；不伪称有历史字节。
磁盘真满/无权限与超过预算是两回事：前两者应报告真实失败。不要在工作盘造满盘场景；自动故障注入只验证错误分支。
