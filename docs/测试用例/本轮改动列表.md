## 自动回归命令

- 服务单测：`npx vitest run tests/host/runtime/changes.test.ts`
- 组件回归：`npx vitest run tests/renderer/features/home/turn-changes.render.test.tsx`
- 权限边界：`npx vitest run tests/shared/method-access.test.ts`
- 真构建集成（含 `change-diff-worker`）：`npx vitest run tests/integration/changes.test.ts`
