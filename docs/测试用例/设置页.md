# 设置页

## 统一字号

用户自行启动应用，在「设置 → 外观」测试：

1. 界面依次选11、14、16px，侧栏、说明、普通按钮、标题按阶变化；模型/项目菜单、
   右键菜单与弹窗保持可读，正文和输入草稿字号不随界面变化。关闭后重开仍为所选值。
2. 主窗口缩到400px，检查设置行窄布局、长中文标签和下拉选项不横向挤出；打开控制台，
   在最小760px宽度下检查侧栏、时间线、详情与长标题。
3. 代码依次选8、14、24px，聊天代码块、工具输出、控制台JSON及原文共同响应；行号、
   自动换行、搜索与折叠正常。选「跟随主题」恢复主题代码值；未指定时聊天代码采用
   正文的0.875倍（内置默认为14px），控制台和工具输出回14px。
4. 保持主窗口和控制台同时打开，在主窗口调字号，控制台即时同步；关闭控制台重开检查
   首帧正确。开发服务与打包 file 页面都要做，不能用同源iframe结果代替。
5. 亮暗两面重复端点，确认控件不裁字、文字未被截成半行，图标和页面间距没有整体缩放。

真实浏览器样本：`tests/renderer/features/settings/typography.browser.html`；使用
`tests/browser-harness.config.ts` 独立服务，不启动 Electron。样本自动覆盖36组
界面11/14/16 × 代码8/14/24 × 宽度400/1100 × 亮暗组合。

自动回归：`tests/renderer/lib/appearance-dom.test.ts`、`tests/shared/typography.test.ts`。
新增页面绕过字号阶时 `npm run lint` 应报文件和行号；标准类、颜色类与集中消费点可通过。

## 字体与强调色

1. 分别打开内容、代码字体弹窗，首焦点落英文页签；搜索框占满内容宽度。分别选择
   中英文字体，预览更新但正文暂不变；保存后生效，取消、关闭与 Escape 均丢弃草稿。
2. 导入带亮暗字体的主题，两槽默认标签显示该套实际族名；只改中文时保留主题英文，
   恢复其中一槽默认不清另一槽。关闭重开应用后仍保留已保存选择。
3. 系统字体读取失败时，预设与当前选择仍可使用，重新打开可重试；控制台与内嵌页面
   不应得到本地字体枚举授权。
4. 打开强调色浮层不改偏好；色板、拖动、HEX、RGBA 均即时保存，非法输入失焦回有效值。
   Alpha 改为50%后换色仍保留透明度；模式文字保持不透明，分栏光带与色块体现透明度。
   恢复默认回品牌色，亮暗切换与重启留存符合[设置页模块](../模块/设置页.md)。
5. 键盘 Tab 遍历普通输入、下拉、按钮和控制台搜索，亮暗两面都有统一焦点落点；
   组合件只在外层画线。聊天输入卡自身保持常态，内部工具按钮仍有焦点提示。

自动交互回归：`appearance.render.test.tsx`、`font-picker.render.test.tsx`，位于
`tests/renderer/features/settings/`；真实字体观感与打包窗口授权须在应用内验收。

## 归档（回收站）

1. 归档若干聊天（覆盖无项目 / 有项目 / 项目已删三类），打开「设置 → 已归档的
   聊天」：列表按项目分组两级，组行显示项目名与「N 个聊天」计数；无项目归入
   「未归类」，项目已删的归入「已移除项目」；组默认收起，点组头展开出聊天行
   （标题 + 时间 + 取消归档 / 删除钮），开合为 200ms 高度与透明度过渡，连续
   反向开合自然衔接，收起内容不占布局且不可 Tab 聚焦；系统减少动画时即时切换。
2. 组行「…」菜单：全部取消归档（免确认，整组回主列表）与全部永久删除（弹确认，
   文案带数量）；顶栏「全部永久删除」删当前筛选 + 搜索后的可见集，有筛选或搜索
   时文案变「永久删除筛选结果」；删除确认可取消，删除失败时弹窗留现场。
3. 排序方式切「更新时间 / 创建时间」：组内行序与行内时间跟随切换；项目筛选下拉
   列出所有项目（含 0 条归档的）+ 未归类 + 已移除项目（仅存在时），「所有项目」
   视图含未归类与已移除项目组。
4. 搜索标题过滤组内行并隐藏空组；无匹配显示「没有匹配的归档聊天」，归档集为空
   显示「没有已归档的聊天」。

自动回归：`tests/renderer/features/settings/archive-view.test.ts`（分组身份 /
筛选作用域 / 双档排序 / 筛选选项身份稳定）。
