# 设置页

## 对话显示

在「设置 → 常规 → 对话」测试：

1. 无旧偏好时为「详细」与「2 位小数」；输出详细程度只有「简洁 / 详细」两项，耗时
   精度可选整数 / 1 位 / 2 位，关闭重开应用后保留选择。
2. 在包含读取、命令输出、edit diff、失败、拒绝与 MCP 的对话中切「简洁」：
   仅见工具名称与执行状态，参数、diff 计数与内容、输出、失败原因浮层及展开入口
   均消失；运行中也无输出尾行。思考只保留状态与耗时，摘要、全文及展开入口均消失；
   底部 token、缓存、成本与模型 / 工具耗时整行隐藏。切回详细可查看原详情与统计。
3. 在详细模式检查工作中码表、已工作头条、思考尾标与模型 / 工具统计：秒位按所选精度显示，
   分钟自动用分秒、小时自动用小时分；切精度不重置工作起点。检查分钟进位不出现
   60s，小时档不出现秒，也不随精度变化。

自动回归：`tests/renderer/features/settings/general.render.test.tsx`、
`tests/renderer/components/ui/tool.render.test.tsx`、
`tests/renderer/lib/format-duration.test.ts`。

## 界面主题色

在「设置 → 外观 → 界面样式」测试：

1. 深色浅色下方显示六张主题色卡：森林、薄荷、蜜蜂、羊皮纸、海盐、暮紫；默认薄荷。
   点击任意卡，选中描边和圆点同步变化，头部、窄图标栏与内容侧栏即时更新。
2. 浅色、深色分别切六套；暗色保留各套色相，缩略图与实际头部、侧栏对应。切明暗
   不重置主题色，正文底色、Markdown 主题和自定义强调色不随主题色改变。
3. 选择跟随系统并切操作系统明暗，主题色随环境换套，卡片选择保留。关闭重开应用仍
   为所选主题色；无旧字段时为薄荷。保持同源窗口打开，另一个窗口换肤后应同步投影。
4. Tab 可进入单选组，方向键切换主题色；缩至400px和把界面字号调到16px，卡片与
   名称完整、不横向溢出，焦点仍可见。

自动回归：`tests/renderer/features/settings/appearance.render.test.tsx`、
`tests/renderer/lib/appearance-dom.test.ts`；真实 Electron 计算样式矩阵运行
`node scripts/check-interface-skins-browser.mjs`，可用环境变量
`COGENT_SKIN_SCREENSHOTS` 指定截图输出目录。

## 统一字号

用户自行启动应用，在「设置 → 外观」测试：

1. 界面依次选11、14、16px，侧栏、说明、普通按钮、标题按阶变化；模型/项目菜单、
   右键菜单与弹窗保持可读，正文和输入草稿字号不随界面变化。关闭后重开仍为所选值。
2. 主窗口缩到400px，检查设置行窄布局、长中文标签和下拉选项不横向挤出；打开控制台，
   在最小760px宽度下检查侧栏、时间线、详情与长标题。
3. 代码依次选8、14、24px，聊天代码块、工具输出、控制台JSON及原文共同响应；行号、
   自动换行、搜索与折叠正常。选「跟随主题」恢复主题代码值；未指定时聊天代码采用
   正文的0.875倍（内置默认为14px），控制台和工具输出回14px。
4. 保持主窗口和控制台同时打开，在主窗口调字号，控制台即时同步；关闭控制台重开检查
   首帧正确。开发服务与打包 file 页面都要做，不能用同源iframe结果代替。
5. 亮暗两面重复端点，确认控件不裁字、文字未被截成半行，图标和页面间距没有整体缩放。

真实浏览器样本：`tests/renderer/features/settings/typography.browser.html`；使用
`tests/browser-harness.config.ts` 独立服务，不启动 Electron。样本自动覆盖36组
界面11/14/16 × 代码8/14/24 × 宽度400/1100 × 亮暗组合。

自动回归：`tests/renderer/lib/appearance-dom.test.ts`、`tests/shared/typography.test.ts`。
新增页面绕过字号阶时 `npm run lint` 应报文件和行号；标准类、颜色类与集中消费点可通过。

## 字体与强调色

1. 分别打开内容、代码字体弹窗，首焦点落英文页签；搜索框占满内容宽度。分别选择
   中英文字体，预览更新但正文暂不变；保存后生效，取消、关闭与 Escape 均丢弃草稿。
2. 导入带亮暗字体的主题，两槽默认标签显示该套实际族名；只改中文时保留主题英文，
   恢复其中一槽默认不清另一槽。关闭重开应用后仍保留已保存选择。
3. 系统字体读取失败时，预设与当前选择仍可使用，重新打开可重试；控制台与内嵌页面
   不应得到本地字体枚举授权。
4. 打开强调色浮层不改偏好；色板、拖动、HEX、RGBA 均即时保存，非法输入失焦回有效值。
   Alpha 改为50%后换色仍保留透明度；模式文字保持不透明，分栏光带与色块体现透明度。
   恢复默认回品牌色，亮暗切换与重启留存符合[设置页模块](../模块/设置页.md)。
5. 键盘 Tab 遍历普通输入、下拉、按钮和控制台搜索，亮暗两面都有统一焦点落点；
   组合件只在外层画线。聊天输入卡自身保持常态，内部工具按钮仍有焦点提示。
6. 颜色选择器的16个预设色下面有「主题色」分区，森林、薄荷、蜜蜂、羊皮纸、
   海盐、暮紫排成三列两行；浅深两面均与对应界面主题色的点缀色一致。透明度设为50%
   后依次点六色，HEX和RGB同步更新，Alpha保持50%；关闭重开后保留选择与透明度。
   在面板打开时切明暗，候选换套，已选强调色保持原值；再点候选才应用该套新色。

自动交互回归：`appearance.render.test.tsx`、`font-picker.render.test.tsx`，位于
`tests/renderer/features/settings/`；真实字体观感与打包窗口授权须在应用内验收。

## 归档（回收站）

1. 归档若干聊天（覆盖无项目 / 有项目 / 项目已删三类），打开「设置 → 已归档的
   聊天」：列表按项目分组两级，组行显示项目名与「N 个聊天」计数；无项目归入
   「未归类」，项目已删的归入「已移除项目」；组默认收起，点组头展开出聊天行
   （标题 + 时间 + 取消归档 / 删除钮），开合为 200ms 高度与透明度过渡，连续
   反向开合自然衔接，收起内容不占布局且不可 Tab 聚焦；系统减少动画时即时切换。
2. 组行「…」菜单：全部取消归档（免确认，整组回主列表）与全部永久删除（弹确认，
   文案带数量）；顶栏「全部永久删除」删当前筛选 + 搜索后的可见集，有筛选或搜索
   时文案变「永久删除筛选结果」；删除确认可取消，删除失败时弹窗留现场。
3. 排序方式切「更新时间 / 创建时间」：组内行序与行内时间跟随切换；项目筛选下拉
   列出所有项目（含 0 条归档的）+ 未归类 + 已移除项目（仅存在时），「所有项目」
   视图含未归类与已移除项目组。
4. 搜索标题过滤组内行并隐藏空组；无匹配显示「没有匹配的归档聊天」，归档集为空
   显示「没有已归档的聊天」。

自动回归：`tests/renderer/features/settings/archive-view.test.ts`（分组身份 /
筛选作用域 / 双档排序 / 筛选选项身份稳定）。

## 存储

1. 打开「设置 → 存储」：首访短暂「正在统计占用…」后出总量（行右端刷新钮）、
   分段条与图例（会话转录 / 附件 / 观测日志 / 引擎数据 / 配置与其他；0 字节类
   不进图例，全空根只出总量「0 字节」不画条）；「占用明细」默认收起，展开为
   两档行：会话转录 + 其他（附件/观测日志/引擎数据/杂项的聚合值），0 字节档
   不出现；开合为 200ms 高度与透明度过渡，连续反向开合自然衔接，收起内容
   不占布局。
2. 切走再切回不闪加载卡（快照缓存先渲染）；刷新钮重扫（扫期禁用），
   在 ~/.cogent 下增删文件后刷新，总量与明细跟随变化。
3. 「应用数据文件夹」行显示存储根绝对路径（可选中复制、长路径换行不溢出），
   「浏览」用资源管理器打开该目录；设 COGENT_HOME 指向别的目录时路径与
   统计跟随。

自动回归：`tests/renderer/features/settings/storage-view.test.ts`（字节格式化 /
归类表 / 图例聚合 / 明细两档聚合）。
