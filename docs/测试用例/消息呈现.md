# 消息呈现手动验收

机制见 [消息呈现](../模块/消息呈现.md)，原理见 [流式呈现动效](../技术笔记/流式呈现动效.md)。
本册是可重复步骤；jsdom接线与节点断言不能替代布局、像素、动效或真窗口性能结论。

## 环境与触发

由用户启动实际Electron31；使用生产构建核对不同主题、100%/125%/150%缩放、
纯文字与代码/表格/思考/工具混合长回复。记录模型、缩放、主题、窗口尺寸和视口起点。
可用提示：`先解释一段较长文字，再读取一个工作区文件，再输出代码块和表格总结`。
性能测量和暂缓项统一见 [动效与渲染性能收尾](../计划/动效与渲染性能收尾.md)。

## 跟随、阅读与工作行

正文与输入框对齐：聊天面板分别取 1100、896、761、760、641、640、480、340、280、240px 宽，核对正文列
与输入卡的中心线，输入卡宽态左右各超出正文 20px、窄态对称收敛，边距连续变化；长内容出现滚动条后仍保持此关系。保持窗口宽度不变，拖动
会话侧栏或标签页分栏跨过 760px：大于 760px 显示，760px 及以下索引外壳在 200ms 内由 24px 收至 0，正文不为
索引额外偏移；收拢后 Tab 不进入刻度，放宽后反向展开且点击可定位。快速反向拖动
不得闪回旧宽度；系统 reduced-motion 开启时直接切换。

窄面板裁切：使用真实 MessageScroller + MessageRow，分别放入长中文提问、短提问、
多段正文、长链接及代码/表格，缩窄后再放宽并滚动。正文与输入卡的两侧留白随宽度变化；
双侧滚动条槽之外仍有留白，用户气泡右侧圆角、复制/编辑按钮与
正文末字完整可见。主窗口拖小到 400×600px 后不能继续缩小；需重启主进程验证新限制。
可在用户已启动的开发服务中打开 `tests/renderer/features/home/chat-layout.browser.html`
（Vite `/@fs/` 路径）运行真实 HomeChat 几何回归；该页使用开启计划的会话、长模型名
与上下文用量，检查重复缩放、滚动槽净留白、长短气泡和正文右缘，以及工具行
各按钮是否越界、权限/模型文字与上下文圆环是否按面板宽度切换，不计入 Vitest 的 jsdom 测试数量。
窄态逐一点击权限、厂商图标、上下文圆环：仍能选档、选模型、打开详情；详情不展示压缩说明/按钮，发送/停止保持可达。
`tests/renderer/features/home/shell-layout.browser.html` 以隔离 iframe 验证完整 AppShell：
宽窗打开两侧后，缩到 1100px 右栏收起、760px 左栏收起、400px 只剩对话；放宽后
恢复原布局；手动关闭的栏不被放宽窗口误打开。400px 头部菜单、窗口控制、输入工具
均不横向溢出，草稿和会话节点不因自动折叠卸载。圆角分别核对主体 radius-xl、
InputGroup 原生圆角和发送/停止 icon-sm 原生圆角。
索引预览：宽面板悬停已完成回合，看问题和三行以内回答；生成中、工具间封段、
停止/失败回合只显示问题；完成后同一浮窗出现摘要。链接/强调不露 Markdown 标记，
移向卡片不闪退，点击仍定位，刻度颜色不抢正文。

| 场景 | 操作与预期 |
| --- | --- |
| 回底/发送 | 长回复超过一屏，索引定位早期消息后回底或发送新提问；恢复跟随 |
| 阅读权 | 上滚、触摸、滚动键、拖动滚动条离底；后续输出、resize、终态收起均不抢回 |
| 近底微滚 | 距底约0.5/1/2px时一次上滚，再让同帧追加内容/收起/resize；仍保持阅读 |
| 主动回底 | 用户向下实际滚到底、显式回底、发送恢复；布局或程序定位不能冒充用户输入 |
| 已近底下行 | 阅读态已近底时明确下行wheel/键/上滑触摸可恢复；未知方向滚动条按下不恢复 |
| 平滑定位中断 | 索引平滑滚动途中上滚；程序目标立即交权，原生阅读手势继续 |
| 单份工作行 | 短内容工作行随正文，溢出跟随时贴视口下缘；上翻后随正文滚走，始终只有一份 |
| 几何变化 | 改窗口/字体/主题、内容缩回一屏，工作行无副本、无错位或残留占位 |
| 清理 | 停止/完成/失败撤掉工作行；切会话、卸载后无旧observer/timer继续影响新会话 |

工作行分别观察三叶图标、标题扫光和码表，不把动画自身变化计作位移。
采连续帧时保持不同视口起点与小数布局；可暂停装饰动效作对照，记录证据范围。
几何读数归零不代表像素稳定，某个场景通过不代表全部主题/缩放通过。

## 终态、压缩与隔离

| 场景 | 操作与预期 |
| --- | --- |
| 正文后停止 | 实际停止事件后显示已停止，半截正文/thinking/工具保留且仅一份，无运行错误条 |
| 空输出停止 | 首片前停止后再发你好，旧空回合仍显示已停止；新回合正常完成 |
| 详情开合 | done/stopped/failed默认收起，半截终答在外；手动展开/收起不被重渲染反转 |
| 尾字屏障 | 尾字仍在30ms批队列时停止/失败/重载，不能丢尾或30ms后复活占位，usage不重复 |
| 真实失败 | 点过停止但引擎明确报error仍显示出错了/错误条；先完成就保持完成 |
| 旧回合 | 下一次提问完成后，旧停止/失败头不改成已工作；同文提问也按user身份区分 |
| 会话隔离 | A停止或后台流式时切B，B状态不受影响；切回A结果正确，text/thinking不串 |
| 操作错误 | abort IPC拒绝仅撤当次stopping、显操作错误；手动compact失败不改成功回合结果 |
| 旧响应 | 延迟旧submit/abort/compact回包到下一run、切会话、删桶后；不清新草稿、不改新结果、不重建桶 |
| 自动压缩 | 工具轮间bar仍归原回合，原工作行不消失；随后停止不临时改归属 |
| 手动压缩 | idle的bar独立可见；重拉历史保留旧内容与压缩条 |
| 热路径 | 审批tag随审批变化；无用量正文不触发多余usage聚合，正文流不反复刷新审批列表 |

重启后历史停止/失败标签尚无磁盘恢复保证；运行中消息切走再回来可能重播首帧渐显。
分别记录这些既有边界，不能将已加载会话的正确结果扩大为历史恢复通过。

## 准备期与续写（可控链路）

1. 分别卡住装配、切模型、input/auth、before_agent_start后停止；显示正在停止并保留
   运行锁。释放Promise后只发一次aborted终态、无新增模型请求，下一次能正常提交。
2. 准备期停止后，原提问在消息区、live context、JSONL/重开历史中各恰一份；
   装配真实失败仍报初始化错误，不把未保存的输入写成保存成功；handled输入不永久running。
3. 卡住continue首await，再submit/continue/compact须忙拒；取消保留旧截断前缀。
   继续输出新尾后停止，前缀/新文/压缩条都在，旧usage不重计；无效续写释放预约。
4. manual compact装配或内部取消窗口停止，不发摘要请求、不伪造run终态。
   不合作Promise释放前仍等待收敛；晚返回对象在删除/退出后dispose，不重挂会话。
5. A/B同时准备只停止目标；在input钩子内删除后再释放，既有与未落盘会话都不发新请求/复活JSONL。
6. 核对真实provider遵守signal的范围；一个可控端点的取消结论不能外推到全部provider。

自动回归覆盖可控边界；实际Electron另核对正在停止、草稿、工作行和后续输入可用。

## 正文渐显与结构稳定

| 场景 | 操作与预期 |
| --- | --- |
| 短批文字 | 中文逐字/拉丁逐词淡入，尾部细粒度渐隐，全文可复制 |
| 大批正文 | 单次大批首帧完整占位，按短语组出现；不生成数千同步动画，也不整批突然settled |
| 同文段落 | 先后或同批追加两个“相同”段落，各自排期；第一段不重播 |
| 细粗边界 | 601字后追加甲乙，旧32组保留，新字各有新节点；短批跨96单元不重组旧字 |
| 多文本片段 | 普通601字+粗体601字或双段同时追加，每片独立压组，同批最晚250ms起跳 |
| 语法补全 | 未闭合强调/code/setext/列表/围栏、后补链接定义/脚注：全文结构等同原生解析，旧文不重播 |
| 代码/表格 | 追加行淡入、旧行/高亮不闪；行内/单元格内部增长直出，列宽/换行/横滚正确 |
| 封段连续 | 长文已出后选中正文，再启动快工具；选区不丢、代码不闪灰，新段排期不早于前段尾拍结束 |
| 静态与替换 | 历史消息零渐显；权威非前缀改写立即完整可读；第二条同文实时消息仍正常动画 |
| 自然收尾 | 尾字/纯代码尾行尚在淡入时结束：头条/输入区立即终态，工作行消失，已有淡入自然播完 |
| 收尾回收 | 真实opacity/marker-color过渡完成或取消后回收reveal；无关扫光不延迟收口，无Promise错误 |
| 降级与竞态 | reduced-motion/隐藏/无动画立即static；收尾中开新流/替换/切会话，旧等待不改变新树 |

常规封段和终态保留节点；权威快照段数与live不齐等边角仍可能换DOM，不能宣称所有路径逐像素连续。
需要复核自动化时使用 `npm test -- --project web tests/renderer/`；它验证节点/接线，
不提供FPS或真实透明度过渡结论。本册不依赖一次性tmp预览服务。
