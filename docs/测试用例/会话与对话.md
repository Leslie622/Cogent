# 会话与对话验收

机制真源见[会话与对话](../模块/会话与对话.md)。本册集中会话标题验收，其他会话行为
的既有自动回归见该模块的验收句。

## 自动标题

用户自行启动应用；自动化验证不依赖 renderer，使用临时存储根与本地模拟模型端点。

1. 设置 → 常规 → 对话，确认自动生成会话名称默认开启、标题模型默认跟随对话模型。
   新聊天发送“你好”：侧栏立即出现原文临时标题，随后变成相关简短标题；不要求固定措辞。
2. 首回复还在生成时允许名称先更新；标题完成前手动停止，或右键重命名为同名/“新会话”，
   迟到标题不覆盖。继续发消息、续写、压缩、重开聊天和重启均不重复命名。
3. A/B 同时发送不同主题，名称各自对应；生成中置顶、归档、切权限，完成后这些状态与
   活动时间保持，归档项不回活跃列表。删除会话与退出后不接受旧结果。
4. 只有附件或目录时用显示名称概括，不声称读过内容。切换独立标题模型，再创建新聊天，
   主对话模型不变；同名模型按供应商区分。关闭开关后新聊天只显示原文临时标题。
5. 断网、标题模型不可用或标题输出失败：保留临时标题，主对话按自己的结果收尾；控制台
   接口层可查看标题的启动、结果/失败/取消、所属 Run、请求标识和独立用量。
6. 设置读取/保存失败显示原因并可重试，已保存设置不假改；重启后开关和标题模型保留。
   已删除的标题模型显示不可用，可重新选跟随或其他模型。400px 宽下行控件不溢出。

自动回归：`tests/host/runtime/session-{auto-title,title-config,title-generator}.test.ts`、
`tests/host/runtime/inspector.test.ts`、`tests/integration/session-auto-title.test.ts`、
`tests/renderer/features/settings/session-title.render.test.tsx`。
覆盖一次性资格、无界面 Host、三种自定义 API 方言、模型双键、取消/迟到、并发摘要、
磁盘失败、错误式模型返回、超时和设置控件。模拟端点可验证协议与隔离，不能代表真实
模型措辞、费用或共享限流下的主回复首字延迟。

自动验证结果：lint、typecheck、生产构建通过；完整 `npm test` 为 120 个文件通过，
1,030 项通过、1 项跳过。首次全量暴露的主请求脚本与辅助标题请求冲突已修正：通用
场景夹具显式关闭标题，标题专册独立验证默认开启与并发行为；常规页测试等待实际
控件与浮层就绪，不依赖同步渲染时机。

待补证据：真实供应商标题质量、费用/延迟及 Electron 窗口操作与窄屏视觉手测。
