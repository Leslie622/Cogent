# 会话与对话验收

机制真源见[会话与对话](../模块/会话与对话.md)。本册集中会话标题验收，其他会话行为
的既有自动回归见该模块的验收句。

## 自动标题

用户自行启动应用；自动化验证不依赖 renderer，使用临时存储根与本地模拟模型端点。

1. 设置 → 常规 → 对话，确认自动生成会话名称默认开启，且只有开关、没有标题模型选择。
   新聊天发送“你好”：侧栏立即出现原文临时标题，随后变成相关简短标题；不要求固定措辞。
2. 首回复还在生成时允许名称先更新；标题完成前手动停止，或右键重命名为同名/“新会话”，
   迟到标题不覆盖。继续发消息、续写、压缩、重开聊天和重启均不重复命名。
3. A/B 同时发送不同主题，名称各自对应；生成中置顶、归档、切权限，完成后这些状态与
   活动时间保持，归档项不回活跃列表。删除会话与退出后不接受旧结果。
4. 只有附件或目录时用显示名称概括，不声称读过内容。切换对话模型后创建新聊天，标题
   请求使用首条实际模型的供应商与端点；旧独立模型配置不生效。关闭开关后新聊天只显示原文临时标题。
5. 断网或标题输出失败：保留临时标题，主对话按自己的结果收尾；控制台
   接口层可查看标题的启动、结果/失败/取消、所属 Run、请求标识和独立用量。
6. 设置读取/保存失败显示原因并可重试，已保存设置不假改；重启后开关保留。
   旧配置的独立模型不存在也不会阻止标题使用对话模型。400px 宽下行控件不溢出。
