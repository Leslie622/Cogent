## 手动步骤

1. 准备多项目、未归类与归档聊天。侧栏搜索钮/Ctrl+K 打开，空输入显示最近聊天；
   加载时 spinner 在结果区居中，结果和空态保持相同弹窗高度；“聊天”分区每个会话只有一项，
   未搜索时为单行标题及实际项目名，不显示未归类、时间或右下角范围说明。
2. 搜索标题、用户原话、助手正文、中文“你好/好”、代码路径与 `%_`；
   输入两个关键词与引号短语，确认不跨不同消息假命中。
3. 默认及自动选中的首项为次要文字/图标色，hover 时一起转主色、离开后恢复。
   输入下没有项目筛选或包含归档控件；跨项目聊天均可搜到，归档聊天不在浮层中，
   项目被移除的聊天仍能找到；彻底删除后搜索和重启都不复活。
4. 选择带命中摘要的聊天行，确认打开首条命中的原文。命中“用时”过程中的中间正文时先展开，
   摘要命中加粗、原文命中带下划线，均无高亮底色；上下命中可继续，关闭清除范围，代码和链接仍可复制/点击。
5. 不重启，搜索刚完成的直播聊天；再重启搜索，两个来源都要准确。
   同毫秒、重复句子、自动/手动续写及压缩前历史不得跳错。
6. 快速输入 A/B、输入法确认、切会话、关闭浮层、查询中删聊天；旧响应不替换新结果，
   旧历史不重建已删除桶。键盘上下/Enter/Esc、焦点恢复可用。
7. 在一次性测试目录中破坏一个转录，确认其他结果仍可见且提示不完整；
   破坏派生库，确认报错，手动重建保留旧库、不改转录。

## 验证范围与余项

Windows x64 Electron 40 的生产脚本覆盖真产品链与过程定位；隐藏窗口测试先等待
真实焦点、浮层关闭与尺寸变化，再截图，不能拿 compositor 上一帧作视觉证据。
构建、单测、协议测试与真实 GUI 各自记录，不相互冒充。

Linux x64/arm64 的 Node FTS5 和完整 GUI、不同 DPI/主题、屏幕阅读器、真实超长语料、
网络客户端并发查询、磁盘权限/容量与进程故障注入尚需对应环境补测。
合成 50,000 条数据不代表任意容量和真实用户语料保证；暖查询目标 p95 ≤200ms
须同时报告机器负载与统计范围，首建库单列，不能把纯 SQL 计数当端到端结果。
