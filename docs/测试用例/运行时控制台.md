# 运行时控制台验收

机制与采集边界见 [运行时控制台](../模块/运行时控制台.md)。真实模型与 Electron
窗口由用户启动；浏览器样本验证阅读交互，不代替真实 provider 观测验收。

## 阅读与折叠

| 操作 | 预期 |
| --- | --- |
| 打开 POST 请求体 | 记录信息收起；默认展开2层；展开信息后，记录/事件/时间戳与概览均为两列表格，长值可换行 |
| 打开 turn · stop，展开记录信息再收起 | assistant 数据随详情页统一纵向滚动，无代码区第二层纵向滚动 |
| 分别折叠记录信息、assistant 块 | 每块独立开合；原文/复制按钮不触发块折叠 |
| 查看提示词、JSON与记录表格 | 常规字号均为13px，标题只加粗；正文无横线，标题行集中操作，类别与时间在记录表内 |
| 打开数据块更多菜单 | 显示格式/字符/行数，可切换原文与自动换行；原文态禁用搜索和层级；重开折叠块仍可搜索 |
| 层级菜单选展开1/2/3层，再全部展开/折叠 | 根容器算第1层，深于所选层级的完整容器被折叠；原文不变 |
| 全部展开后滚到JSON最后一行 | 最后一行和底部分隔线可完整进入视口；不被固定代码高度裁切 |
| 搜索一个字段或正文片段 | 可导航命中位置；自动换行开关可切换横向滚动；正文只读 |
| 切换原文并复制含大整数、转义的 JSON | 与留存字符串逐字一致，不经数字精度转换；复制失败可见 |
| 打开带采集截断尾标的 JSON | 显示仅留存部分的说明；原文、查看器与复制均保留截断现场 |
| 详情栏拖到 320px / 440px / 720px | 工具条换行，无正文被外层横向裁切；代码区至少 240px 高 |

## 状态与留存

- 左下角设置菜单打开控制台 → 最小化 → 再从设置菜单打开：原窗口恢复并获得焦点，内容保留；
  普通或最大化时重复点击入口仍复用原窗口；关闭后再次点击可重新打开。
- 关闭“会话”层过滤：已完成 Run 仍显示完成，失败 Run 仍显示失败。
- 点击 Run 标题或状态文字：整条一起开合，只隐藏组内条目，不改变终态或详情。
- 首条 seq > 1：显示仅留存尾部；没有终态也未观察到实时运行：显示“未见终态”。
- 持续产生超过详情环容量的条目后，点击已淘汰详情：明确提示缺失，不显示空成功。
- 初载快照与实时事件相撞：历史和实时条目都保留，按 seq 排序且不重复。
- 对照数据来源：POST 说明明确是发送前对象，SSE 说明明确是解析后事件。
