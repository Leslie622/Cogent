# 交互座手动验收

机制见 [交互座](../模块/交互座.md)，权限见 [审批与权限](../模块/审批与权限.md)。
本册覆盖真实模型、面板、键盘、会话隔离和重启；下列均是验收预期，不是通过记录。

## 前置与触发语

由用户启动应用，准备 `<临时工作区>` 和可靠工具调用模型，另备会话B。
无特别说明时用 ask（“变更前确认”），不假定新会话一定继承全局缺省值。
权限三档与 planEnabled 是独立字段；计划批准只关闭开关，全程不改权限档。

| 场景 | 输入 |
| --- | --- |
| 清单 | `用 todo_write 建任务清单：调研、实现、测试三项，然后逐项完成并更新状态` |
| 单问 | `动手前先用 ask_user 问我：界面风格选哪种？选项：亮色 / 暗色` |
| 多问 | `用 ask_user 一次问两个问题：用哪个数据库？部署到哪个环境？各给2个选项` |
| 多选 | `用 ask_user 问要集成哪些服务：GitHub / GitLab / Bitbucket，multiSelect=true` |
| 计划 | `先调 enter_plan 只读调研，再调 submit_plan 给我方案审批，批准前不要写文件` |
| 清空 | `清空任务清单，todo_write 提交空数组` |

todo/ask/plan工具本身为read类，免工具执行审批；它们的交互挂起与权限审批是两条链。
提问/计划面板占输入区，挂起中不能用该处停止按钮；删除会话或退出应收口。
挂起状态不持久化；切换会话后挂起保留，但面板本地未提交作答可能清空。

## 清单

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| IN-01 | 新会话发清单触发语 | 右上角浮卡出现，过程有 todo_write 摘要，无审批面板 |
| IN-02/03 | 再加一项并完成首项，保留三种状态 | 全量替换而非重复追加；计数同步，完成绿勾/划线，进行中深色，待办灰虚线 |
| IN-04 | 独立折叠钮收起→原位hover→移开再hover→点胶囊 | 滑入角内计数胶囊；600ms冷却不误播，之后展开图标平滑加入；整颗胶囊可展开 |
| IN-05/09 | A/B各建不同清单，来回切换 | 各自内容/状态隔离；不串到空会话 |
| IN-06 | 非空清单时退出重启并打开该会话 | 内容/状态从会话数据恢复 |
| IN-07 | 下一轮问“我现在的任务清单是什么” | 模型消费常驻段直接复述，不需读文件 |
| IN-08 | 清空；另验全部完成后下一轮普通消息 | 空数组后浮卡消失；全完成段会催模型清空，模型未遵从时记录模型行为与请求段证据 |

折叠是页面本地态；普通会话切换可保持，离开聊天视图再回来可能复位，清单数据不受影响。

## 提问面板

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| IN-10/16 | 单问/带header和描述的问题 | 输入区为单题向导，编号选项与自由输入；header/说明正确，单题无切换器；已有清单仍显示 |
| IN-11 | 单选点选项；多题中翻回重选/点已选项 | 单选立即收题推进，末题立即提交；换项覆盖，点已选项取消并留本题；模型按答案继续 |
| IN-12 | 自由输入后Enter，含中文输入法组合阶段 | 自由文本优先，组合阶段不误提交；最终回答进入转录 |
| IN-13 | 每题点忽略 | 非末题推进，末题整卡提交；模型知道全部跳过后自行继续，不再空挂 |
| IN-14 | 多问首题作答，翻回检查草稿，再忽略末题 | ‹n/m›与边界禁用正确，草稿保留；部分答/部分跳过回灌准确 |
| IN-15 | 多选勾两项、取消一项，再继续/提交 | 多选点击不自动推进；最终模型收到保留项集合 |
| IN-17 | 挂起中切B再回A | B无A面板；A仍挂起，可继续作答；本地草稿重建边界按前置说明 |
| IN-18 | 挂起中删除会话 | 引擎取消挂起，无残留面板、无崩溃 |
| IN-19 | 可选：诱导工具含重复问题/选项或自带“其他” | 工具错误明确，模型可修正重调；校验本体以自动回归为准 |

键盘另验：↑↓/Tab循环高亮，Enter/空格与点击同义；“其他”行Enter进入输入；
输入框空格正常输入、↑↓交还列表；无高亮时不吞冒泡按键。

## 计划开关与裁决

从 ask + 计划关开始。每次裁决消费一个挂起面板，验证不同裁决时重新触发方案。

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| IN-20 | 发计划触发语，模型调enter_plan；已开时再调 | 浅灰计划chip与菜单勾选同步出现，权限钮一直是ask；重复开启幂等 |
| IN-21 | 计划开着让模型write/edit/exec | 直接工具错误，不弹权限审批；read/grep/todo/ask可用 |
| IN-22 | 新聊天与已有会话分别从菜单开计划；点击chip文字、计划图标及空白，再hover点×；另用Tab聚焦×后按Enter/空格，窄面板重复 | 主体点击不关闭；只由独立×关闭，鼠标hover及键盘聚焦时可见；窄面板保留关闭入口；菜单同步，chip与分隔线消失，档位不变 |
| IN-23 | 调submit_plan，使用长方案 | 输入区方案面板，pre限高可滚，两选项批准/拒绝，无切档下拉；清单可并存 |
| IN-24 | ask权限下批准方案 | 面板关闭、计划chip消失、权限仍ask；后续写文件照常询问，允许后才落盘 |
| IN-25 | 计划开启时切完全访问（过风险闸门），再让模型写 | 计划约束优先，仍拒写；关计划后才按完全访问直行 |
| IN-26 | 无附言拒绝 | 当前run结束、输入恢复、计划保持开启，不自我修订空转 |
| IN-27 | 附言“改用SQLite，其他不变”后拒绝/附言Enter | 意见回灌，模型修订并重提；计划仍开，无附言拒绝与此路径区分 |
| IN-28 | ↑↓/Tab选择、hover、Enter，焦点进出附言 | 高亮与执行一致；附言Enter只提交拒绝+意见，不误批准；无选中则确认禁用 |
| IN-29 | 可选：计划关时直调submit_plan；或调研中手动关 | 工具错误并指引先开计划，不挂起；读取的是活开关 |
| IN-30 | 批准后隔几轮问已批准计划 | 模型仍可复述计划，常驻段不依赖历史未压缩 |
| IN-31 | 重启前分别设权限/开关并批准计划，退出重启 | 权限、开关、已批准计划分别按存储恢复；开关不覆盖档位 |

## 收口与综合

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| IN-32 | 提问/计划挂起时退出重启 | 不复活挂起面板，旧调用呈中断语义，会话仍可新对话 |
| IN-33 | 可选：计划开启时同批制造plan与ask挂起 | UI按审批>计划>提问逐个显示，裁决后下一个可见且可处理；触发不稳不能算通过 |
| IN-34 | 让模型先计划、按需ask、批准后执行笔记工具，执行前手动切完全访问 | 档位/计划独立，提问回灌，清单推进与清空正确；无双重面板、卡死或残留 |

多会话并发再验：A挂起时B可继续，A的答复只回A；有附言的拒绝与真正模型失败
分别观察，不能按接近发生的时间推断根因。模型不调用工具时先核对请求工具目录与
模型能力，记录触发未成功，不能把未触发用例写成通过。
