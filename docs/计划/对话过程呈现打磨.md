# 对话过程呈现打磨

> 用户实测反馈五问题（2026-11-16）：折叠闪烁/高度跳变、工具行缺类别词、
> 失败红色块、工作中行上下跳动、spinner 换流光。目标形态对齐 zcode
> （用户给的三张参考图，第三张修正 live 形态——工作中在流底、顶部头条
> 只在收尾出现）。已实施（四关 33 文件 230 用例全绿）；现状描述见
> 模块/消息呈现.md 与 UI布局.md「过程行」。

## 一、目标

1. 「已工作/思考」折叠展开：动画平滑，无闪烁；一行内容展开不再大幅跳变；
2. 工具行 = 图标 + 类别词 + 主文案（如「已读取 src/index.ts」），不再是
   裸 `read("src/index.ts")` 等宽串；
3. 工具失败：行尾小字「执行失败」（点状下划线），hover 弹 Tooltip 看原因
   （带复制），整行不再变红；
4. 流式输出期间「工作中」指示不再上下跳动；
5. 运行中状态去掉旋转圆圈 spinner，改流光扫过（文字扫光为主）。

## 二、对比结论（reference 同主题，出处：文件:行号）

zcode（`packages/ui/src/`）：

- **流光**（问题 5）：纯 CSS —— `styles.css:957-1007` `animated-gradient-text`
  （`background-clip:text` + `background-position` 4s 循环扫光），**没引任何动画库**。
  图标刻意静态：`ToolLayout.tsx:138-140` 注释原话「旋转 loading 图标会让动画
  长期占用渲染资源；运行态改由文案扫光和状态文字表达」；
- **工具行结构**（问题 2）：`ToolLayout.tsx` + `ToolSummaryRow.tsx`：
  `图标 + kindLabel(类别词"已读取") + primaryText(路径) + diffCount(+199) +
  statusNode(执行失败)`。类别词随状态翻（`i18n zh-CN.ts:6352-7186`：
  正在读取/已读取/正在写入/已写入/正在搜索/已搜索…），运行中类别词扫光
  （`ToolLayout.tsx:143-148`）；
- **失败呈现**（问题 3）：`ToolLayout.tsx:241-294` —— 状态词「执行失败」
  `underline decoration-dotted` + Tooltip（错误文本 line-clamp-3 + 复制钮），
  失败不强制展开内容、不红整行；
- **折叠动画**（问题 1）：Radix keyframes + **300ms 延迟卸载**
  （`ToolLayout.tsx:196-203`：卸载先行会让高度变量消失继承外层高度，
  「详情区域短暂撑成超高空白块」—— 与本项目闪烁同病）；收起时 padding
  留在动画节点外层（`ToolLayout.tsx:348-351` 注释）；
- **live 形态**（问题 4，2026-11-16 补图核实）：live 期间**无顶部头条**，
  过程条目就地逐条追加，ChatLoading（「工作中」扫光 + 计时 + 非旋转
  图标）钉在**流的最底部**（`chatLoadingVisibility.ts:38-62`：isLastTurn +
  isRunning 即显示）；「已工作 X」顶部头条只在 run 收尾出现
  （`ConversationTurnGroup.tsx:557-576`）；
- **思考行单行化**（问题 4 主源，`reasoning.tsx:270-421`）：live 思考
  **默认收起为单行** = 静态脑图标 + 「正在思考」扫光 + **末行摘要横向
  滚动**（overflow-hidden，超宽渐隐 mask，增长即推到末尾）—— 逐 token
  增长永不撑高布局；展开态才 `max-h-60` 内部滚动 + 底部跟随
  （`reasoning.tsx:451-476`），且**纯文本渲染不走 Markdown 解析**
  （注释原话：每 chunk 重跑解析字数越多越卡）；收起动画期间 300ms
  延迟卸载保高度（`reasoning.tsx:178-183`）；计时 1s 粒度且仅展开时
  更新（收起态不为隐藏耗时每秒重渲染，`reasoning.tsx:126-141`）。

Cogent 现状病灶：

- a) `trace.tsx:136` 折叠体用 `h-(--collapsible-panel-height)`（Base UI 首测
  高度）过渡；父级 `message-scroller.tsx:74` 带 `[content-visibility:auto]
  [contain-intrinsic-size:auto_10rem]` —— 视口边缘条目内容未渲染时面板量到
  10rem 估值，一行内容也按 ~160px 展开再回落 → 跳变+闪烁；
- b) `data-starting-style:h-0`：默认展开态每次挂载都从 0 播一遍动画 → 闪烁；
- c) Base UI Panel 关闭即卸载（keepMounted 默认 false），展开首帧 markdown/
  字体未完成布局，高度变量中途变 → 动画过程跳；
- d) `TurnGroup.tsx:363-377` live 态「工作中」行浮在过程流底部（位置本身
  与 zcode 一致），跳的是**上方内容**：Reasoning 思考自动展开、全文逐 token
  增长撑高（Cogent `open ?? running` 与 zcode 默认收起相反）+ 完成时又自动
  收起一跳；bash ProgressTail 行数 0→1→2 翻动；终答开流翻 headerMode
  （摊开→折叠）整体跳变。

动画库调研（问题 5 附带）：zcode 同款效果纯 CSS 即达；Cogent `globals.css:250-282`
已有同手法 `.shimmer`（trace 标题在用），`tw-animate-css` 已在依赖。
**结论：本批不引库**。若后续要弹簧物理/layout 动画，届时选
[motion](https://motion.dev)（原 framer-motion，~30KB min+gz，React 默认选）；
react-spring ~18KB 偏物理弹簧；auto-animate ~2KB 管列表增删 —— 本批均用不上。

## 三、设计

### 3.1 折叠动画换 grid-rows 技法（问题 1）

`TraceCollapsibleContent` 弃高度测量，改 CSS Grid 轨道动画：

```css
/* 闭合 0fr ↔ 展开 1fr，fr 可插值无需测量 —— 病灶 a/c 直接消失 */
display: grid;
grid-template-rows: 0fr;
transition: grid-template-rows 200ms ease-out;
&[data-open] { grid-template-rows: 1fr; }
内层 { overflow: hidden; min-height: 0; }
```

- 钩 Base UI Panel 现成属性 `data-open`/`data-closed`（Panel 暴露，已核实），
  starting/ending-style 不再需要（挂载即展开态时 grid 初始即 1fr，无动画起跳
  —— 病灶 b 消失）；
- 内边距留在内层（overflow 随轨道连续裁切，同 zcode `ToolLayout.tsx:348`
  的教训）；motion-reduce 降级为无过渡直开直合；
- `.shimmer` 等 keyframes 不受影响。

### 3.2 工具行结构（问题 2）

`tool.tsx` ToolCard 头行改为：`图标 + 类别词 + 主文案 + diff 计数 + 状态词`。

- **类别词表**（新纯函数 `toolDisplay(name, status)`，含单测）：

  | name | 运行中 | 终态 |
  | --- | --- | --- |
  | read | 正在读取 | 已读取 |
  | write | 正在写入 | 已写入 |
  | edit | 正在编辑 | 已编辑 |
  | grep / find | 正在搜索 | 已搜索 |
  | ls | 正在列出 | 已列出 |
  | powershell / bash | 正在执行 | 执行命令 |
  | todo_write | 更新待办 | 待办清单 |
  | ask_user | 正在询问 | 已询问 |
  | enter_plan / submit_plan | — | 进入计划 / 提交方案 |
  | mcp__<server>__<tool> | 正在调用 | 已调用 `<server>.<tool>` |
  | 资源三件 / 其余 | 正在执行 | 已执行 |

  运行中类别词挂 `.shimmer`（zcode 同款：图标静态、文案扫光）；
- **主文案**：新纯函数 `parseToolSummary(summary)` 剥出括号内参数文本
  （等宽字体保留）；解析不出（历史异形）整段 fallback 显示原 summary；
- **diff 计数**：edit/write 终态从 `diff` 文本数 `+N -N` 尾标（绿/红小字）；
- 思考行补时长尾标「持续了 Xs」：`splitTurn` 的 thinking 伪段改保留
  durationMs（只剥 usage），`Reasoning` 加可选 `durationMs` 尾标。

### 3.3 失败呈现（问题 3）

- error 态：图标保持工具图标（不再是 CircleX），整行不再 destructive 变色；
  行尾「执行失败」小字 + `underline decoration-dotted` + Tooltip
  （`npx shadcn add tooltip` 装组件，约定 §3.2 shadcn 优先）—— hover 出
  错误详情（`resultSummary`）+ 复制钮；
- 折叠体保留（手动展开看全量输出 CodeBlock，default 变体不再红）；
- blocked（已拒绝）维持置灰单行不变。

### 3.4 live 流稳定化（问题 4）

「工作中」行**留在流底部**（zcode 同位；跳的不是它，是它上方的内容），
抗跳三板斧把上方全部单行化：

1. **思考行单行化**（Reasoning 改造，主源）：live 态默认收起 = 静态
   BrainIcon + 「正在思考」扫光 + 末行摘要横向滚动（overflow-hidden +
   超宽渐隐 mask + 增长推到末尾，zcode `reasoning.tsx:227-268` 手法）；
   展开态限高 `max-h-60` 内部滚动 + 底部跟随；展开内容改纯文本渲染
   （不走 Markdown，逐 chunk 解析是卡顿源）。废除「思考中自动展开」
   （现 `open ?? running` 与 zcode 相反，正是撑高主源）；完成态标题
   「思考」+「持续了 Xs」；开合仍「用户手动优先」；
2. **ProgressTail 定高**：bash 运行中尾部快照固定两行槽位（不足补空），
   行数翻动不再推挤；
3. **删「终答开流即折叠」翻转**（`TurnGroup` headerMode 分支 + live
   RunTrace 头）：live 全程 = 过程条目（已单行化）+ 流式正文 + 底部
   「工作中」行，结构恒定；run 收尾**一次性**收进顶部「已工作 Xs」
   头条（终答常驻头条下）。**推翻 2026-11-10「终答开流即折叠」定调**
   （摊开→折叠翻转正是流中跳变源；过程单行化后摊开不再占空间，
   收尾统一收），回执进 决定.md。收尾折叠动画即 3.1 的 grid-rows。

### 3.5 spinner 退场（问题 5）

- `run-trace.tsx`（WorkingLine 与 RunTrace live 头）/ `tool.tsx` /
  `reasoning.tsx` 运行态的 `LoaderCircleIcon animate-spin` 全部移除：
  图标静态（工作中行用 ClockIcon、思考行 BrainIcon、工具行各自工具图标），
  活动感由类别词/标题 `.shimmer` 扫光承担；
- bash 运行中在尾行上方加 indeterminate 扫光细条（64px 宽 1px 高，
  高光滑块往复，zcode `styles.css:1008-1020` 同款 keyframes），
  替代圆形 spinner 的「活着」信号；
- 码表 100ms 走字保留（2026-11-11 定调不动）。

## 四、边界 / 首发不做

- **连续同类工具聚合组**（zcode ConsecutiveSummaryGroup「已读取 3 个文件」
  翻滚摘要）：真实墙是 Cogent 消息流无「组闭合」边界信号（zcode 靠
  tailRowId + taskRunning 双条件），需引擎侧协议配合 —— 后续件；
- **流光粒子球等品牌动效**（zcode ChatLoadingOrbs 是 Z 品牌资产）：不做，
  静态图标 + 文字扫光已满足「不用圆圈」的诉求；
- **MCP 工具专属图标**：zcode 按 server 配图标，Cogent MCP 无图标元数据
  通道 —— 统一终端/插件图标兜底，协议有通道后再做；
- **动画库引入**：本批不需要（见对比结论），不为「补库」而引。

## 五、验收

1. 展开任一「已工作/思考」折叠：全程单一连续动画，无闪烁、无高度回落
   （含视口边缘条目）；
2. 每个工具行有类别词 + 主文案；运行中类别词扫光、无旋转图标；
3. 失败工具行：整行非红，行尾「执行失败」hover 出 Tooltip（原因 + 复制）；
4. 长输出回合（工具+思考+正文持续流式）期间「工作中」行稳定在流底部：
   思考增长/收起、bash 进度翻动、工具翻态不引起上方高度翻动；顶部
   「已工作 Xs」头条只在收尾出现，收进过程为单次平滑动画；
5. lint / typecheck / build / npm test 全绿；新增纯函数
   （toolDisplay / parseToolSummary / diff 计数）带单测，turn-group 既有
   测试随结构更新，失败态 Tooltip 补一条渲染断言。
