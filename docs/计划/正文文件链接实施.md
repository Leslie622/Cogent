## 4. 文件目标与来源身份

### 4.1 路径来源随消息保存

- 每个真实用户输入分配 turnId；来源记录最少含 version、turnId、实际 userEntryId、实际工具 cwd、当时根集合与 Host 平台。
  cwd 取实际内核／工具上下文，不在点击时从当前项目配置重新推断。没有绑定项目时沿用现有工具的 Home cwd，但不扫描 Home。
- 扩展 onUserEntry 对纯文本和附件输入均绑定；写入独立的 `cogent.file-context.v1` custom 元数据。
  提前停止但已保存的输入也绑定；装配尚未成功则只保留已知来源状态，不编造实际 entry。
- 自动续写／压缩／手动继续沿用原用户 turnId，内部 continue 消息不生成新用户回合。①不引入 executionId 或 before/after 账本。
- readPiTranscript 回读后把助手段和工具引用关联到相应真实用户 entry；轻量历史查询不装配 pi。
  只增 optional 字段，原 `u-N/a-N` ID、DOM key、附件元数据、压缩条和用量归并不变。
- 旧消息没有来源元数据：显式绝对路径可用；相对路径可按会话当前主根打开并注明“使用当前工作区”。
  不为旧反引号名字猜测已知文件，不假装还原历史来源。

### 4.2 fileId 只代表已解析的当前目标

Host 按 session＋来源＋规范路径登记不可猜测 fileId，保留展示别名、实际目标、文件类型、服务代次和当前版本标记。
位置单独放在 FileLocation 中，不能把 `:12` 拼进文件名；同文件不同定位可复用预览。
fileId 不是授权本身，读取与动作仍校验会话和来源；Host 重启后旧 ID 失效，正文凭保存的来源重新解析，不要求 ID 跨进程存活。
符号链接当前目标与登记时不同要报“目标已变化”，不静默换身份；文件后来修改时显示当前版本，删除时明确报缺失。

```text
owner: Host = 来源/目标与读取；renderer = 链接/预览；main = 用户触发的桌面动作
用户输入 → 实际 entry ↔ turnId/cwd（轻量持久化）
正文 → Markdown 语法树 → 内部目标 → FileLink
点击 → files.resolve(session/turn/原目标) → fileId → 当前内容预览
                                                    └─ main 复核目标 → 打开/定位/另存/编辑器
重启 → 回读来源 → 点击时重新 resolve；不恢复或伪造历史文件内容
```

## 5. 解析与渲染规则

| 输入 | 约定 |
| --- | --- |
| `[名称](./src/a.ts)`、`[名称](src/a.ts)`、裸文件名目标 | 相对消息来源 cwd；明确 Markdown 目标可以无扩展名，不靠扩展名猜文件／目录 |
| Windows 盘符、POSIX 绝对路径、`~/` | 按来源 Host 平台解析；异平台路径不强转成当前盘上的同名文件 |
| UNC | 支持反斜杠 UNC 与 `file://server/share/...`；裸 `//host/path` 按协议相对网页处理，UNC 使用前两种明确形式 |
| 含空格／中文／特殊标点 | 支持标准尖括号目标与合法转义；Windows 原文恢复包含普通链接、尖括号及 title 场景，校验失败不猜改 |
| `:行`、`:行:列`、`#L行`、`#L行-L行` | 拆为定位信息；无效／越界位置仍可看文件，显示未定位原因；字面 `#/?` 和数字冒号用百分号编码 |
| `%2520`、`../` | 文件目标百分号只按语法解码一次；先保留相对含义，再按来源 cwd 解析实际目标，不让 URL 清洗提前吞掉父级 |
| HTTP(S)、网页片段、其他协议 | HTTP(S) 走现有系统浏览器；纯 `#片段` 不当文件；未知协议与未完成标记保持不可打开，不导航走应用 |

固定处理顺序：

1. remark 从 VFile 原文恢复 Windows destination，位置切片与反转义结果必须一致；不在显示文字上做路径正则替换。
2. 在默认 URL 安全处理前识别本地目标，编码为 `#cogent-file:…` 的内部载荷，保留原始路径与定位信息。
   编码只用于渲染树；手写相同前缀也必须过载荷校验与 Host 校验，不能成为越权捷径。
3. 保留 Streamdown 全部默认 remark／rehype 插件和现有主题／reveal 顺序；自定义数组的覆盖语义必须在真实组件测试中验证。
4. `a` 组件只对合法完整目标渲染 FileLink；`streamdown:incomplete-link` 禁用。完整链接可在流式中点击；不逐 token stat。
   来源、插件和 components 引用按消息稳定，不能每次 delta 让全部历史块重新解析。
5. 反引号词表来自成功的 read/write/edit 等明确单文件操作；使用真实工具 cwd 与规范路径，包含嵌套调用。
   精确路径或唯一 basename 才变 FileLink；代码围栏、命令、歧义、未知 token、已有 a/button 内保持原样。
   不扫描目录找同名文件，也不解析任意 shell 命令／MCP 文本猜文件；②③将来只需向同一词表补充结构化引用。
6. 工具卡按 callId 绑定 optional fileRefs；历史从结构化调用与成功结果重建同样引用，失败不捏造“已读／已写”的词表成员。
   保留原摘要，明确路径单独提供入口，不把截断文本拆成假路径。

## 6. Host 合同、读取预算和桌面动作

| 拟增合同 | 作用 |
| --- | --- |
| `files.resolve` | `{sessionId,turnId?,rawTarget}` → 文件描述、fileId、服务代次、位置与来源状态；按需解析，不建立全工作区索引 |
| `files.readText` | 按 fileId／当前版本／位置读取有界文本，返回编码、起始行与后续 cursor；定位所需内容同样受预算约束 |
| `files.readChunk` | 按 fileId、offset、length 读取当前普通文件字节；分块组装图片／PDF／媒体 Blob，不传任意路径 |
| `files.parseDocument`、`files.cancel` | 复用文档 worker 的分页／工作表参数；按会话和预览 operationId 取消，不中止 Agent run |
| `session.messages` optional 来源表；消息 optional turnId | 历史水合；来源绑定与正文同时可用，不根据当前选中会话补归属 |
| 工具事件／ToolCallRecord optional fileRefs；run.started optional turnId | 供词表和实时占位继承来源；旧引擎／旧数据自然缺省，不改既有事件名 |
| 壳 `files:action` | 仅 `open/reveal/save/editor`；main 向 Host 重新核对 fileId，再执行系统动作；renderer 不传任意可执行命令 |

所有文件读取方法进入类型注册表和 main 显式白名单；HTTP/WS 与 guest 默认拒绝 `files.*`，
复用附件域的桌面隔离方式。main 内部取系统目标的能力不进入 renderer 通用方法白名单。
可信窗口检查以主窗口 webContents/frame 来源为准，不能只靠请求里自报 sessionId。

本机主窗口允许显式链接指向根外可访问文件，与现有 read 的语义一致；不因此扩展项目绑定、写权限或远程读盘权限。
不对普通点击新增审批弹窗。入口验证协议载荷、会话归属、真实目标和普通文件／目录类型；内部调用信任已验证类型。

读取初始护栏：2 路并发预览；单帧字节块最多 256 KiB；文本预览最多 20 MiB；图片最多 20 MiB／4,000 万像素；
PDF／Office／媒体字节合计最多 100 MiB／当前预览；文档解析超时 30 秒沿用 worker 限制。
超限保留文件信息及系统打开，不伪装完整预览。分块版本变化时中止并提示重新加载，不能把两个版本拼成一个文件。
这些预算需要实测内存与耗时后调优，不宣称已经通过该容量验收；不把字节内容写进会话或持久内容库。

复制路径用已确认的展示绝对路径；reveal 定位文件，目录则打开目录；系统打开失败显示原因；另存用系统对话框，取消不报成功。
编辑器提供最小配置入口：VS Code／Cursor 固定参数适配＋用户选择的可执行文件路径，设置落现有设置域；
使用 execFile 参数数组和窗口隐藏选项，禁止自由 shell 命令模板。未配置时可在文件菜单选择，不依赖后续阶段新增设置功能。

## 7. 预览与状态归属

| 类型 | 本阶段预览 |
| --- | --- |
| 文本／源码 | 只读 CodeMirror，行号、搜索、行列／范围定位，语言扩展按需加载；UTF-8、BOM UTF-16 明确解码，未知编码提示 |
| Markdown | 渲染／源码切换；相对引用相对当前文件目录；本地依赖仍走 fileId 服务，外部资源不自动加载 |
| 图片 | 原图、缩放与适配；加载失败显示原错误，不无限重试 |
| PDF | PDF.js 按页渲染、页码和缩放，取消离屏任务，释放 worker／canvas；不是只提取文字 |
| DOCX／XLSX／PPTX | 复用 worker 的结构文字、工作表／范围、幻灯片页序；明确标内容预览，原生版式用系统打开 |
| 音视频 | 预算内 Blob URL＋原生控件；格式／编码不支持时给系统打开，切换即释放 URL |
| 目录／其他／超预算 | 文件信息、复制／定位／系统打开／另存等适用动作；不把可执行 HTML／脚本嵌成应用权限页面 |

FilePanel 由 HomeMain／HomeTabs 的现有右侧区域承载，当前文件重复点击复用视图；在 ≤1100px 的自动折叠布局里使用 Dialog，
不强撑开被断点禁止的侧栏。点击文件是明确打开意图，可以展开宽窗右栏；关闭恢复已有布局逻辑，不新增浏览器或通用标签页系统。
菜单、按钮、Dialog、Tabs 和分栏沿用 shadcn 原生形态；文件图标映射、加载／错误显示封装为复用组件，不在调用点加皮肤补丁。

预览状态按 session／fileId／服务代次归属；每次加载带 request generation、版本和 operationId。
切文件／会话、关闭、删除会话或 Host 重启时取消旧读取、终止旧 worker、回收 Blob；迟到结果不能复活旧预览。
状态不塞进 Markdown 块或 Agent 运行位；阅读中的用户不因预览开合被拉回聊天底部。

| 场景 | 必须观察到 |
| --- | --- |
| Windows 盘符／UNC、Linux、无扩展名、空格中文、含 title 的链接 | 目标正确；反斜杠和路径字符不丢；不导航走主窗口 |
| `./`、`../`、`~/`、根外绝对目标、多根同名文件 | 按原来源解析；根外可访问目标可开；歧义 basename 不乱选 |
| `%2520`、字面 `#/?`、数字冒号、行列范围、无效位置 | 文件名不被重复解码；位置与路径分离；无效位置说明原因 |
| 普通 HTTP(S)、`#片段`、未知协议、脚本 URI、内部载荷伪造 | 各走约定路由；不能绕过 Host 校验或导航走应用 |
| 流式链接未闭合→闭合→终态，重复段落与长回答 | 未完成不可点；完整可点；无逐 token stat；已有渐显／选择／滚动不退化 |
| 只 read 后引用、write/edit 后引用、嵌套工具、同名与失败工具 | 已知且唯一才链接；失败不宣称成功；重启后的结构化引用一致 |
| 新消息后切项目／改根、压缩、自动续写、手动继续、准备期停止 | 来源不漂移、不产生重复回合或丢附件元数据；旧消息降级说明真实 |
| 文本定位与搜索、Markdown 本地依赖、图片、PDF、三类 Office、音视频 | 逐类型验收；PDF 显示页面；Office 不冒充版式；不支持格式有可用系统动作 |
| 文件后来改写／删除、符号链接换目标、Host 重启 | 当前状态真实；不显示旧缓存冒充当前；失效 ID 可重新解析 |
| 切文件／会话、关面板、删除会话，旧请求迟到 | 旧任务取消、资源释放、不串台、不复活已删状态 |
| 大文件、超像素、解析超时、无权限、版本在分块中改变 | 明确错误／容量边界，不卡住 Agent run，不生成拼接的错误内容 |
| 复制、定位、系统打开、另存取消／成功、编辑器配置与缺失 | 动作作用于正确目标，路径不进入 shell 插值；HTTP／guest 无这些能力 |
| 400px 窄窗、明暗主题、100%／125%／150% 缩放、键盘与阅读中打开 | 无裁切／焦点陷阱，侧栏遵守断点，聊天阅读位置不被夺走 |

自动测试必须覆盖纯解析、真正的 Streamdown 默认管线、Host／IPC 边界、历史来源和异步归属；
Electron 点击／系统动作、Windows 路径、目标 Linux、缩放与文档排版单独记录手测结果。没有实机的项标待验，不能以 jsdom 代替。

## 10. 边界、文档与完成定义

| 边界 | 实际原因与处理 |
| --- | --- |
| 不回填旧消息从未保存的历史来源 | 原始 cwd 不可可靠还原；仅按当前会话根明确降级，不按时间猜 |
| Office 原生排版／编辑 | 现有解析器只提供结构内容；本阶段保留内容预览和系统打开，不引入新排版引擎 |
| 超预算内容与 Electron 无法解码的媒体 | IPC／内存／编解码器有真实上限；保留文件信息和原生应用入口 |
| HTTP／guest 读任意当前文件 | 现有 token 尚无 Session 文件范围授权；新增读取留在可信桌面通道，不扩张外部文件权限 |
| 不保留历史文件内容 | ① 的承诺是正确打开当前目标；②交付副本和③版本快照单独建设、单独验收 |
