## 仍需设计或实测的优化

| 优先级 | 主题 | 实施前需解决的边界 |
| --- | --- | --- |
| 1 | 统一资源权限 | 已封桌面文档边界；用户 token、session scope、审批真实路径与执行时链接边界继续按[架构地图方案](架构地图目标架构.md)设计 |
| 2 | 文件资源交接和容量 | 草稿晋升需在 Host 校验后转移文件上下文所有权。附件废弃暂存、预览准入预算、搜索与观测 I/O 使用真实产品链测量后定策略 |
| 2 | 工作区极窄窗 | 400px 广域探针复现活动标签头被裁切，保留原始截图和几何条件。正式流式性能门槛仍依照[工作区验收余项](多标签工作区实现.md) |
| 2 | 退出与网络实测余项 | 模拟服务器和合成工具的回归不等于真实服务器全矩阵；网络预算仍需真实产品负载定档 |
| 3 | 测试并发与发行 | 验证 pi 缓存独立后评估集成并发。最终安装布局产出后，从安装目录量 Host 与各 worker 冷起；Linux 阶段先验证独立 Host |
| 3 | 内核与协议类型 | 继续沿稳定的转录、配置和运行职责提取，统一公开契约与事件投影 |

保留 Vitest 的源码、jsdom、产物三层，CI 保持真实 Electron 最小链路。按缺陷与重复覆盖增删用例；数量不作验收门槛。
