# 图片与文件附件：验收余项

实现机制、UI 配方和原理已经分别归入[模块页](../模块/图片与文件附件.md)、
[UI布局](../UI布局.md)、[技术笔记](../技术笔记/图片与文件附件.md)。
本文件只保留尚未完成的目标环境验证，不重复已落地设计。

## 既定边界

本批路线为本地受管附件 + 自带 read_attachment 文档工具 + 媒体 MCP；
服务器上传只提供可注入 uploader。原生 PDF/视频、离线 OCR、ffmpeg 抽帧/转码/转写、
Office 完整渲染/编辑、公式重算和旧 Office 转换不内置：它们需要额外引擎、资源分发和
质量验收，现有出口为配置的 document/video MCP，缺失时保留未解析原件。

## 验收余项

- Windows 资源管理器的实际复制操作、真实鼠标拖入、Excel 混合剪贴板、
  中文 IME、原生多选/另存对话框；受控 DOM 粘贴/拖入不替代 OS 文件管理器证据。
- 目标 Linux 文件管理器/URI 剪贴板、Node 22.19 最低版本、glibc 2.28 与 PDF.js 可选
  原生依赖、发行包中的共享 chunks/worker/字体/CMap/wasm 资源。
- 实际媒体服务的认证、超时、格式/容量与时间覆盖；测试 MCP 的允许/拒绝/停止已覆盖
  宿主接线，但不能据此宣称所有厂商服务可用。真实服务配置由用户选择，不自动借用主模型 key。
- 400px/分屏的深浅主题、OS 100%/125%/150% DPI 和键盘/屏幕阅读完整矩阵；
  最大准入容量、复杂/加密 PDF、复杂 Office 与外部缓冲区内存峰值。
- 异常退出遗留暂存、无引用记录和分析 artifact 的维护清理策略；当前不做全盘自动清扫，
  日常移除草稿与删除聊天已按引用释放原件。

## 证据与收口

自动化与桌面步骤统一维护在[附件手测册](../测试用例/图片与文件附件.md)。
真实 pi 已验证条目绑定、纯附件、原生图片请求、早停、压缩后的保留式历史；
构建 worker 已验证中文 PDF 与 PPTX 资源。Electron 31 受控临时配置已验证截图粘贴、
DOM 文件拖入、原生 FileDropList 双文件 Ctrl+V、图片预览、400px、页面缩放、深色布局、
重启草稿和零空会话；原生 OS DPI 和全主题矩阵仍待补。

上述平台/服务矩阵完成后，将剩余结论迁入手测册并删除本过程稿。
