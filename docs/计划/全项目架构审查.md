# 全项目架构审查

审查基线为 `dd23d07398` 和当时的工作区，包含正在修改的架构地图。下文保留修复前的代码证据和复现，行号可能随实现变动。当前修复与剩余验收见[优化修复清单](优化修复清单.md)，实施顺序见[全局架构](全局架构.md)。

Electron 与独立 Node Host 的进程边界、pi 持有转录真源的分工、主 UI 与普通浏览器的隔离，以及目录扫描、会话搜索和附件解析下沉到 worker，都适合保留。当前主要问题出在同一操作跨入口时的授权、身份和提交语义。优先用现有产品链验证这些合同，再按职责拆分 `SessionManager`、契约和测试平台。

## 小问题与局部修复候选

- **对外 MCP 配置。** 真实产物在隔离存储中收到合法 JSON `null` 会退出，空对象可正常回落。建议对解码成功后的顶层形状统一收窄。MCP 开关、凭据文件刷新与已签发 token 的生命周期也需明确，当前配置变更依赖启动刷新。 [配置读取](../../src/host/mcp-server/config.ts#L30) · [启动交接](../../src/electron/main/index.ts#L182)
- **工具进度。** 进度先经过首段裁剪，再尝试取尾部，长输出无法得到文档约定的实时尾部。把流式摘要与历史投影的裁剪分别测试。 [投影](../../src/host/runtime/message-projection.ts#L13) · [进度事件](../../src/host/runtime/session.ts#L2128)
- **浏览器临时资源。** 导航会使旧文档的一次授权失效，但旧记录可能继续保留。以文档和 guest 为 owner，在导航、弹窗关闭和销毁时释放，沿用已有权限用例。 [一次授权](../../src/electron/main/browser/runtime.ts#L423) · [销毁](../../src/electron/main/browser/runtime.ts#L592)
- **边缘故障。** 旧壳数据的迁移复制与删除应按实际文件身份交接。控制台的侧栏切换应走已有的错误呈现。对话中移动纯费用格式函数可解除两个组件的循环依赖。 [迁移](../../src/electron/main/storage-root.ts#L44) · [控制台](../../src/renderer/src/features/console/ConsoleSidebar.tsx#L36) · [费用引用](../../src/renderer/src/features/home/CompactionBar.tsx#L15)
