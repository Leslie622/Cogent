# 代码与表格过渡

> 对话流畅性剩余清单第 2 项（交接 §22）。调研范围沿用用户裁决：只对照
> zcode（2026-11-18）。本文为目标 / 对比结论 / 设计 / 边界 / 验收，
> **用户审批通过后才动代码**。

## 1. 目标

流式中的代码块与表格目前整块静态出现（`stream-reveal.ts:23`
`REVEAL_SKIP_TAGS` 跳过 `pre/svg/table`）：围栏打开时整块代码「啪」一下
全亮，表格新行同样直出。本批给**新增内容**补低成本过渡：代码块的追加行、
表格的追加行首次挂载时淡入；高亮、未闭合语法、列宽、单元格换行与横向
滚动保持现状正确。

## 2. 对比结论（本次实读，仅 zcode + 本仓依赖实读）

| 项 | 出处 | 结论 |
| --- | --- | --- |
| 逐词插件跳过代码块 | zcode `docs/streaming-markdown-reveal.md:66`、`message.tsx:852`；Cogent `stream-reveal.ts:23` | 两边一致（高亮异步会打架），**行级过渡 zcode 无先例**——代码块/表格/引用块边框「随挂载直出」是其明确记录的接受边界（doc `:74-75`） |
| 可挪用素材：动效双家族 | zcode `styles.css:1117-1122`（300ms ease-out 逐词 / 260ms 急起整块入场） | 行级 mount 淡入归属逐词家族（要看出渐变得用 ease-out 尾部帧），与正文共用 `--reveal-duration/--reveal-ease` |
| 可挪用素材：@starting-style 只作用首次挂载 | zcode `styles.css:1128-1141` 注释（「已挂载元素上的 new 不会重播」） | 正是「旧行不重播、新行自动淡入」所需的语义，Cogent globals.css 同款机制已在用 |
| **行身份（本仓独有证据）** | `node_modules/@streamdown/code/dist/index.js`：按行前缀缓存 Shiki grammarState、只重亮尾部（`lastIndexOf('\n')` 前缀命中复用 `rows`） | **旧行 token 结构稳定**——追加代码不会重排已高亮的行 |
| **行 DOM（本仓独有证据）** | `node_modules/streamdown/dist/chunk-7TTQLYRW.js` CodeBlock（`In` 组件）：`result.tokens.map` 每行一个 `<span>`（索引 key）结构化渲染，**不走 innerHTML**（全文件仅 mermaid 一处 `__html`） | 追加行 = 末尾新挂载的 span；React 按位置复用旧行 span → mount-only 淡入纯 CSS 可行 |

结论：清单里「找到可靠的增量/行身份」已找到——行身份 = 索引 key 的行 span
+ 增量高亮保证前缀稳定 + `@starting-style` 只认首次挂载。**方案是纯 CSS
的 mount-only 淡入，不动 stream-reveal、不给代码排期、不逐词化。**

## 3. 设计

1. **作用域标记**：`markdown.tsx` 根 div 增
   `data-md-streaming={renderStreaming ? 'true' : undefined}` —— 取
   `renderStreaming`（含 §15 收尾暂留窗口），历史/终态 static 恒无标记、
   零动画；
2. **globals.css「逐词浮现」段旁新增**：

   ```css
   [data-md-streaming='true'] [data-streamdown='code-block-body'] code > span,
   [data-md-streaming='true'] table tr {
     transition: opacity var(--reveal-duration) var(--reveal-ease);
   }
   @starting-style { …同选择器 { opacity: 0 } }
   ```

   - 首挂整块（围栏刚打开）：所有行同帧起淡 = 免费的「整块入场」；
   - 追加行：只有新 span 挂载，逐行淡入，相邻行的淡入自然叠成瀑布
     （与正文尾巴同节奏，无需排期）；
   - 未闭合围栏的最后一行每批改写内容但**元素保留**（索引 key + 增量
     高亮）→ 不重播；
   - `prefers-reduced-motion` 与既有段同关；
3. **不动**：`stream-reveal.ts`、表格列宽/换行/横滚逻辑、高亮管线、
   mermaid/svg（维持 zcode 同边界）。

```text
owner: Markdown（renderStreaming 作用域标记），CSS（@starting-style 挂载语义）
     ，@streamdown/code（行结构稳定性，本批只依赖不修改）
代码/表格追加行 → 新挂载的行 span/tr → @starting-style opacity 0→1（300ms）
旧行：索引 key 复用 + 增量高亮前缀稳定 → 元素保留 → 永不重播
终态/static：标记消失；已挂载行 opacity 已 1 → 无变化、无重播
```

**实施第一步（交接判据要求，先于 CSS）**：真 DOM 探针复验三件事——
流式追加代码时旧行 span 同节点、新行是新 span、异步高亮到达不换行元素；
表格旧行 tr 保留、新行新 tr。任一不成立即回到设计台，不带病上 CSS。

## 4. 边界（真实的墙）

- 单元格/未闭合行**内部**的文字增长仍直出（行身份 ≠ 字身份，zcode 同
  边界）；行内 code 增长同；
- 高亮异步首达时颜色瞬变（灰→彩）是既有行为，本批不变；
- 行结构证据来自 `@streamdown/code` / `streamdown` dist 实读（非公开
  API 契约）——**升级依赖须复验行 span 结构**（同 zcode 对 processor
  缓存规则的同类依赖先例）；
- `table tr` 的 opacity 在 Electron31（Chromium 126）的真机表现（边框/
  斑马纹随行淡入）实施时目验，异常则把过渡收窄到行内容盒；
- reduced-motion 下关闭；历史/快照/终态 static 零动画。

## 5. 验收

自动（先红后绿）：

1. markdown 根的 `data-md-streaming` 合同：renderStreaming（含收尾窗口）
   为 'true'、static/历史无；终态收尾完成后翻 undefined 不引起行重播；
2. 真实 Streamdown 渲染回归：流式中代码块行 span / 表格行结构存在（钉
   选择器合同，防依赖升级静默漂移）；
3. 相关既有回归（stream-reveal / markdown-terminal / turn-terminal）全过，
   四关全绿看完整输出。

手测（真机 Electron31，用户复验）：

1. 让模型流式输出多行代码（长函数）：追加行逐行淡入、旧行不闪不重播、
   高亮正确（含未闭合围栏过渡到闭合）；
2. 流式表格：新行淡入、列宽变化与横向滚动正常、斑马纹正确；
3. 历史消息（切会话回来）代码/表格零动画；系统 reduced-motion 时无动画。

## 6. 实施与验证记录（2026-11-18）

- **探针（§3 第一步）先于 CSS**：真 Streamdown + jsdom 渲染复验四件事全部
  成立——追加代码行旧行 span 同节点/新行新 span、围栏未闭合→闭合不重排
  旧行、异步高亮上色不换行元素（`--sdm-c` 到达后行 span 仍同节点）、表格
  旧 tr 保留/新行新 tr。一处测试修正：`| --- |` 分隔线不渲染成 tr（头行
  +N 数据行）。探针删除后以 `md-line-transition.render.test.tsx` 重建为
  正式回归（身份合同 5 项 + 作用域标记合同 3 项）。
- **实现**：`markdown.tsx` 根挂 `data-md-streaming`（`renderStreaming` 时
  'true'，含收尾暂留窗口；终态/static 摘除）+ `REVEAL_LINE_SELECTOR`
  常量；`globals.css`「逐词浮现」段新增行级 mount-only 淡入两条规则
  （与正文共用 `--reveal-duration/--reveal-ease`），reduced-motion 段
  transition 归零 + 起步态放开同关。
- **实施中发现的必要修改（计划外、同主题）**：终态收尾等待原本只认
  `data-reveal`/`data-reveal-marker` —— 纯代码/表格消息没有 reveal span，
  终态会立即切 static、切断仍在播的行淡入（Block 树被换、行元素重挂）。
  收尾等待的 opacity 分支纳入 `REVEAL_LINE_SELECTOR` 目标（仍是「只等本件
  渐显」语义，行淡入即本件渐显）。红灯验证：退回旧过滤器该回归即红
  （`markdown-terminal.render.test.tsx` 新增 1 项：行淡入未完不摘标记、
  行元素保留到淡完、放完后摘标记）。
- **属性合同红灯**：实现前 2 项标记合同红（流式 'true' / 作用域链选择器），
  实现后全绿。
- **四关**：lint（修 1 处测试冗余断言）/ typecheck / build 全绿；
  npm test **56 文件 540 项全过**（+1 文件 +8 项）。
- **边界回顾**：jsdom 不实现 CSS 过渡与 @starting-style，动效本身与
  Electron31 下 `table tr` opacity 的边框/斑马纹表现（§4 已列）按测试用例
册真机步骤由用户复验；终态翻转后 static 树重挂是既有行为（Block 渲染
路径切换），重播由「摘标记后无 scoped 规则」挡住，非 DOM 身份不变。

**2026-11-18 用户真机复验通过**（§5 手测 1–3 与 §4 表格行边框/斑马纹
边界项）：追加行逐行淡入、旧行不重播、高亮稳定、表格行淡入正常、终态
