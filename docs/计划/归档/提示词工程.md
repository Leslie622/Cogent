## 一、调研结论：三库三条路线

**pi = 分节 system + 按节 diff；dsh = 注册表节序 + 易变事实外置 user 快照；
zcode = 双轴 section + 对话内附件降权。** 实现三家三样，收敛点同一个：
系统提示词是**装配产物**（命名分节、可排序、可局部更新），不是一整段
字符串。

## 二、共性收敛（三家一致 → 直接偷，不论证）

1. **装配而非整段**：提示词由命名分节拼出，节可独立更新；
2. **静态/动态分离**：稳定指令进领头 system；易变事实（cwd/env/权限态）
   走对话内**可取代**通道，且取代语义对模型显式（含「摘要里的旧版作废」）；
3. **工具文本双层**：一次性格式进 description，跨调用纪律/清单进提示词层，
   且**注册表驱动**（工具自述，加工具自动进段；模型看不到的不写）；
4. **错误即自纠指令**：error 文案内置动作句，参数 description 预告错误
   条件（事前防错优于事后报错）；
5. **指令文件多候选+预算+如实报告**：候选链、逐级降级、marker 明报删了什么；
6. 压缩指令用结构化模板——**Cogent 已对齐**（批次 4 抄 pi 双提示词；通道
   已是末位 user 消息 `compaction.ts:643`，与 dsh 的 KV cache 复用一致）。

## 四、批次

### 批次 A（结构地基）：提示词分节化 + 通告升级节更新

- 目标：`buildSystemPrompt` 产出命名分节——preamble 无标签，workspace /
  environment / project_instructions / tools 用 XML 标签包裹（pi 手法，节名
  规则 `^[a-z][a-z0-9_-]*$` 照搬）；权限通告从「前缀+content」升级为
  sections patch（节名 `permission`）：领头声明初始节，切换时按节替换。
  这就是 `session.ts:196` 注释里「通告不进 buildSystemPrompt（leading
  固化后运行中切换改不动）」的正式解法；
- 步：① 装配分节化（分段内容不变仅加节结构；用 `getSystemMessageText`
  渲染对比，除标签外逐字一致）② 通告改 sections ③ plan / autonomous /
  full-access 三模式文案核对；
- 风险：各方言对中部 system 的拼装（collapseSystemMessages）行为要过
  tools-smoke；AGENTS.md 段名用 pi 同名 `project_instructions` 还是
  `workspace_instructions` 批内定。

### 批次 B：注册表驱动工具段 + 权限联动

- 每工具文件导出 `promptContribution { snippet, guidelines }`（pi 命名
  照搬）；装配层从工具注册表拼 `- name: snippet` 清单+规则（Set 去重）；
  删除 `session.ts` 手写清单（单处维护）；
- 权限联动（D2）：不藏声明，工具段按当前权限模式标注写类工具状态
  （拦截已有 error 文案兜底）；plan 模式文案借 zcode 句式
  「This supercedes any other instructions」。

### 批次 C：AGENTS.md 候选链 + 降级 + OVERRIDE 句

- 候选链 `AGENTS.override.md > AGENTS.md > CLAUDE.md`（D3）；选中
  override 时加一句 OVERRIDE 强调（zcode）；超总预算逐级降级：丢最宽
  根 → 截断最特异根 → marker 如实报告「omitted X; truncated Y」（dsh）；
  每根 16k 上限保留。

### 批次 D：错误文案自纠体系

- 全工具 error 文案过堂：每条带动作句（「重新读文件后再试」句式）；
  参数 description 补错误条件预告（edit 的「必须唯一匹配」为范本补齐
  其他工具）；核查 bash 退出码对模型可见性，无则加 `[exit code: N]`
  尾缀（dsh）；补跨调用纪律（edit 前先 read 的提示词纪律；read-before-edit
  状态机不做，D4）。

### 批次 E（候选，视 A–D 验收再定）

- SYSTEM.md / APPEND_SYSTEM.md 用户定制通道（pi 项目+全局两级）；
- 日期/模型身份注入（D1 倾向不注）；
- 缓存断点核查：Cogent 走 pi 方言层，断点归上游管——只核查不开发。

每批完成 → 技术笔记一篇（含三库同主题对照+引出处）；机制同步进 session
模块页并核对「验收：」句。
