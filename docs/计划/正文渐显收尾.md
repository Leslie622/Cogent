# 正文渐显收尾

> 对应 [对话流畅性诊断与改造](对话流畅性诊断与改造.md) §6.2 已批准的“结束后已有淡入自然完成”。
> 用户验过块身份修复后要求继续。本批沿用其调研选择：聚焦最小修复，仍对照三仓；
> 在实现前记录本地生命周期、设计与验收。业务状态不等待视觉动画。

## 1. 目标

回复完成时，已经开始或正在延迟阶段的正文淡入自然结束，之后恢复原生静态全文解析。
运行位、输入按钮、用量、WorkingLine消失与RunTrace终态同步业务事件，不能留幽灵running。

## 3. 设计与owner

```text
owner: store/既有回合相位 = 权威业务完成，不改事件与消息
owner: Markdown = 本实例的视觉保留代次与最终static切换
owner: 浏览器CSS/Animation.finished = 真实过渡完成或取消

terminal事件 → running=false / 消息终态 / WorkingLine撤销 / RunTrace与用量出现
  → Markdown业务streaming=false、isAnimating=false（立即）
  → 仅视觉mode暂留同一Block树，停止给新文字排期
  → 查询真实reveal opacity与marker color过渡（包含delay阶段）
  → 无匹配过渡：直接static；有过渡：finished或cancelled后static
static → 原生整文解析与最终语义，reveal span回收
新流/非前缀替换/卸载 → 旧等待失效；不cancel仍在显示的过渡、不写业务位
```

1. 根节点用稳定ref包装，仅供收尾查询；保持正文布局与语义，继续复用默认Block与插件链。
2. streaming=false立即关闭isAnimating和新增reveal；保留视觉树只服务于已有动画。
3. 通过getAnimations({subtree:true})筛选本件data-reveal的opacity CSSTransition与
   data-reveal-marker的color过渡；不等工作行扫光、代码高亮或任意无限装饰动画。
4. Promise.allSettled(animation.finished)覆盖自然完成和取消；没有固定550ms延时，
   不用计时猜测浏览器是否结束。effect cleanup只撤销本代回调，不强制取消动画。
5. 无过渡、reduced-motion实际取消过渡、页面hidden时直接static；visibilitychange变hidden
   也立即清理。重新开流和组件卸载不会被旧Promise回调切错mode。
6. 最终正文若是非前缀替换，立即按权威最终文本静态呈现；相同正文或末尾追加可保留节点。
   不保留第二份旧正文，不改变复制/搜索的数据。

## 4. 边界与真实的墙

- 不永久保留预览树：remend与终态字面/引用语义确实不同，必须最终调用static全文解析。
- 不延迟业务终态：运行位与输入权限是store合同，动画只影响Markdown局部资源回收。
- 工具封段将answer搬入process的另一父容器，不属于本次run终态保留；维持该过程父容器
  的实例需要单独调整回合装配，不能只在Markdown内声称解决。无user且以streaming为首项
  的兜底组也有根key变化边界。本批钉住常规有user回合，不把这些路径写成通过。
- 真失败移除占位时遵守权威消息删除，不保留被删除的幽灵正文。传入stopped相位的视觉
  回归不能替代真实abort链标签验收；本次读取还发现run.failed清stopping后HomeChat可能
  推done的既有状态问题，出处`stores/chat/events.ts:340-352`、`selectors.ts:21-22`，本批不改store。

## 5. 验收

- 真实Markdown在terminal提交后保留同一span，isAnimating=false；过渡完成后span回收。
- opacity与marker color完成/取消，无动画、已完成动画、reduced-motion及隐藏页均收口。
- 新流、相同组件内容替换、会话/组件卸载、StrictMode后旧等待不写新实例。
- 未闭合强调、行内code、链接、围栏及reference/footnote最终等同原生static输出。
- 真实TurnGroup纯文本、有过程以及done/stopped/failed相位交接，终态头立即出现、工作行
  立即消失；父消息根与旧正文span保留。业务失败删除正文照原合同。
- 生产浏览器观测terminal前后实际opacity与Animation身份，延迟阶段也不能漏收；jsdom
  只证明Promise/节点合同。最终跑完整lint/typecheck/build/npm test并同步事实文档。
