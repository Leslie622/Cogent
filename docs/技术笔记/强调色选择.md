# 强调色选择

Cogent 把拖拽中的 HSVA 留在 `ColorPicker` 面板内。换色相时，灰色显示值可能不变；
若每帧都从 HEX 反推 HSV，用户刚选的色相就会丢掉。HEX 输入和色板只替换 RGB，
保留 A；不完整输入留在输入框，失焦回到最后有效值。

`cogent-appearance` 的 `accent` 键存六位 RGB；有透明度时追加两位 Alpha。旧 Cogent
预设 ID 读档回到品牌蓝。共享外观投影覆盖 `--chrome-accent`；模式文字从中取不透明颜色，
避免文字因 Alpha 太低难以阅读。明暗不改色，默认档移除覆盖。
取色入口的色块也直接读取 `--chrome-accent`，让默认档随明暗主题变化，同时保留自选色的透明度。
入口由 PopoverTrigger 组合原生 Button outline 档，尺寸、边框和悬停沿用组件配方。
