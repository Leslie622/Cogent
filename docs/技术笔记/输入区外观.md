# 输入区外观

聊天输入卡与正文同为白色时，只有一条边框会让输入区看起来贴在页面上。
层次由前后关系与柔和浮层投影表达：灰色项目信息条在后、白色输入卡在前，
卡片投 `0 4px 12px rgba(0,0,0,0.05)`（2026-11-20 用户定调；更早是
"近处接触 + 大范围柔和"双层投影，后改 1px 黑色环形浅深同值，现回到
柔投影并分档）。投影走 globals.css 自建的 `shadow-composer` token
（shadcn 官方主题只有颜色与圆角 token，无阴影；Tailwind 内置 shadow
刻度明暗同值），浅深色各取原始值：深色同几何提黑 alpha 到 0.4，
浅色 0.05 投到深底上不可见。

Cogent 把输入卡皮肤放在 `components/ui/input-group.tsx` 的 `composer`
变体，页面只选择档位。普通表单继续使用默认变体，避免聊天样式扩散到
搜索和设置输入。聊天卡圆角比原生表单大两档（`rounded-2xl`，对齐 zcode
composer，经 twMerge 盖掉基类 `rounded-lg`）；外壳不裁切内容，附件与
工具菜单继续使用原有交互。

新聊天的信息条向下伸入卡片，卡片用自身不透明底色覆盖交叠部分。
深色卡面使用 `card` 令牌，比页面底色亮一档；投影仍为黑色，不能用
前景色反转成白色光晕。焦点轮廓由全应用规则维护，与常态投影分别
表达键盘落点和空间层次。发送钮禁用只影响按钮，不改变整卡明暗。

工具行的图标按钮需要由内外两层使用同一尺寸档位。InputGroupButton
只拼宽高类而不传递 `size` 时，底层 Button 的默认最小高度仍生效，
24px 宽的加号按钮会被撑到 32px 高。组合件把尺寸传给底层，加号入口
使用与发送按钮等高的 28px 正方形档位，图标保持居中。

## 同主题源码对照

- zcode `reference/zcode/packages/ui/src/v4/ConversationComposer.tsx:2974`
  的输入区容器在有 `contextHeader` 时组合 `rounded-2xl bg-surface shadow-xl/5`，
  表达信息头与输入面的整体层级。Cogent 保留信息条在后、输入卡在前的
  布局关系，同样采用 `rounded-2xl`，阴影自建为浅深分档的浮层投影
  token（`shadow-composer`），值集中在主题层、类集中在输入框变体。
- zcode `reference/zcode/packages/ui/src/components/ui/input-group.tsx:73`
  的图标按钮档位分别为 24px 和 28px。Cogent 使用同样的方形尺寸，
  并显式传递底层档位，适配自身 Button 的最小高度约束。

视觉参数的权威描述见 [UI布局](../UI布局.md)。
