## 1. 截图里的功能是什么

可称「右侧多标签工作区」（Side Pane / Tabbed Workspace）。标签是容器，文件、
差异审查、网页、终端和插件页面是不同内容。新标签页是宿主启动器，不必加载网页。
本次 ChatGPT、Zcode 截图证明交互形态，不证明闭源产品的进程或插件实现。

| 层 | 职责 | Cogent 可用的基础 |
| --- | --- | --- |
| 工作区壳 | 标签、新建、切换、关闭、排序、宽度、占满、来源隔离 | HomeMain 分栏；HomeTabs 尚为占位 |
| 内容视图 | 文件树、文件查看器、差异页、网页、终端 | ①②已有文件查看器与动作 |
| 桌面资源 | 文件句柄、网页实例、终端进程、登录态、释放 | FileService 与 Electron 壳；浏览器实例管理尚缺 |
| Agent 能力 | 页面感知、点击、截图、审批、取消 | pi 工具/MCP 装配；尚未接浏览器控制 |

普通浏览器解决用户浏览；browser-use 解决模型操作。两者可以共享网页实例，但
共享需要明确接线，安装一个同名库不会自动产生工作区、可见网页或人机接管。

## 4. Zcode 浏览器：实际是 webview + CDP

旧笔记将当前 Zcode 浏览器写成 WebContentsView，依据不足；本次按实际挂载链纠正。

```text
React 标签 → 稳定 <webview>
               ↕ main BrowserGuestManager（WebContents、owner、代次、CDP）
               ↕ Host BrowserControlMainBridge
               ↕ core browser-client + browser-use skill / node_repl-host
               ↕ 模型 JS 操作
```

- `packages/ui/src/browser-use/BrowserViewportSurface.tsx:150–167`：稳定 webview，
  `persist:zcode-embedded-browser`；正常切换不重建，异常才换 generation。
  `packages/ui/src/lib/workspaceSidePane.ts:599–618` 要求 browser/browser-use 持续挂载。
- `packages/desktop/src/main/index.ts:401–404,2471–2477`：renderer 上报 guest ID，main attach CDP；
  `main/browserView/browserGuestManager.ts:644–650,705–725,790`（同 desktop/src）验证
  webview、window/workspace/session owner 后才 attach。index/host 的旧注释不能覆盖实际链。
- `packages/desktop/src/host/browserControlMainBridge.ts:176–253`：请求携带身份、代次、
  requestId/controlScopeId；超时反向取消。已下发操作可能有副作用，不能假报未执行。
- `packages/desktop/src/main/browserView/browserGuestManager.ts:3359–3378,4331–4362`
  记录上游 Electron 41 的 guest/CDP 销毁问题与 detach ACK 顺序；不代表 Cogent 40.9.3 已复现。
- `packages/desktop/src/main/desktopWindowChrome.ts:700–760` 硬化 guest；
  `embeddedBrowserPermissionPolicy.ts:154–262`、`browser-local-preview/index.ts:100–104`
  （同 main）处理 origin 权限、设备与受管本地预览，后者禁直接 file:。

`apps/zcode-cli/packages/browser-use-plugin/package.json:5–6` 自述 skill/client runtime；
`src/browser-client.ts:1–19` 接 core 与 node_repl-host transport。
`apps/zcode-cli/packages/core/src/browser-client/index.ts:52–72` 安装 agent.browsers，
`runtime/helpers/runtime-tools.ts:256–262`（同 core/src）按 feature+控制口启用。
插件 `skills/control-browser/SKILL.md:40,86–94` 区分 iab/extension/cdp；模型新标签可见，
人类标签需 claim；`docs/workflow.md:40–71` 主循环为 DOM/ARIA snapshot→locator→action→
最小观测，视觉任务再截图。`packages/desktop/src/main/browserView/browserPlaywrightDomSnapshot.ts:257,397–410`
调用注入的 Playwright snapshot 并合并 iframe。这条 JS/Node 链不等于 Python 同名项目。

  `src/host/runtime/outputs/service.ts:245–269` 区分 source-only 当前原件与真实副本，
  并为同发布清单依赖生成自己的交付 target。去重按实际类别，恢复保存稳定来源，不存父 fileId。
- `src/electron/main/webview-policy.ts:15–49` 只准 demo 并强制 guest preload；
  `src/electron/preload/guest.ts:17–22` 安装 SDK；`src/electron/main/ipc/guest.ts:15–26`
  只凭 webview 类型签 write 票据。browser guest 必须与可信 app guest 分开，并收紧凭据身份
  校验，不能只扩 URL 白名单。

  HomeMain 卸载清理，局部标签保留不冒充完成该独立方案。

## 9. 能否直接抄

可以局部移植，不把「不抄外部视觉细节」外推成禁止代码复用。纯状态操作、去重、相邻
选择、关闭竞态值得提取；完整 useAppPanels/PreviewPane/browserGuestManager 依赖上游
会话、远程、插件与恢复协议，整块复制意味着一同接管大量依赖。

按具体文件授权核实：Zcode `NOTICE.md:71–73`、`LICENSE:90–122` 规定第一方 Apache-2.0，
保留许可/归属/适用 NOTICE 并标记修改；browser-use-plugin 的 `package.json:6` 单列 MIT。
`THIRD-PARTY-NOTICES.md:3–5` 说明第三方另适条款；Harness 根 `LICENSE:1–16` 为 MIT。
不能说 Zcode 全家桶 Apache，也不从根许可推出所有字体/图标/二进制均可同样复制。
本轮只研究，未移植代码。

### 为什么不直接照搬手写树

Zcode `packages/ui/src/workspace-file-tree/model.ts:383–461` 自写展开后的扁平行，
`useWorkspaceFileTreeData.ts:80–86`（同目录）自持 children/expanded/loading/error；
`WorkspaceFileTree.tsx:471–495,566–582` 自接展开/键盘，
`WorkspaceFileTreeRowView.tsx:242–262` 直接画 role=treeitem/aria-expanded。
其虚拟化来自 `WorkspaceFileTree.tsx:22,195–200` 的 TanStack，不是完整 Tree 库。
本项目可以取业务边界，通用树行为交给成熟库。

Headless Tree [虚拟化](https://headless-tree.lukasbach.com/recipe/virtualization)、
[状态](https://headless-tree.lukasbach.com/guides/state)、
[可访问性](https://headless-tree.lukasbach.com/guides/accessibility) 分别说明扁平 items、
外部控制与键盘/ARIA；100k 示例不证明真实磁盘/IPC/搜索达到同样性能。

### 分页必须自己拥有，不能误用异步 loader

[core 1.8.0 发布源码](https://registry.npmjs.org/@headless-tree/core/-/core-1.8.0.tgz) 中：
`src/features/sync-data-loader/types.ts:1–10` 返回整组子项；
`src/features/async-data-loader/feature.ts:68–86` 将结果整组写 childrenIds；
同目录 `types.ts:22–43` 没有 cursor/AbortSignal/目录错误合同。
`feature.ts:46–94` 的失败路径也不能替代本项目显式错误/重试状态。

因此采用 Cogent DirectoryOwner 做异步数据权威，syncDataLoaderFeature 只读快照。
分页用独立 kind 的“加载更多/重试”合成行，不伪造文件；getter 不发请求。
[外部数据更新](https://headless-tree.lukasbach.com/recipe/external-state-updates) 要求重建看到新快照，
适配 scheduleRebuildTree 时序，不能 setState 后立刻以旧闭包重建。
排序/目录完整性同样是 Host 合同，虚拟化不保证先到的一页就是全目录前200项。

[searchFeature](https://headless-tree.lukasbach.com/features/search) 是 typeahead，不扫描未加载目录。
Zcode `packages/ui/src/workspace-file-tree/useWorkspaceFileSearchIndex.ts:35–40,59–118`
下载/解包再交 worker；`packages/services/src/file/file.ts:21–24,45–62` 另有有界搜索与全索引分片。
Cogent 选有界 Host 搜索+结果页，不先把全索引灌入 renderer。

### 标签库细节

本仓 `src/renderer/src/components/ui/tabs.tsx:1,73–81` 是 Base UI，透传 Panel props；
[Base UI Tabs](https://base-ui.com/react/components/tabs) 用 keepMounted/data-hidden，
不能照搬 Zcode 的 Radix forceMount。关闭按钮和 sortable 属性不得破坏 role/tabIndex。
[旧版 sortable](https://docs.dndkit.com/presets/sortable) 有横向策略/DragOverlay/KeyboardSensor；
