# 统一字号

界面维护少量公共层级，比每个控件各设像素更容易支持用户调整。Cogent 复用 Nova 的
Tailwind 标准字号类，将变量集中于 `globals.css`，具体数值的权威表见 [UI布局](../UI布局.md)。
偏好链路与持久化边界见 [设置页](../模块/设置页.md)。

## 两仓对照

- ZCode 的 `reference/zcode/packages/ui/src/lib/uiFontSize.ts:20` 只更新独立
  `--ui-font-size`，避免缩放 rem 间距；`:29` 监听 storage，同源独立窗口同步。
  `reference/zcode/packages/ui/src/styles.css:182` 另定义 `text-ui-*` 阶。
  Cogent 沿用独立基准与同源重读，但直接绑定标准 `--text-*`，不新增类命名；本项目的
  `cn@0.5.2` 默认会把 `text-ui-*` 当颜色，标准字号类没有这项兼容问题。
- ZCode `reference/zcode/packages/ui/src/components/ai-elements/message.tsx:2003`
  把正文也放在界面阶上。Cogent 用 `.content-typography`/`.md-body` 恢复内容阶，
  隔离气泡、草稿、思考与 Markdown；代码工具栏恢复界面变量，正文主题不串入按钮。
- DeepSeek Harness 的
  `reference/deepseek-harness/packages/client/ui-theme/src/theme-settings.ts:57`
  拆 text/code/terminal 配置；
  `reference/deepseek-harness/packages/client/ui-layout/src/client/theme-presenter.ts:77`
  将它们写为 body 变量。Cogent 将代码统一到一个数值，同时保留聊天主题档，避免工具输出
  与控制台留下隐藏的独立字号；没有终端消费者，因此不引入终端字号设置。
- `reference/zcode/packages/ui/src/command-center/CommandCenterDialog.tsx:373` 的裁字
  修法使用最小高度。Cogent 的文字按钮、徽标、输入、Select 同样允许被真实行高撑开，
  固定图标按钮尺寸继续作为图形几何，不随根 font-size 放大。
  头部文字入口用 Button 的 header 档：保留紧凑内距，字号继承正文阶；不复用带小字的
  sm 档，避免把几何尺寸相近误当成文字层级相同。浏览器分栏回归检查头部11/14/16px。

## 所有权与验证

```text
appearance store（校验持久化旧值）
  → bindAppearanceDom（所有窗口首帧 + store订阅）
  → 文档根界面/代码变量 → 标准阶与代码正文
其他同源窗口存储事件 → rehydrate → 同一投影
聊天主题 + 用户代码覆盖 → 编译 → 消息流变量 → Markdown
```

`@theme` 字号段不使用 inline 展开，使公共工具类保留 `var(--text-*)` 间接层；
内容根重新绑定局部阶时无需改第三方 Streamdown 源码。代码查看器不再固定13px，
CSS变量变化不重建 EditorView，原文与编辑器使用同一个消费类。

`scripts/check-typography.mjs` 使用 TypeScript 语法树检查字面量、模板、内联样式及
直接 DOM 写入，再扫描自有 CSS；`npm run lint` 与 CI 共用。图形首字的字号计算只在
ProviderLogo 的具体表达式例外，CSS字号限于集中声明和已有消费表达式，不豁免整片目录。
静态门禁不能判断某段文字该用哪一档，真实布局仍需浏览器验收。

自动回归覆盖端点、非法/旧持久值、同源事件和清覆盖；真实浏览器入口为
`tests/renderer/features/settings/typography.browser.html`，检查四阶、内容隔离、三类代码
正文、控件内部高度、原文切换及同源 iframe 同步。iframe 提供浏览器存储事件证据，
不等同打包 Electron 两个 BrowserWindow 的人工验收，后者步骤见 [设置页手测](../测试用例/设置页.md)。
