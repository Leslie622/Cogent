# 对话显示偏好

> 学习主题：把显示密度与时长精度留在呈现层，保留原始记录供不同显示档消费。
> 当前设置、消息行为与验收分别见[设置页](../模块/设置页.md)和
> [消息呈现](../模块/消息呈现.md)。

## 显示偏好与数据所有权

工具记录提供参数摘要、结果和 diff，耗时保持毫秒。切换显示密度时若改写消息或
工具记录，切回详细就需要再次加载历史，也会把呈现选择混进运行状态。
因此偏好由 renderer 的 appearance store 持有，组件在最后消费处选择显示范围。
工具状态和身份仍能表达当前动作，具体内容只在详细档挂载。
思考使用同样的呈现边界：简洁档保留状态与耗时，但不挂摘要、全文或展开入口；
用量统计则整行不渲染。切回详细时原始思考与计费事实仍在，无需重跑或重新计账。

```text
owner: appearance store（持久偏好），chat store（原始消息与工具记录）
设置 Select → appearance setter → 本地持久化 + 组件订阅更新
工具 / 思考 / 用量事件及历史回查 → chat store → 各消费组件按偏好呈现
毫秒事实 + 秒位精度 → formatDuration → 码表 / 头条 / 思考 / 统计行
```

把精度作为纯格式化函数的显式参数，使不同位置共享同一套单位与进位规则；
组件订阅偏好，函数本身不读取 store。整数刻度下计时源仍保留毫秒，切回小数档
无需重置时钟，也不影响原有模型 / 工具耗时聚合。

## 参照源码对照

- pi：`reference/pi/packages/coding-agent/src/modes/interactive/components/tool-execution.ts:47`
  持有局部 expanded；`:150-169` 的 fallback 输出在收起时仍预览前几行，展开可读
  完整结果。这说明展开选择可以属于呈现件，但收起不等于隐藏具体内容。
  Cogent 的简洁档直接不挂具体内容，与详细档的局部开合正交。
- zcode：`reference/zcode/packages/ui/src/ToolCallBlocks/ToolLayout.tsx:111-137`
  分别计算展开状态、内容挂载、摘要主文案和 diff 计数。Cogent 复用同样的职责区分，
  用一个显示档同时控制这几个消费点，避免只藏折叠体却泄露参数或尾行。
- zcode：`reference/zcode/packages/ui/src/v4/conversationWorkDuration.ts:24-39`
  从毫秒舍入到整秒，拆天 / 时 / 分 / 秒，再取最多两个单位。Cogent 只使用需求中的
  秒、分秒、小时分三种形态，秒位独立精度；小时档直接省略秒，精度不会改变小时分。

这些对照限定在上述实读函数，未据此推断参照项目是否具备全局详细程度或精度设置。

## 验证边界

格式化单测覆盖亚秒、三档精度、分钟与小时进位，以及小时档不受秒位精度影响。
组件回归覆盖真实下拉选择、重读偏好、旧档默认值、即时更新、工具 / 思考详情移除
与单条 / 回合统计整行隐藏；
码表用受控时间验证精度切换不改变起点。桌面重启、真实长回合和窄窗观感按
[设置页测试用例](../测试用例/设置页.md)在应用中检查。
