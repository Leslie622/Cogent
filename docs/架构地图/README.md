# Cogent 项目地图

交互式目标与现状架构图。以同一 LikeC4 模型（结构 + 专题流程）驱动 5 张架构视图与 9 张专题流程图，节点标明能力完成度，点击连线可查看边界契约。
按源码查当前调用关系和进程边界，见[当前架构](../架构.md)。按任务查代码与测试，见[模块索引](../模块/索引.md#按任务追链)。

## 视图与交互

- **架构地图**：`架构总览`（引擎为主干）、可下钻的 `桌面壳内部` / `Host 服务层` / `执行能力`，以及 `数据与存储`（`COGENT_HOME` 单写者归属，含 `attachments/v1/` 与派生搜索库）。
- **专题流程**：`身份验证与权限`、`消息与审批闭环`、`MCP 双轨机制`、`技能加载机制`、`钩子与扩展机制`、`上下文工程与压缩转录`、`文件边界与产物交付`、`凭据与模型出站`、`提示词工程与装配`。
- **筛选与溯源**：顶部支持 `全部 / 仅已实现 / 高亮缺口` 切换（`仅已实现` 隐藏未实现规划项）；点击节点或连线可在右栏查看职责、突出技术边界、核验日期，点击来源卡片直接复制仓库路径，并支持 `#view=` 定位。

布局与状态规则见[架构地图模块](../模块/架构地图.md)，流程图绘制与审查规范见[流程图指南](流程图指南.md)，选型与对照见[技术笔记](../技术笔记/架构地图.md)。

## 本地运行与构建

独立自包含静态项目，首次只需安装本目录依赖（无需安装根项目或主应用 UI 依赖）：

```powershell
npm --prefix docs/架构地图 ci
npm --prefix docs/架构地图 run dev
```

生成可离线双击打开的单文件页面（产物 [dist/index.html](dist/index.html) 约 1 MB，不入库）：

```powershell
npm --prefix docs/架构地图 run build
```

## 检查命令

本项目参与[根目录与 CI 检查](../模块/测试.md)：

```powershell
npm --prefix docs/架构地图 run typecheck
npm --prefix docs/架构地图 test
npm --prefix docs/架构地图 run test:browser
```

浏览器验收默认使用本机 Chrome，可通过 `COGENT_BROWSER_CHANNEL=msedge` 切换 Edge，截图写入 `tmp/架构地图验收/`。
