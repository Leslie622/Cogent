# 决定 — 容易误改的取舍

保留稳定编号和容易重犯的替代方案。当前行为及验收查链接，原理和源码对照查技术笔记。

1. **模型显示真实 API id**，原生模型 id 只读。营销名称不替代 API id。[凭据与模型目录](模块/凭据与模型目录.md)
2. **设置页可按 Provider 完整回显密钥**。默认遮蔽，用户可查看明文，引擎协议只回有无。[凭据与模型目录](模块/凭据与模型目录.md)
3. **压缩保留历史**。轮内压缩进原过程，轮外独立呈现，压缩条不截断回合。[消息呈现](模块/消息呈现.md)
4. **目录约束决定写审批规则的适用范围**。允许越界写的单次裁决，工作区规则只在根内生效，执行类按权限档查规则或询问。[审批与权限](模块/审批与权限.md)
5. **权限通告更新具名提示词节**。不向转录插临时 system 消息，不依赖 reload 求值。[审批与权限](模块/审批与权限.md)
6. **用户动作才创建会话**。空列表和全归档展示新聊天，启动时不补建会话。[会话与对话](模块/会话与对话.md)
7. **沿用 pi 的 fd/rg 获取和降级链**。Cogent 不另写 glob/grep。[工具系统](模块/工具系统.md)
8. **区分已知价格和估价**。同 id 覆盖继承目录价格，未知价格显示 0，估价带 `≈`。[用量与成本](模块/用量与成本.md)
9. **保留截断和流错误前的转录**。后续可读到半截内容，终态仍保留实际结果。复现脚本故障单独归因。[会话与对话](模块/会话与对话.md)
10. **store 保留平铺消息**。回合分组与两态由渲染层派生。[消息呈现](模块/消息呈现.md)
11. **项目只支持本地**。云端与远程保留禁选，删项目不级联删除会话。[工作区与项目](模块/工作区与项目.md)
12. **文字使用实色 token**。透明度配方用于背景和 hover，避免文字栅格发糊。[UI 布局](UI布局.md#颜色字体与空间)
13. **「允许，并切换为」同时持久化项目默认**。允许本次并切当前档，收紧经独立菜单。[审批与权限](模块/审批与权限.md)
14. **计划是正交开关**。批准只关开关，计划约束优先。第四档权限、回退字段 `prePlanMode` 和模型免审自退均被否。[交互座](模块/交互座.md)
15. **运行中保持过程单行和底部工作行**。终态才挂工作头，首个终答片段不触发折叠。[消息呈现](模块/消息呈现.md)
16. **Trace 收起保持挂载**。用 `keepMounted` 和 `hidden` 保留 Markdown、Shiki 与工具树，立即或延迟卸载均被否。[思考流式呈现](技术笔记/思考流式呈现.md)
17. **折叠轨道和内距一起归零**。使用 `minmax(0, 0fr ↔ 1fr)` 和同步 padding，裸 `fr`、静态内距及取消动画均被否。[机制](技术笔记/思考流式呈现.md) · [回归](../tests/renderer/components/ui/trace.render.test.tsx)
18. **Trace 与头条同级左缘**。移除 `border-l` 导线、额外缩进及常驻分隔线。[消息呈现](模块/消息呈现.md)
19. **Themd 提供完整内容样式合同**。缺值回落基准，宿主适配 Streamdown，用户覆盖最终生效。仅迁移稀疏差值的方案被否。[对话内容主题](技术笔记/对话内容主题.md)
20. **吸底由一个控制器负责**。恢复跟随只认用户向底意图，工作行只有一份 DOM。布局滚动、残差平移与第二个 pin 均被否。[机制](模块/消息呈现.md) · [验证](技术笔记/流式呈现动效.md)

## 架构级取舍

第 21–37 条原为全局架构的 D1–D17，依序对应。

21. **main 只做壳，Host 是独立 Node 子进程**。不把 pi 放进 Electron main。[架构](架构.md)
22. **stdio 与 HTTP/WS 共用注册表**。WS 承载请求和事件，POST 便于脚本；默认 loopback，放开监听必须显式配置。[HTTP通道](模块/HTTP通道.md)
23. **main 经 stdio 发起票据签发，Host 存证和兑换**。根 secret 不出 Host、不持久化；readonly ⊂ write ⊂ admin，Host 重启旧 token 全失效；session 绑定 scope 尚未实现。[HTTP通道](模块/HTTP通道.md)
24. 目标是 **Host 服务层只依赖 CogentKernel 窄合同**。排除 waterfall 全量合同与 replay 确定性承诺。[内核合同](技术笔记/内核合同.md) · [当前依赖](架构.md#进程与依赖边界)
25. **只维护 PiSdkKernel**。PiRpcKernel 留作崩溃隔离/独立版本的接口位，DeepAgent 仅作合同反向校验，不维护第二实现。[内核合同](技术笔记/内核合同.md)
26. **pi 托管循环、工具、压缩、Provider 与 JSONL 树**。Host 保存业务摘要、权限与观测，不再写一套内核。[pi接入与会话托管](技术笔记/pi接入与会话托管.md)
27. **能力装配复用 pi 扩展缝，MCP 连接归 Host 统一池**。customTools、InlineExtension、skillsOverride 保持；MCP 由 `McpRuntimeManager` 复用 pi-mcp 客户端/传输/OAuth，`createCogentMcpExtension` 与 `createToolSearchExtension` 桥接会话，不再按会话另建连接。每座齐备接口/实现/消费三角色。[MCP座](模块/MCP座.md) · [钩子座](模块/钩子座.md)
28. **beforeToolCall 链式包裹保留 abort signal**。主界面审批经专属 IPC 回填；内置工具用 ToolKind 静态表，MCP 用已受信且启用服务的运行时 annotations 分类，分类不建立配置或工具信任；嵌套调用仍过同一审批链。[审批与权限](模块/审批与权限.md)
29. **对外 MCP 是独立 stdio 入口，连接正在运行的 Host**。默认关闭，写组按凭据 scope 显式开放，不创建第二引擎。[对外MCP](模块/对外MCP.md)
30. **第三方页面以 webview 沙箱 + window.cogentHost 小 SDK 接入**。不暴露宿主完整 IPC；MCP Apps 仍是互操作预留。[内嵌页面](模块/内嵌页面.md)
31. **构建期下载官方 Node 22 并核验 SHA256**。只必带 Node，git/python 走系统与将来可选下载器。[Node运行时分发](技术笔记/Node运行时分发.md)
32. **当前安全边界是三档权限 + 正交计划开关 + 审批矩阵**。bash 只读分类尚未做，OS 沙箱留后续独立评估。[审批与权限](模块/审批与权限.md)
33. **inspect + 独立运行时控制台是调试面**。改为内嵌消费者与网络抓包均未立项，不因此重做观测系统。[运行时控制台](模块/运行时控制台.md)
34. **Electron 固定 40.9.3**。Chromium 144 原生支持 Tailwind v4，不设旧 Chromium CSS 兼容专项；多平台实机验证仍须单列证据。[平台边界](计划/全局架构.md#2-平台边界与理由)
35. **HTTP chat 门面已定方向、未立项**。与既有云端 chat 接口同构，调用方改 baseURL 即可切换；HTTP+SSE 适配 HostApi，审批须有推送与回答往返；不等于现有 POST /rpc。[待排队列](计划/全局架构.md#5-路线与未完成队列)
36. **拨出中继已定方向、未立项**。本地 WS 主动连云端穿 NAT；数据经云端改变信任边界，立项时单独决策。[待排队列](计划/全局架构.md#5-路线与未完成队列)
37. **插件是 skills/MCP 等能力的本地分发单位**。首发包管理、版本缓存、开关与作用域；agents 待子会话座，UI surfaces 待真实消费者；云端市场因需服务端不首发。[插件座实现](计划/插件座实现.md)
38. **附件读取不委托 MCP，提示词只写事实**。`read_attachment` 只做本地文字提取；图片、音视频、扫描页由模型对着工具目录自选工具，品类与工具的对应不写进提示词；视觉后端（指定模型转录）另立项。[图片与文件附件](模块/图片与文件附件.md) · [方案](计划/附件读取与MCP解耦实现.md)
