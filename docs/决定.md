# 决定 — 有意偏离与被否方案

本文只索引后来者容易顺手改错的取舍，编号保持稳定。当前机制看各条链接，
原理与源码对比看技术笔记；已完成过程留在 Git，不另保留计划归档。

1. **显示模型 id**：聊天与设置显示真实 API id，原生目录模型编辑时 id 只读。
   被否：以营销显示名替换。见[凭据与模型目录](模块/凭据与模型目录.md)。
2. **API key 可完整回显**：设置页默认密文态，可点眼睛查看；壳侧按 Provider
   单取明文。被否：只存末四位或掩码回显。引擎协议仍不回明文，见[凭据模块](模块/凭据与模型目录.md)。
3. **压缩保留历史与两形条**：轮内自动压缩进原回合过程，回合外压缩独立可见。
   被否：删被摘要历史、让 bar 截断回合、把手动压缩藏入工作头。见[消息呈现](模块/消息呈现.md)。
4. **读取不限工作区，写边界决定规则适用域**：ask 越界写可人工允许，但不能吃
   根内“始终允许”；auto 放行，自主模式只对 write/edit 直放行，exec 仍查规则或询问。
   被否：把根内规则扩大到越界写。见[审批与权限](模块/审批与权限.md)。
5. **权限通告用结构化系统提示词节**：before_agent_start 更新具名 section，
   变更回放按名替换。被否：往转录塞临时 system 消息、依赖 reload 才求值的
   systemPromptOverride。见[审批与权限](模块/审批与权限.md)。
6. **会话随用户动作物化**：空列表/全归档是新聊天着陆页，不自动创建会话。
   被否：启动补建导致归档幽灵复活。见[会话与对话](模块/会话与对话.md)。
7. **接受 pi 的 fd/rg 依赖**：PATH、上游自动下载、失败可诊断；内网分发预置待排。
   被否：在 Cogent 重写一套 glob/grep。见[工具系统](模块/工具系统.md)。
8. **成本口径诚实**：目录快照按既定汇率换算，估价带≈；全新模型无价格时为0，
   同id覆盖继承目录价格，不编造价格。见[用量与成本](模块/用量与成本.md)。
9. **保留截断/流错误的半截转录**：后续请求可以读到，不能吞成正常完成。
   复现脚本错误不能推断成引擎吞回复。见[会话与对话](模块/会话与对话.md)。
10. **store 消息平铺**：回合分组与两态由渲染层派生，store 不再存另一份分组。
    见[消息呈现](模块/消息呈现.md)。
11. **项目类型仅本地**：云端/远程置灰是既定范围；删项目不级联删会话。
    被否：把禁选项当未完成 TODO 解锁。见[工作区与项目](模块/工作区与项目.md)。
12. **文字色使用实色 token**：避免透明文字在 Chromium 光栅化中发糊；
    透明度只用于背景/hover。见[UI布局](UI布局.md)。
13. **审批“允许，并切换为”写项目默认**：允许本次、切当前权限、记项目默认；
    收紧权限走独立菜单。被否：仅在暂存位切档不持久化。见[审批与权限](模块/审批与权限.md)。
14. **计划是正交开关**：planEnabled 不覆盖三档权限，批准只关开关，约束优先于
    档位放行。被否：第四档 plan、prePlanMode 回退字段、模型免审自退。
    见[交互座](模块/交互座.md)与[审批与权限](模块/审批与权限.md)。
15. **live 过程结构恒定**：过程单行、底部工作行，终态才出现工作头。
    被否：终答开流即折叠、工作中行锚回合顶部；不得因换图标动效恢复流中结构翻转。
    见[消息呈现](模块/消息呈现.md)。
16. **Trace 收起不卸载**：keepMounted + hidden 避免每次点击重挂 Markdown、
    Shiki 和工具树。被否：立即卸载或为本轨道加延迟卸载。见[思考流式呈现](技术笔记/思考流式呈现.md)。
17. **折叠轨道与 padding 同步归零**：minmax(0,0fr↔1fr)，内层纵向 padding
    随开合过渡。被否：裸 fr 的自动最小尺寸、静态 padding 尾段地板、取消动画来掩盖问题。
    证据与原因见[思考流式呈现](技术笔记/思考流式呈现.md)，回归见 tests/renderer/components/ui/trace.render.test.tsx。
18. **Trace 平级无导线**：折叠体与头条同级左缘 0。
    被否：border-l 导线缩进。头条下曾挂常驻分割线（折叠机构外），
    2026-11-20 用户定调取消。见[消息呈现](模块/消息呈现.md)。
19. **对话内容主题包含 Themd 基础样式合同**：空缺令牌回落本地 Themd 基准，
    Streamdown 结构由宿主显式适配；默认主题保留聊天密度，用户覆盖最终优先。
    被否：只迁移稀疏差异、让空缺项静默采用 Streamdown 排版，或由主题覆盖用户设置。
    见[对话内容主题](技术笔记/对话内容主题.md)。
20. **吸底只有一个 owner**：关闭库 autoScroll，本地 controller 用真实尺寸RO
    贴底；上滚先交出控制，恢复跟随须用户向底意图，布局/程序scroll不能冒充。
    工作行只有一份DOM，reading归流；不得以几何归零为由添加残差平移或第二个pin。
    证伪与像素边界见[流式呈现动效](技术笔记/流式呈现动效.md)，合同见[消息呈现](模块/消息呈现.md)。
