# 决定 — 有意偏离与被否方案（防回潮索引）

> 每条一句话决定 + 警句 + home（正文所在）。只收「后来者容易顺手改错」的
> 跨模块决定；常规决策随 计划/ 留档。新增决定追加到末尾，编号递增。

1. **显示一律模型 id** —— 聊天菜单/设置页一律显示 API id（deepseek-v4-pro），
   不显示目录营销名；默认（目录原生）模型编辑时 id 只读。勿"统一修回显示名"，
   所见即所传（2026-11-10 定调）。home：模块/凭据与模型目录.md
2. **API key 字段全量回显** —— 掩码/末四位脱敏被否（"输进去就没了"）；
   明文默认密文态、点眼睛查看。勿"顺手加掩码"。home：模块/凭据与模型目录.md
3. **压缩呈现保留式 + 两形条** —— 销毁式（摘要区原位换折叠条、删历史）、
   "bar 自成组截断回合"（一回合多条 bar 切出多个「已工作」头）、"手动压缩
   也塞进已工作折叠体"三案均被否决；现行 = **轮间自动压缩**行内
   插在回合过程流（一问恒一头）、**回合外压缩**（手动/idle）独立成行直接
   可见（判据：bar 后直到下一 user 有无工作项）；被摘要历史保留不删。
   勿"顺手删历史省内存"、勿"让 bar 切开回合"、勿"把手动压缩藏进回合"。
   home：模块/上下文压缩.md、模块/消息呈现.md
4. **只读不限界；写的限界只管「规则适用域」**（zcode 对齐）——
   read/find/grep 可读工作区外；写的根内判定只决定 ask 能否吃「始终允许」
   规则：**auto/autonomous 完全放行（含越界写，主流同款）、ask 越界写照常
   弹面板可手许（人是最终裁决者）、规则永不覆盖越界**。
   home：模块/审批与权限.md
5. **权限通告走 before_agent_start sections** —— 经内联扩展设
   `cogent_permission` 节（pi 变更才追加 patch、回放按名替换，切换不堆积）。
   勿"往消息流塞 system 通告"（pi 会话树 append-only，塞了不落树）或改用
   systemPromptOverride 拼段（loader 只在 reload 时求值，运行中切不动）。
   home：模块/审批与权限.md
6. **会话只随用户动作物化** —— 不自动建会话；空列表/全归档 = "新聊天"着陆页。
   自动建曾产生归档幽灵会话（重启复活）。home：模块/会话与对话.md
7. **接受 pi 的 fd/rg 外部依赖** —— find/grep 即 fd/rg（PATH → 自动下载 →
   error 降级），全内网不可达时靠分发期预置（远期批次）。
   勿"重搓 node 版 glob/grep"。home：模块/工具系统.md
8. **成本诚实** —— 目录快照 = 官方高峰价 ÷ 6.8，估价带 ≈；全新模型 id 成本
   诚实 0（同 id 覆盖永远继承目录定价）。勿拍脑袋补价。home：模块/用量与成本.md
9. **半截文本留存转录** —— 截断/流错误按 pi 语义留存（后续请求可见），
   不吞成 completed；曾误判"吞回复"，实为复现脚本缺陷。home：模块/会话与对话.md
10. **消息流 store 平铺** —— 分组/两态是渲染期计算（TurnGroup），store 不存
    分组结构。勿"在 store 里加分组状态"。home：模块/消息呈现.md
11. **项目类型只做本地** —— 云端/远程置灰禁选是**终态**不是 TODO。勿"解锁"。
    删除项目不级联删会话（悬挂保留是有意的）。home：模块/工作区与项目.md
12. **文字色一律实色 token** —— 禁 `text-x/75` 透明度文字色（Chromium 降级
    光栅化发糊）；层级靠实色深浅。透明度只许背景/hover。home：UI布局.md
13. **「允许，并切换为」落项目默认**（zcode 对齐）—— 审批面板第 3 项 =
    允许本次 + 切会话模式 + 记为项目默认（同项目新会话沿用）；只列两档
    放宽（自主/完全访问），切回收紧走权限菜单。"暂存位不持久化（防忘了
    关）"的顾虑由项目级落位 + 权限菜单可见兜住。
    home：模块/审批与权限.md
