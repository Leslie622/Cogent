# 决定 — 有意偏离与被否方案（防回潮索引）

> 每条一句话决定 + 警句 + home（正文所在）。只收「后来者容易顺手改错」的
> 跨模块决定；常规决策随 计划/ 留档。新增决定追加到末尾，编号递增。

1. **显示一律模型 id** —— 聊天菜单/设置页一律显示 API id（deepseek-v4-pro），
   不显示目录营销名；默认（目录原生）模型编辑时 id 只读。勿"统一修回显示名"，
   所见即所传（2026-11-10 定调）。home：模块/凭据与模型目录.md
2. **API key 字段全量回显** —— 掩码/末四位脱敏被否（"输进去就没了"）；
   明文默认密文态、点眼睛查看。勿"顺手加掩码"。home：模块/凭据与模型目录.md
3. **压缩呈现保留式** —— 销毁式（摘要区原位换折叠条、删历史）被 GUI 验收
   否决；压缩条原位中插、被摘要历史保留不删、重拉历史不消失。勿"顺手删
   历史省内存"。home：模块/上下文压缩.md
4. **只读工具不限界** —— read/glob/grep 可读工作区外（绝对路径）；
   "全工具限界 + 无根零工具"案被驳回。写类才设软限界闸。home：模块/工具系统.md
5. **权限通告走 transcript** —— mode 语义变化用单条 system 消息（替换式），
   不进 buildSystemPrompt（leading 固化后运行中切不动）。home：模块/审批与权限.md
6. **会话只随用户动作物化** —— 不自动建会话；空列表/全归档 = "新聊天"着陆页。
   自动建曾产生归档幽灵会话（重启复活）。home：模块/会话与对话.md
7. **bash 平台路由不引外部依赖** —— Windows=PowerShell（系统必有）、
   unix=bash；不学上游引 fd 等外部命令。home：模块/工具系统.md
8. **成本诚实** —— 目录快照 = 官方高峰价 ÷ 6.8，估价带 ≈；全新模型 id 成本
   诚实 0（同 id 覆盖永远继承目录定价）。勿拍脑袋补价。home：模块/用量与成本.md
9. **半截文本留存转录** —— 截断/流错误按 pi 语义留存（后续请求可见），
   不吞成 completed；曾误判"吞回复"，实为复现脚本缺陷。home：模块/会话与对话.md
10. **消息流 store 平铺** —— 分组/两态是渲染期计算（TurnGroup），store 不存
    分组结构。勿"在 store 里加分组状态"。home：模块/消息呈现.md
11. **项目类型只做本地** —— 云端/远程置灰禁选是**终态**不是 TODO。勿"解锁"。
    删除项目不级联删会话（悬挂保留是有意的）。home：模块/工作区与项目.md
12. **文字色一律实色 token** —— 禁 `text-x/75` 透明度文字色（Chromium 降级
    光栅化发糊）；层级靠实色深浅。透明度只许背景/hover。home：UI布局.md
