# 决定 — 有意偏离与被否方案（防回潮索引）

> 每条一句话决定 + 警句 + home（正文所在）。只收「后来者容易顺手改错」的
> 跨模块决定；常规决策随 计划/ 留档。新增决定追加到末尾，编号递增。

1. **显示一律模型 id** —— 聊天菜单/设置页一律显示 API id（deepseek-v4-pro），
   不显示目录营销名；默认（目录原生）模型编辑时 id 只读。勿"统一修回显示名"，
   所见即所传（2026-11-10 定调）。home：模块/凭据与模型目录.md
2. **API key 字段全量回显** —— 掩码/末四位脱敏被否（"输进去就没了"）；
   明文默认密文态、点眼睛查看。勿"顺手加掩码"。home：模块/凭据与模型目录.md
3. **压缩呈现保留式 + 两形条** —— 销毁式（摘要区原位换折叠条、删历史）、
   "bar 自成组截断回合"（一回合多条 bar 切出多个「已工作」头）、"手动压缩
   也塞进已工作折叠体"三案均被否决；现行 = **轮间自动压缩**行内
   插在回合过程流（一问恒一头）、**回合外压缩**（手动/idle）独立成行直接
   可见（判据：bar 后直到下一 user 有无工作项）；被摘要历史保留不删。
   勿"顺手删历史省内存"、勿"让 bar 切开回合"、勿"把手动压缩藏进回合"。
   home：模块/上下文压缩.md、模块/消息呈现.md
4. **只读不限界；写的限界只管「规则适用域」**（zcode 对齐）——
   read/find/grep 可读工作区外；写的根内判定只决定 ask 能否吃「始终允许」
   规则：**auto/autonomous 完全放行（含越界写，主流同款）、ask 越界写照常
   弹面板可手许（人是最终裁决者）、规则永不覆盖越界**。
   home：模块/审批与权限.md
5. **权限通告走 before_agent_start sections** —— 经内联扩展设
   `cogent_permission` 节（pi 变更才追加 patch、回放按名替换，切换不堆积）。
   勿"往消息流塞 system 通告"（pi 会话树 append-only，塞了不落树）或改用
   systemPromptOverride 拼段（loader 只在 reload 时求值，运行中切不动）。
   home：模块/审批与权限.md
6. **会话只随用户动作物化** —— 不自动建会话；空列表/全归档 = "新聊天"着陆页。
   自动建曾产生归档幽灵会话（重启复活）。home：模块/会话与对话.md
7. **接受 pi 的 fd/rg 外部依赖** —— find/grep 即 fd/rg（PATH → 自动下载 →
   error 降级），全内网不可达时靠分发期预置（远期批次）。
   勿"重搓 node 版 glob/grep"。home：模块/工具系统.md
8. **成本诚实** —— 目录快照 = 官方高峰价 ÷ 6.8，估价带 ≈；全新模型 id 成本
   诚实 0（同 id 覆盖永远继承目录定价）。勿拍脑袋补价。home：模块/用量与成本.md
9. **半截文本留存转录** —— 截断/流错误按 pi 语义留存（后续请求可见），
   不吞成 completed；曾误判"吞回复"，实为复现脚本缺陷。home：模块/会话与对话.md
10. **消息流 store 平铺** —— 分组/两态是渲染期计算（TurnGroup），store 不存
    分组结构。勿"在 store 里加分组状态"。home：模块/消息呈现.md
11. **项目类型只做本地** —— 云端/远程置灰禁选是**终态**不是 TODO。勿"解锁"。
    删除项目不级联删会话（悬挂保留是有意的）。home：模块/工作区与项目.md
12. **文字色一律实色 token** —— 禁 `text-x/75` 透明度文字色（Chromium 降级
    光栅化发糊）；层级靠实色深浅。透明度只许背景/hover。home：UI布局.md
13. **「允许，并切换为」落项目默认**（zcode 对齐）—— 审批面板第 3 项 =
    允许本次 + 切会话模式 + 记为项目默认（同项目新会话沿用）；只列两档
    放宽（自主/完全访问），切回收紧走权限菜单。"暂存位不持久化（防忘了
    关）"的顾虑由项目级落位 + 权限菜单可见兜住。
    home：模块/审批与权限.md
14. **计划模式 = 正交开关，不做第四档**（2026-11-16，三仓对照定调）——
    planEnabled bool 独立于三档权限，permissionMode 永不被 plan 触碰；
    批准 = 关开关（原档自动恢复，无切档下拉、无 prePlanMode 回退字段）；
    开关只读约束短路优先于档位放行（完全访问 + 计划开 = 只读）。
    **被否**：plan 占档位（原四档互斥——原档被覆盖、裁决被迫带切档下拉，
    仅 Claude Code 键盘流 shift+tab 如此，GUI 无此约束）；模型免审 exit_plan
    （三家 exit 全是带 plan 审批合体 = Cogent 的 submit_plan，免审自退 =
    模型给自己解锁写能力）。UI 双入口：菜单顶部开关项 + 外置 chip。
    home：模块/审批与权限.md、模块/交互座.md；过程 docs/计划/计划模式正交开关.md
15. **live 流恒定结构：过程单行化 + 底部工作中行，收尾才收头条**（2026-11-16，
    zcode 对照定调）—— 思考行默认收起单行（末行摘要横向滚动）、工具行单行、
    bash 进度尾行定高，「工作中」钉流底；顶部「已工作 Xs」头条只在 run 收尾
    出现。**被否**：「终答开流即折叠」（headerMode 翻转，2026-11-10 旧定调，
    摊开→折叠的模式翻转正是流中跳变主源）；「工作中锚定回合顶部」（zcode
    live 期间无顶部头条）。运行态无旋转 spinner：图标静态 + 文案扫光
    （旋转图标长期占用渲染资源）。勿"恢复流中折叠翻转"。
    home：模块/消息呈现.md；过程 docs/计划/对话过程呈现打磨.md
16. **Trace 折叠族收起不卸载（keepMounted）**（2026-11-16，折叠卡顿修复）——
    Base UI Panel 关闭即卸载被否：每次展开都在点击任务里同步重挂载整棵
    子树（Streamdown 解析 + Shiki 高亮 + 工具卡），点击到动画起跳先卡一段；
    zcode 式 300ms 延迟卸载也不取（grid 轨道开合不读内容高度，无卸载必要）。
    现行 = 收起常驻（hidden 不参与布局不绘制，只剩 DOM 节点内存），展开只剩
    浏览器 layout+paint，挂载成本移到收尾翻转帧。勿"顺手恢复卸载省 DOM"。
    home：技术笔记/思考流式呈现.md、模块/消息呈现.md
17. **折叠轨道必须 minmax(0,0fr↔1fr) + 内层 padding 随开合收拢，裸 fr
    与静态 padding 均禁用**（2026-11-16 fold-lab 逐帧采样定案）——「收起
    到 90% 卡住、剩下瞬跳」的真凶：裸 0fr/1fr 是 minmax(auto,fr)，自动
    最小尺寸被折叠体内层的 12px 垂直 padding 顶住，轨道收到 12px 即触
    地板、末段 ~60ms 无动画钉死，收尾靠 hidden 瞬跳（实测帧序列
    278.5→12 后平台 60ms→0）；minmax(0,…) 让轨道真正归零。第二层
    （观感，用户实测"最后 12px 像 opacity 式隐藏"）：静态 padding 的
    收起尾段裁的全是空 padding——内层 pt/pb 改由 data-open 驱动、与轨道
    同曲线过渡（同 ease-out ⇒ 窗口内空隙占比全程恒定 ~3%，尾段首行内容
    顶到裁切边被吃掉）；zcode 同病对照 ToolLayout.tsx:348「padding 挂
    动画节点上主体归零后仍停在 8px」。伴随修复（结构成立但非本症主因）：
    keepMounted 收起不卸载；折叠体条目不套 content-visibility 包装。
    **被否**：「砍动画瞬时开合」（误判已回滚）。勿"把 minmax(0,…) 简化
    回裸 fr"、勿"把 pt/pb 改回静态"（类名钉 trace.render.test.tsx）。
    home：模块/消息呈现.md、技术笔记/思考流式呈现.md
18. **Trace 折叠族平级无导线，头条下常驻分割线**（2026-11-16 用户定调）——
    折叠体内容区不再 ml+border-l+pl-4 导线缩进（23px 层级），与头条同级
    左缘 0；「已工作」头条下挂 border-t 分割线，**常驻不随折叠收起**（收起
    态也是「头条 + 线」的完整行）—— 挂在触发器与面板之间（折叠机构外），
    不参与开合动画；线到条目间距 = 折叠体内层 pt（决定 17 既定曲线）。
    live 过程流容器同步平级（收尾翻折叠横向零位移的约束不变，两侧
    23px→0）。**被否**：zcode 式 border-l 导线（reasoning.tsx:457）；
    分割线进折叠体（收起即消失，首版形态）。勿"恢复导线缩进表层级"
    （类名钉 trace.render.test.tsx；常驻钉 turn-group.render.test.tsx）。
    home：模块/消息呈现.md
19. **正文主题：默认态逐像素 = Streamdown 原生；拆壳必须 [style*] 门控**
    （2026-11-16）—— 消费表（globals.css「聊天正文主题」）两类规则分治：
    平滑属性无条件 + 原生等值回落；结构切换（代码块三层卡 ↔ 灰板、表格
    wrapper 卡 ↔ 裸表）由 `[style*='--t-code-']` / `[style*='--t-table']`

    拆壳，默认态代码块成"语言条/白卡断层"被否。链接色归主题令牌
    （chrome-accent 文内链接硬编码退役，window.open 行为保留）。
    勿"把门控规则简化回无条件"、勿"在 markdown.tsx 加回链接色类"。
    home：模块/消息呈现.md、技术笔记/聊天正文主题.md
20. **流式吸底单源化：关库 autoScroll，useStreamingBottomPin 独占跟随**
    （2026-11-17）—— 库 autoScroll（RO→rAF→scrollTo）慢一帧，流式期间
    "增长帧推下、下一帧拉回"即工作中行抖动（真机 CDP 逐帧采样：1407 帧
    70 次往复）。旧补丁（RO 回调内贴底）有两个致命伤：**Chrome 的 RO 交付
    在 paint 之后**（非"布局后绘制前"，贴底照样晚一帧、中间态上屏）；
    且与库双跟随并存时，库滚动的 scroll 事件把补丁的 2px 容差记账击穿
    （atBottom 误判 false 后永久退出）。现行：贴底走 MutationObserver 微任务
    （React commit 后微任务检查点同步执行，中间态不上屏），atBottom 记账
    用户意图驱动（滚轮/触摸/滚动键才灭；程序向上滚 = 锚点定位类显式离开）。
    勿"重新打开 Provider 的 autoScroll"、勿"贴底搬回 ResizeObserver / rAF"。
    home：模块/消息呈现.md
