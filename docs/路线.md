# 路线 — Cogent

## 已实现

- 窗口壳（`electron/main/index.ts`）与生命周期
- 引擎进程与 stdio JSON-RPC 主循环（`agent-service/index.ts`，`initialize` 已可用）
- main 引擎代理（spawn + Node 版本守卫 + 握手 + 事件出口）
- `app:status` IPC 域 + preload `getStatus`（诊断位）
- ESLint 类型感知规则（防御政策机械强制）
- renderer 壳层布局（2026-11-06）：聊天页三栏（Sidebar 会话栏 + 聊天区 + Resizable 文档栏）
  与设置页两栏（分组导航 + 分区内容），zustand uiStore 视图切换；
  聊天流/输入区已按 AI Elements pattern 重构（MessageScroller + Message/Bubble + InputGroup），
  UI 风格统一切到 base-luma（base-* preset 体系，详见 约定.md §3）
- 无边框窗口 + 自绘标题栏（features/shell/TitleBar.tsx）：frame:false，拖拽区 +
  min/max/close 白名单 IPC（window 域），最大化状态经 window:state-changed 推送
- **基础 Agent 对话（2026-11-06，路线 2/5/6 整合落地）**：
  - 引擎：`runtime/session.ts` 每会话一 pi Agent（builtinModels 目录 + streamSimple +
    getApiKey 查凭据内存表），pi 事件转译协议事件（message.delta / run.completed /
    run.failed）；`runtime/credentials.ts` 凭据内存表（key 只进不出）；
    新 method：session.messages / credentials.set / credentials.list / models.list，
    initialize 增 optional credentials 注入
  - 壳：`credentials/store.ts` safeStorage 加密落盘（userData/credentials.json，
    握手灌引擎）；`ipc/engine.ts` 引擎方法白名单代理 + 事件转发 webContents.send；
    `ipc/credentials.ts` key 写入/状态查询（明文不出 main）
  - renderer：stores/engine（模型目录/key 状态/选中模型）+ stores/chat（会话/消息/
    流式累积，事件流驱动）接真数据；ChatInput 模型下拉（无 key 置灰 + 去设置引导）、
    力度下拉映射 pi ThinkingLevel；会话栏 CRUD；设置页「模型设置」分区
    （ModelsSection：per-provider key 配置，保存后下拉同步解锁）；mock.ts 已删
- **自定义 Provider + 模型可见性收紧（2026-11-06）**：
  - 引擎：`runtime/custom-providers.ts` —— createProvider 构建自定义 OpenAI-compatible
    provider（id `custom/<slug>`）+ setProvider 运行时注入 + 内置 provider baseUrl 覆盖
    （闭包委托原实例）；新 method `providers.custom.sync`（全量替换语义）
  - 壳：`custom-providers/store.ts`（明文 JSON 落盘，定义与 key 分离——key 仍走 safeStorage）
    + `ipc/custom-providers.ts`（get/set，set 时引擎 running 即推 sync）
  - renderer：设置页 ModelsSection 重构（常用 6 家内置 + 每行 baseUrl 覆盖输入 +
    自定义 provider 卡片：名称/端点/key/模型列表表单）；聊天页模型下拉只展示
    配了 key 的 provider 的模型（隐藏而非置灰），activeModelId 失效自动回落
  - 冒烟验证：sync → credentials.set → models.list 含自定义模型 → agent.submit
    报连接错误（请求确实到达自定义 baseUrl）而非"未知模型"
- 引擎冒烟验证（2026-11-06）：initialize(带凭据) → session.create → models.list →
  agent.submit(假 key) → run.started + run.failed 事件链路全通（见 docs/开发.md 冒烟节）

## 空位（建议实现顺序，均为未写状态）

1. `protocol`：消息域类型细化（content blocks、消息模型；当前 ChatMessage 只含纯文本）
2. `agent-service/tools/`：工具注册 + `ToolKind` 分级 + 审批拦截点（发 `approval.request`）
3. `agent-service/storage/`：StorageDriver 接口 + 本地 JSON 实现（会话/消息持久化；
   当前会话只在引擎内存，重启丢失）
4. `renderer`：Markdown(Streamdown) 渲染助手消息；thinking/toolcall 事件的 UI 呈现
   （message.delta 目前只转译 text_delta）
5. `electron/main/credentials/` 演进：per-provider 删除接口（当前"清除"= 写空串）、
   key 脱敏展示（末四位）
6. `agent.abort` 的 UI 反馈：中止后消息流补"已停止"占位（当前只复位 running 态）
