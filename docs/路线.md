# 路线 — Cogent

## 已实现

- 窗口壳（`electron/main/index.ts`）与生命周期
- 引擎进程与 stdio JSON-RPC 主循环（`agent-service/index.ts`，`initialize` 已可用）
- main 引擎代理（spawn + Node 版本守卫 + 握手 + 事件出口）
- `app:status` IPC 域 + preload `getStatus`（诊断位）
- ESLint 类型感知规则（防御政策机械强制）
- renderer 壳层布局（2026-11-06）：聊天页三栏（Sidebar 会话栏 + 聊天区 + Resizable 文档栏，数据为 mock）
  与设置页两栏（分组导航 + 分区内容，「常规」已样式化），zustand uiStore 视图切换；
  聊天流/输入区已按 AI Elements pattern 重构（MessageScroller + Message/Bubble + InputGroup，
  附件 chip + 模型下拉占位），UI 风格统一切到 base-luma（base-* preset 体系，详见 约定.md §3）
- 无边框窗口 + 自绘标题栏（features/shell/TitleBar.tsx）：frame:false，拖拽区 +
  min/max/close 白名单 IPC（window 域），最大化状态经 window:state-changed 推送

## 空位（建议实现顺序，均为未写状态）

1. `protocol`：消息域类型细化（content blocks、消息模型）
2. `agent-service/runtime/`：SessionManager + pi Agent 接入
   （每会话一实例，pi 事件转译为协议事件）
3. `agent-service/storage/`：StorageDriver 接口 + 本地 JSON 实现
4. `agent-service/tools/`：工具注册 + `ToolKind` 分级 + 审批拦截点（发 `approval.request`）
5. `electron/main/credentials/`：safeStorage 凭据存取（握手时注入引擎）
6. `renderer`：接真实数据 —— 会话/消息消费引擎事件（store 订阅 + preload 白名单扩展）、
   发送接 `agent.submit`、模型选择、会话 CRUD（布局架子已就位，见 features/chat 与 features/settings）

> 每完成一项：勾掉并在「已实现」补一行；架构有变先改 架构.md。
