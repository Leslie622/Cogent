# 架构地图

> 完全自包含的静态文档站（`docs/架构地图/`），用 LikeC4 管模型、确定性列/泳道网格布局排布与正交通道路由，React Flow + 本地轻 UI 渲染。
> 运行命令见[项目说明](../架构地图/README.md)，设计与演进依据见[架构地图重构方案](../计划/架构地图重构方案.md)。

## 结构与数据流

```text
owner: 架构.c4 / 流程.c4 = 元素、关系状态与视图；视图布局.ts = 列/泳道槽位；模块说明.ts = 职责、契约与出处
.c4 模型 → LikeC4 Vite 插件 → 网格布局.ts（列/泳道排布 + 正交避障路由）→ React Flow 画布
点击模块/连线 → 右栏职责、边界契约、核验日期与源码（可一键复制路径或下钻返回）
```

- **左侧双分组导航**：
  - `架构地图`：`架构总览`（引擎为主干，`desktop`、`host.services`、`host.runtime.capabilities` 可点击下钻返回）、`桌面壳内部`、`Host 服务层`、`执行能力`、`数据与存储`（`COGENT_HOME` 单写者归属，含 `attachments/v1/` 与 `search/sessions-v1.sqlite`）。
  - `专题流程`：`身份验证与权限`、`消息与审批闭环`、`MCP 双轨机制`、`技能加载机制`、`钩子与扩展机制`、`上下文压缩与转录`、`文件边界与产物交付`、`凭据与模型出站`。
- **完成度筛选与右栏阅读**：画布顶部提供 `全部 / 仅已实现 / 高亮缺口`，其中 `仅已实现` 隐藏未实现规划节点与规划连线；右栏区分视图概览与模块详情，突出显示「技术边界」，来源卡片点击直接复制仓库相对路径（不跳转外链）。
- **确定性布局**：放弃 Graphviz 全局自动布局与 `.likec4/*.snap` 快照，[视图布局.ts](../架构地图/src/视图布局.ts) 只声明逻辑 `(col, lane)` 与紧凑行容器；[网格布局.ts](../架构地图/src/网格布局.ts) 保证新增节点只影响局部列/泳道，连线按通道槽位分配实现零共线、跨线留白与标签避让。

## 独立构建与保真守卫

- **零跨目录依赖**：不依赖主应用 `src/renderer/` 的 shadcn 组件、`globals.css` 或外部字体，使用自包含 SVG 图标与系统字体栈，单文件离线产物 `dist/index.html` 小于 2 MB。
- **两层防漂移**：[保真校验.test.ts](../架构地图/tests/保真校验.test.ts) 在 CI 中校验所有 `sources[].path` 真实存在、代码符号存在、13 张视图全部渲染连线均具备 `edgeDetails` 契约说明（禁止通用兜底文案）及模型/说明双向齐备；语义同步遵循[约定 §4](../约定.md#4-文档纪律写任何-docs-文档前)，过渡性改动不动图。

验收：左侧栏 13 项视图（5 架构 + 8 流程）切换与 3 处总览下钻返回正常；`全部 / 仅已实现 / 高亮缺口` 筛选（`仅已实现` 真正隐藏规划项）与点击连线契约有效；全视图满足无节点重叠、容器完整包围、连线正交不穿卡不共线、标签不盖卡片；`sources` 路径/符号与模型双向校验通过；1920/1440/1024/390px 无溢出且离线无外部请求，产物小于 2 MB。
