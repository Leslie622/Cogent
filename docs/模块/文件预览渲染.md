# 文件预览渲染

文件查看器位于 `features/home/files/`，`FilePanel` 按描述分发，重解析库按需加载。
入口来源、租约与桌面动作见[正文文件链接](正文文件链接.md)，标签宿主见[多标签工作区](多标签工作区.md)。

| 内容 | 渲染技术 | 查看能力 |
| --- | --- | --- |
| 文本/代码 | Pierre File + Virtualizer、Shiki WASM | 多语言高亮、行号/换行、原文行列/范围定位、搜索和复制 |
| Markdown | Streamdown + code/CJK/math/Mermaid | 预览/源码、数学和图表、本地依赖相对解析 |
| 图片/SVG | 原生img | 适配、原图、倍率、拖动、PNG复制、原文件另存；SVG可切源码 |
| PDF | react-pdf 10.4.1、PDF.js 5.4.296 | Canvas与可选文字层、单行图标翻页/缩放/适配、离线中文CMap与字体 |
| DOCX | docx-preview 0.4.0 | 纸张分页、section页边距、表格、图片、页眉页脚/脚注 |
| XLSX/XLSM/XLS | react-xlsx 0.16.0、duke_sheets WASM | 只读Canvas、工作表、格式、库支持的图形和图表 |
| PPTX | pptx-renderer 1.2.4 | 懒页模型、页面导航、文字/图形/图片/图表 |
| HTML/媒体 | 受管webview、原生audio/video | 显式网页预览、媒体播放；隐藏时暂停 |

`.doc` 沿用Zcode的 react-docx 0.8.1 查看入口，但该依赖仅明确承诺DOCX格式；真实旧OLE文档的成功解码未获确认。
损坏或库无法解码的文件显示明确错误；不把抽取的文字或空页冒充版式成功。
模型附件解析与 `parseDocument` 合同保留，预览可视化不改变模型得到的内容。

## 所有权与寿命

```text
owner: Host=可信来源/版本/有界读取；file-preview=tab字节/Blob/阅读偏好；查看器=派生资源
acquire → descriptor/version → readText或readChunk → 稳定原文或Blob
Office Blob → 可取消fetch → ArrayBuffer → ZIP目录预算 → 独立格式懒包
隐藏 → 保留文件和阅读位置；PDF卸载Page、PPTX释放slide、媒体暂停
关闭/回收 → 请求换代/取消 → 卸载观察器与页面 → 撤Blob → 归还lease
不可取消的库解析迟到 → 只清自己的离屏根，不能提交到新文件
```

`file-preview.views[tabId]` 是阅读状态的单写入口，只在运行期内存保留；应用重启不恢复阅读位置、选区或查看偏好。
文件字节、worker和第三方控制器由各自运行期owner持有，寿命不由阅读状态控制。
同标签导航到另一文件会开启新读取代次并清空阅读槽，源码/可视化滚动与媒体退出保存携带原代次，迟到清理不能写回新内容。
源码页不放常驻搜索按钮，Ctrl/Cmd+F按需展开查找。
代码选区使用原始UTF-16偏移；行DOM与高亮在Shadow DOM内，CSS Highlight不改写token节点。
可见范围可恢复原生选区，大跨页复制从原文范围取值；搜索保留大小写、全词和正则选项。
SVG源码与预览滚动分别使用源码/渲染滚动槽，互不覆盖。
源码页重新激活时显式恢复Pierre可见性并重绘虚拟行，再恢复选区和滚动；保留File实例，
不会因隐藏期间回收DOM后命中同一渲染范围而留下空白。普通搜索和选区变化不强制整页重绘。

DOCX每次字节拥有独立离屏根和作用域样式，保留不同section与原始字体版式；禁用altChunk HTML。
XLSX保留模型、sheet和真实网格滚动，明暗/隐藏不重建工作簿；PPTX只让活动页拥有绘制handle。
PDF的API、worker、CMap、字体与WASM来自同版包；PPTX的EMF-PDF转换也使用本地同版入口。
PDF视口预留稳定滚动条占位，适配宽度不随加载占位或Canvas显隐变化；同页缩放只更新Page的scale，
由库更换Canvas与文字层，不重新加载Page。绘制完成仍按独立代次核对，再恢复滚动，旧Canvas完成不能覆盖当前状态。

## 边界与预算

Host全局二进制100MiB上限不变；视觉Office一般25MiB，PPTX64MiB，图片/文本沿用20MiB。
Office ZIP预检最多4000成员、单成员32MiB、合计展开256MiB；预检只扫目录，不先解压大成员。
窗口原始字节256MiB/最多8个重文件驻留限制见工作区模块，不代表总进程内存限制。
PDF页面最多4000万像素，图片复制有独立Canvas像素预算；表格库保留其worker及主线程fallback，不能承诺解析绝不占主线程。

文档作者的DOM/Canvas外链仅允许HTTP(S)，交工作区浏览器；本页书签只在当前文档查找。
拒绝脚本、file、应用协议和带凭据URL，SVG只作为img源，不注入主应用DOM。
表格onOpenLink与PPTX提示文字转义补丁由postinstall强制应用，归因及随包版权文本见 `patches/来源说明.md`。

验收：真实字节而非附件文本驱动Office；换版/隐藏/关闭不跨标签提交，本次运行内页码、sheet、搜索/选区与滚动可恢复；PDF在跨滚动阈值放大后稳定绘制。
实际产品版式与离线资源证据见[渲染验收](../测试用例/文件预览渲染.md)；工作区原有性能失败仍保留。
