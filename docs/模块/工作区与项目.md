# 工作区与项目

> 存储根、项目域（目录绑定）、侧栏真实化与工作区注入。
> 落点：`src/host/runtime/project.ts`、
> `src/electron/main/storage-root.ts`、`src/electron/main/ipc/workspace.ts`、
> `src/renderer/src/features/home/{HomeSidebar,ProjectDialog,ProjectPicker,RemoveProjectDialog}.tsx`、
> `src/renderer/src/stores/project.ts`。

## 存储根 ~/.cogent

- 根 = `COGENT_HOME ?? ~/.cogent`；按域**单写者**：main 写凭据/壳配置/
  approvals（approvals 由引擎写）各管各的文件，双写者是事故源；
- main 侧 userData 旧文件首启自动迁移（搬完删旧，迁移不是复制）；
- 附件受管原件/引用/草稿/分析结果由 Host 写 `attachments/v1/`；壳的同步草稿恢复小日志
  用于未确认 IPC 窗口，归属与释放规则见[附件模块](图片与文件附件.md)。
- 全部落盘原子化（同目录 tmp + rename）；引擎对损坏文件逐文件隔离
  （.corrupt 旁置 + 继续）。

## 项目域（runtime/project.ts，ProjectRegistry）

- 项目 = 目录绑定 `{ id, name, cwds[] }`（**多根**，首个为主根——跨仓库任务
  一个项目，对齐 VS Code workspace / --add-dir）；持久化 projects.json
  （v1 单根 → v2 多根启动迁移）；
- 会话可归属项目并继承全部根（session.create 带 cwd/projectId）；
- 删除项目**不级联**删会话（悬挂保留）；
- 协议 `project.list/create/rename/delete/updateDirectories`。

## 侧栏（HomeSidebar，四分区真数据）

- 新聊天（整行动作）/ **置顶**（pinnedAt 倒序引用语义）/ **项目**（两级：
  项目行 → 子聊天）/ **最近**（无归属按 updatedAt）；归档会话不在任何分区；
- 列表滚动配方见 [UI布局](../UI布局.md#滚动条)。
  验收：空列表和短列表无滚动条占位；长列表使用原生细滚动条，Windows 下保留上下箭头，
  鼠标移开及停止滚动后滑块仍可见，内容减少后占位释放。
  会话列表右侧分割线无中央胶囊，拖拽调宽、方向键微调与双击复位仍可用。
- 会话行保留 DOM，由浏览器跳过屏外子树的渲染；固定行高占位维持滚动范围。
  验收：300 条会话中屏外内容确实跳过渲染；滚动到底后末行可见、可命中且滚动高度不跳，
  键盘聚焦屏外行能恢复渲染并滚入视口。
- 行为：置顶/归档/移除/编辑/在资源管理器中打开 = hover 更多菜单 + **右键
  菜单**双入口（components/ui/context-menu.tsx 原语）；
- 移除目标由 HomeSidebar 持有；RemoveProjectDialog 管确认、在途和错误，两处菜单入口共用。
  弹窗显示项目名并说明聊天和本地文件保留；确认后才请求移除，
  在途禁用取消/确认且不能关闭。成功关窗并显示「项目已移除」通知；失败留窗显示错误，可重试。
  顺序：`菜单 -> 确认 -> project store -> project.delete 成功 -> 更新列表 -> 成功通知`。
  验收：普通/置顶项目的两种入口均先确认；取消不请求、不通知；请求成功后才通知，失败不报成功。
- 归档 = 回收站语义（archivedAt），活动会话被归档时视图落"新聊天"防悬空；
  设置页「归档」按项目分组两级（zcode 对齐）：组行 = 项目 / 未归类 /
  已移除项目（悬空 projectId 合成一组，名字无从查起）+ 计数 + 组级批量菜单，
  组体复用 Collapsible 导航变体（200ms 开合过渡，内容常驻）；分组 / 筛选 /
  排序为本地纯函数（archive-view.ts + 单测）。
- 置顶 / 项目 / 最近分区与项目子列表复用 Collapsible 导航变体；开合为
  200ms 高度裁剪过渡，列表保持自然行高，收起内容常驻且不可交互，分区重开保留项目展开态。
  验收：会话列表和分区开合期间，“新聊天”等静止图标不抖动、不闪虚；连续反向开合自然衔接，
  收起内容不可 Tab 聚焦；系统减少动画时分区即时切换。自动和手动步骤见[工作区与项目验收](../测试用例/工作区与项目.md)。

会话搜索入口、HostApi 范围与来源定位统一见[会话搜索](会话搜索.md)。
验收：侧栏按钮打开搜索；侧栏自动折叠时 Ctrl+K 仍可打开。

## 创建/编辑弹窗（ProjectDialog）

- 创建/编辑两态合流：项目类型三选卡（本地可选；云端/远程置灰禁选是终态）+
  命名 + 目录列表行（多根增删）；点创建后「信任这些文件夹吗」确认层
  （信任才提交）。
- 项目名称行使用自定义图标外壳与 Input embedded 档，自动聚焦保留，输入和外壳均无聚焦描边；
  配方见 [UI布局](../UI布局.md)。

- 验收：多根项目会话的请求体含全部根的声明与各根 git 分支；删掉任一根
  目录后 submit 得错误帧；置顶/归档/移除/编辑/资源管理器打开五动作全部
  接真；全部归档后重启不冒出幽灵会话；归档会话不在主列表但可在归档
  视图恢复。

## 工作区注入（systemPrompt 装配）

- 会话绑定根时系统提示词加：工作区声明（列全部根）+ 环境块（每根 git 分支
  ——直读 .git/HEAD 不 spawn + 各根 AGENTS.md 只读限长 16k）；
- submit 复查全部根存在（已删 → 错误帧）。
- 聊天的文件夹路径引用独立于项目绑定，不增删根、cwd、AGENTS注入或写类信任；
  路径的生命周期与验收见[附件模块](图片与文件附件.md)。

## 输入区信息区

- 未发送新聊天显示“选择项目”或已选项目胶囊；选择/换绑/点 X 解绑只更新同一草稿的归属，
  正文和附件保留，不创建或删除会话。首次提交才将暂存 projectId 交给 session.create。
