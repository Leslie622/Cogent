# 工作区与项目

> 存储根、项目域（目录绑定）、侧栏真实化与工作区注入。
> 落点：`src/host/runtime/project.ts`、
> `src/electron/main/storage-root.ts`、`src/electron/main/ipc/workspace.ts`、
> `src/renderer/src/features/home/{HomeSidebar,ProjectDialog,ProjectPicker}.tsx`、
> `src/renderer/src/stores/project.ts`。

## 存储根 ~/.cogent

- 根 = `COGENT_HOME ?? ~/.cogent`；按域**单写者**：main 写凭据/壳配置/
  approvals（approvals 由引擎写）各管各的文件，双写者是事故源；
- main 侧 userData 旧文件首启自动迁移（搬完删旧，迁移不是复制）；
- 全部落盘原子化（同目录 tmp + rename）；引擎对损坏文件逐文件隔离
  （.corrupt 旁置 + 继续）。

## 项目域（runtime/project.ts，ProjectRegistry）

- 项目 = 目录绑定 `{ id, name, cwds[] }`（**多根**，首个为主根——跨仓库任务
  一个项目，对齐 VS Code workspace / --add-dir）；持久化 projects.json
  （v1 单根 → v2 多根启动迁移）；
- 会话可归属项目并继承全部根（session.create 带 cwd/projectId）；
- 删除项目**不级联**删会话（悬挂保留）；
- 协议 `project.list/create/rename/delete/updateDirectories`。

## 侧栏（HomeSidebar，四分区真数据）

- 新聊天（整行动作）/ **置顶**（pinnedAt 倒序引用语义）/ **项目**（两级：
  项目行 → 子聊天）/ **最近**（无归属按 updatedAt）；归档会话不在任何分区；
- 行为：置顶/归档/移除/编辑/在资源管理器中打开 = hover 更多菜单 + **右键
  菜单**双入口（components/ui/context-menu.tsx 原语）；
- 归档 = 回收站语义（archivedAt），活动会话被归档时视图落"新聊天"防悬空；
  设置页「已归档的聊天」= 归档时间倒序 + 恢复/彻底删除。

## 创建/编辑弹窗（ProjectDialog）

- 创建/编辑两态合流：项目类型三选卡（本地可选；云端/远程置灰禁选是终态）+
  命名 + 目录列表行（多根增删）；点创建后「信任这些文件夹吗」确认层
  （信任才提交）。

- 验收：多根项目会话的请求体含全部根的声明与各根 git 分支；删掉任一根
  目录后 submit 得错误帧；置顶/归档/移除/编辑/资源管理器打开五动作全部
  接真；全部归档后重启不冒出幽灵会话；归档会话不在主列表但可在归档
  视图恢复。

## 工作区注入（systemPrompt 装配）

- 会话绑定根时系统提示词加：工作区声明（列全部根）+ 环境块（每根 git 分支
  ——直读 .git/HEAD 不 spawn + 各根 AGENTS.md 只读限长 16k）；
- submit 复查全部根存在（已删 → 错误帧）。

## 输入区信息区

- 有项目会话显示项目胶囊（项目名/本地/分支）；胶囊 hover 出 X = **解绑项目**
  （删绑定脚手架会话 + 视图态回「选择项目」，不是删项目）；新聊天显示
  「选择项目」单钮。
