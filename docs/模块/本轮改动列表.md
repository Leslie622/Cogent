# 本轮改动列表

追踪每个用户回合（`turnId`）留下的工作区净文件变化、增删统计与冻结前后差异审查；撤销/重做（Batch 3）尚未实施。
原理对照见[文件引用笔记](../技术笔记/文件引用与改动追踪.md)，实施边界见[实现方案](../计划/本轮改动列表实现.md)，验证见[验收册](../测试用例/本轮改动列表.md)。

## 捕获与净差结算

- **审批放行后按需捕获**：`SessionManager.decideApproval` 仅在非只读工具放行后调用 `WorkspaceChangesService.beforeTool`；`plan` 拦截、用户拒绝或中止零开销。
- **延迟全量基线**：纯只读回合在 `finishRun` 由 `finishEmpty()` 直接短路；仅 `write`/`edit` 回合只按 `resolveToolFilePath` 精确捕获目标，不扫工作区；首次放行 `bash`/`powershell`/`mcp__*` 等才扫描绑定工作区根，且保留先前工具已捕获的更早 `before`。
- **范围与覆盖**：`scanner.ts` 排除 `.git`/`.svn`/`.hg`/`node_modules`/`.pnpm-store`/`.yarn` 与 `hostRoot`，不跟随目录符号链接并在嵌套 `.git` 停止深入，不按 `.gitignore` 全盘过滤；无绑定根时自动降级 `tools-only`（仅作内部状态，不出标签也不出警告），超时或超限标 `partial` 并附警告，且起点未完成扫描的目录不会在收尾误判为新增。
- **结算与去重**：`finalize()` 计算首尾净差；内容相同且唯一配对的一删一增折叠为 `renamed`；纯换行符/编码差异记 `eol-or-encoding`；二进制、超限或超时保留条目并标 `null`（UI 呈 `—`）。

```text
owner: SessionManager = 预约与收口; WorkspaceChangesService = 快照/净差; change-diff-worker = 文本diff
submit/continue → changes.begin [零I/O]
  → 放行 write/edit → 单文件 before 捕获
  → 首次放行 exec/mcp → 有界工作区基线扫描
  → finishRun → 冻结终点/净差 → 清理未变基线blob → 原子manifest → changes.updated
```

## 存储、协议与界面

- **会话分域 CAS**：`ChangeStorage` 将 `blobs/<prefix>/<sha256>` 与 `turns/<turnId>/manifest.json` 存于 `changes/v1/sessions/<sessionId>/`；8 路并发 I/O 限流（8 路）、单文件副本 `20 MiB`、哈希 `100 MiB`、单轮 `256 MiB`、会话 `1 GiB`、基线 `20,000` 文件；收尾清理未变化基线对象，删会话整目录清理；残留 `running`/`finalizing` 在 `get()` 时推进为 `interrupted`。
- **桌面隔离**：`changes.get` / `changes.diff` 在 `method-access.ts` 仅开主窗口白名单（经 `requireFileWindow`），HTTP/WS 与 guest 拒绝，事件不随 WS 广播，详情按需读取不进 `session.messages`。
- **呈现**：`TurnGroup` 尾部 `<TurnChangesBar />` 折叠呈现汇总与条目（仅 `partial`、告警或存在未统计/净改动项时展示，`complete`/`tools-only` 零改动无告警时静默隐藏）；文件状态由 `ChangeKindBadge` 消费项目素材库的文字 SVG，随主题切换并保留中文提示。尺寸见[UI 布局](../UI布局.md#设计素材)。点击条目在 `useWorkspaceStore` 打开 `kind: 'diff'` 标签，`DiffPreview` 使用 Pierre `MultiFileDiff` 渲染统一/双栏对比并支持跳转到当前原文件。

验收：只读零盘扫描、`write+edit+powershell` 合并基线、`A→B→C→A` 消零、唯一改名折叠、未绑定降级、`interrupted` 恢复、删文件/重启后冻结 Diff 与 HTTP 403 均有单测和集成回归；`TurnChangesBar`/`DiffPreview` 均通过组件回归。状态徽章在 Electron 40 的产品组件验收面通过深浅主题、约 400px 窄屏与 125% 缩放检查，徽章 44×20、行高 32px。真机大仓压测、完整窗口缩放与 Batch 3 撤销/重做仍在待测/待做队列。
