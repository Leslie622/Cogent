# 多标签工作区

右侧工作面承载新标签启动器、文件导航、文件查看与普通浏览器。正文和产物文件入口复用同一工作区，
文件交付与历史版本规则仍归[正文文件链接](正文文件链接.md)、[产物文件卡片](产物文件卡片.md)。
设计与待验证范围见[实现计划](../计划/多标签工作区实现.md)，原理对照见
[内置浏览器与聚合面板](../技术笔记/内置浏览器与聚合面板.md)。本轮净改动列表与 Agent 网页操作不由标签容器代办。

## 宿主与标签身份

- `WorkspaceFrame` 常驻在应用主内容区，`HomeMain` 保留对话；工作区使用同一绝对定位宿主，
  并排时以对话右内距留位，默认宽度与双击把手复位均为350px；占满只改宽度/可见性，不在多个 Dialog/portal 间搬动内容。
  不按窗口断点禁用展开或自动占满。窗口≤760px时与会话侧栏同步自动收起，放宽恢复原手动意图；拖窄至160px以下折叠。
  `workspace.autoCollapsed`是窗口呈现态：AppShell供给断点，Frame在布局阶段通过store写入；Frame/Surface/HomeMain共同消费。
  显式打开标签/资源或开合覆盖自动状态，下次断点变化重新投影；此字段不改scope手动开态或引擎配置。
  把手复用会话侧栏SidebarResizeHandle与光带，反转右侧拖动方向；rAF直写宽度，松手提交内存，越过阈值即时提交折叠。
  收放只过渡外层裁剪宽度，内层保持完整宽度；收起200ms后隐藏查看器，拖动期间不启用缓动。
- `stores/workspace.ts` 按真实session或`draft:<draftId>`在内存持有标签、顺序、激活、宽度与关闭历史。
  首次提交把草稿标签关联到session；切项目不改已开文件来源，删除聊天关闭对应资源。
- 标签头使用shadcn Tabs与dnd-kit；单行控制与对话头部对齐，展开入口只在收起时显示。
  搜索标签列表整行激活且只保留一层hover，关闭钮独立且不激活标签；不显示打开时长，打开列表不自动聚焦输入。排序只改变头部顺序，内容按创建顺序稳定挂载。
  tabId表示查看实例，规范资源键用于文件去重，网页同URL允许独立实例。
  文件树、文件搜索结果与单选本地文件通过navigateFile更新当前实例的source，保留tabId、顺序和激活归属。
  导航实例标为navigationMode=current，目标已在别页打开时也不合并或移走当前标签；正文资源入口仍按既有规则去重。
- 新页只有文件/浏览器入口；支持溢出、拖动、关闭其他/右侧/全部，关闭历史从标签列表或快捷键恢复。
  批量关闭固定开始时的ID集合；网页取消beforeunload时保留未关闭标签。
  网页关闭先用空白页导航协商，取消等待本次abort后保留原文档，确认提交后再销毁；探测不改标签URL、标题或文件来源。
  无需确认的标签合并提交，避免逐页激活即将关闭的内容；需要确认的网页依次协商。
  关闭最后一页收起，重新展开空工作区再补启动页；最近关闭按当前scope隔离，只在运行期保存描述，不复活旧lease。
  最后一个逻辑标签关闭时释放该scope的目录缓存、watcher和worker引用；最近本地文件重开时重新授权。

```text
owner: WorkspaceController = 描述/布局；FilePreview = 阅读/缓存；main BrowserRuntime = 网页
应用启动 → 工作区收起、标签为空 → 显式打开才创建内容
打开 → 新建/激活tab → 本资源加载 → 本tab显示
隐藏/切聊天/设置 → 留住节点与状态、交还焦点、暂停媒体
关闭 → 固定scope/ID → 内容owner关闭确认 → 释放资源 → 移除描述
迟到响应 → 只清理原操作，不复活tab、不覆盖其他scope
```

## 文件上下文与lease

项目根变更按[目录交接](项目目录交接.md)更换导航 owner，取消前后台旧扫描；已打开文件仍持有自己的 lease。

- `shared/file-views.ts` 定义桌面专用通道；main校验主窗口顶层帧，注入windowId，Host再校验载荷和归属。
  `fileViews.*` 不向HTTP/WS或普通网页开放，目录变更事件也不经WS广播。
  main 还持有页面代次。顶层重载或 renderer 崩溃先清旧 lease、context、watcher 和在途操作，新代请求等待清理结果。
  取消原生文件或目录选择直接返回取消，不创建 Host 上下文或写授权。
  同windowId可申请新资源，旧授权对话框、文件解析或原生动作的迟到结果不能提交到新页面。
- 项目根来自Host项目事实；原生选文件/目录由main写入`file-view-grants.json`，renderer只在内存保存grant ID引用。
  手动选择的文件授权记录不要求绑定项目；context重建只接收当前scope传入的grant IDs，应用重启不恢复这些引用。
  授权用于读取与context重建，不决定文件树范围；树与文件搜索只消费绑定项目的目录根，未绑定项目时为空。
  项目内面包屑使用项目相对路径，外部文件显示完整路径；长路径保留各段原宽并可横向滚动，激活时定位末尾文件名。
  Breadcrumb的scroll档和TabsList的workspace档共用水平滚动渐隐hook，按滚动/视口与内容尺寸变化更新两侧提示，
  隐藏滚动条，不遮淡已到端点的文字；提示仅投影DOM标记，不因滚动重渲染文件或网页。
  单独预览不创建项目或把文件所在目录加入树。
  授权按规范路径去重，同ID出现在两个scope不等于自动跨会话继承，新scope默认没有授权。
  授权与运行期context分开；context重建复核真实目标，损坏授权不自动清空，junction换目标需要重新选择。
  空白新对话使用desktopContext，不伪造session、改Agent cwd或导入附件。
- acquire统一接受session正文来源、OutputTarget或桌面context；当前文件由Host回传窗口内规范目标键，
  正文、树与草稿来源可在同一工作区合并，显示路径保留别名。
  source-only按实际当前文件分类；交付资源键包含session/turn/revision/outputId，旧版本失败不回退新字节。
- `FileViewsService`的显式lease使用独立登记，release同时覆盖原件和交付副本；旧files接口继续兼容。
  关闭一个调用方不夺走别的lease；父Markdown解析期间临时持有父登记，子成功后保存稳定来源。
  `relativeTo`是父lease，fileId/lease/Blob不跨Host重启使用。尚未解析成功的Markdown内链保存稳定的
  `parentSource`链（最多8层），恢复时重取父来源；成功后改存解析出的稳定路径或交付target。
- 文件查看器按tab在内存保存源码选区/搜索与滚动、Markdown模式、图片缩放、PDF页码、Office页/工作表、媒体时间。
  当前标签改看另一个文件时释放旧lease/Blob与读取任务、清空该阅读槽；旧读取和旧查看器退出保存按代次拒绝，不能覆盖新文件。
  各格式的可视化依赖、原始字节与派生资源寿命由[文件预览渲染](文件预览渲染.md)统一说明。
  隐藏音视频暂停；内容缓存按窗口256MiB原始文本/Blob预算及最多8个重文件查看器驻留回收后台内容，
  LRU按激活时间更新，保留阅读位置和交付租约。恢复时版本变化要求显式重新加载，不把新字节冒充原阅读版本。
  该预算不等于网页、图片解码、Canvas或总进程内存上限。
- 全部读取仍复用FileService的两路队列、分片/版本/软链接校验和既有格式容量限制。
  Host重启保留可诊断标签，重新解析稳定来源；迟到读取释放旧登记。
  会话真删除在Host同步释放对应lease/context并中止在途acquire，不依赖renderer导航；已有父内链临时hold结束后再注销登记。

## 目录、分页与项目搜索

- `FileWorkspacePane`是所有文件标签的稳定父容器；当前scope只显示一份导航与工具行，
  文件内容按tabId保留，切scope或草稿绑定不搬动内容节点。左树右预览，工具行统一文件位置与动作。
  树折叠只隐藏导航；切到浏览器隐藏整个文件工作面，原树owner缓存和文件阅读状态保留。
- `FileNavigatorOwner`拥有上下文、目录缓存、游标与取消；Headless Tree同步读取快照，TanStack只虚拟化可见行。
  导航根从项目目录投影，单文件/外部目录grant不生成树节点；Host搜索同样排除grant根，避免搜索越出项目范围。
  本地文件选择由FileWorkspacePane通过顶部打开按钮组调用同一owner.openContext，空树仅呈现“当前目录为空”。
  主打开动作随当前选择切换为原生选择或系统应用打开，菜单保留文件动作及选择其他本地文件的入口。
  合成的加载更多/错误行不是文件，不能进入文件动作。
- `file-view-worker.js`在独立线程枚举和排序。目录先形成完整有界名称快照，再按目录优先/自然名称分页，
  每页默认200、最多500；单目录最多100,000项/16MiB名称预算。超限明确不完整，不把前200项称为全目录。
  游标绑定context/目录/快照，目录身份变化或刷新后拒绝旧游标。
- 文件名/相对路径搜索覆盖未展开目录，不读文件正文；始终跳过.git，默认应用嵌套.gitignore/.ignore，可包含其他忽略项。
  每次扫描100,000条或5秒工作窗口后可暂停继续；网络盘仍受OS等待边界，取消后不调度后续工作。
  查询页可重放，worker最多保留8组查询/32MiB结果页；目录最多32份/32MiB快照，闲置2分钟过期。
  renderer最多驻留10页，翻页不把第2,001项截掉。
- main窗口最多8个非递归目录watcher，75ms合并为`fileViews.directoryChanged`；失效标记由导航owner消费，
  刷新重取快照。watcher失败明确显示，退出、释放scope与context关闭注销监听。

## 普通网页与本地HTML

- `BrowserRuntime`管理window/scope/tab/代次/lease与guest；节点采用稳定webview，main验证父窗口/partition及附加身份。
  每次初始化独立分配lease，StrictMode重挂或重试的旧回调只能释放自己的授权，不按逻辑tab复用lease。
  reserve、bootstrap和附加握手各有15秒截止；失败明确报错，初始化失败重试释放旧代并重建webview，已就绪页面错误仍普通刷新。
  普通网页只有沙箱JS对话框小桥，没有Host SDK、任意IPC或Node；导航/重定向/frame/popup执行浏览策略，自身Host端口受保护。
- 普通浏览器使用独立持久partition，登录态属于profile而非聊天；临时浏览组使用内存partition。
  站点权限与搜索偏好由 main 原子写 `browser-settings.json`，初始化不依赖设置页。
  一次授权归当前 guest 文档，跨文档导航、进程崩溃或窗口销毁时回收。
  导航、查找、缩放、历史、上传、下载、JS对话框、权限和关闭由具体白名单命令处理。
  Basic/Proxy挑战通过当前标签的用户名/密码对话框回答，只驻留待答请求；导航、超时或关闭取消请求。
  摄像头与麦克风分别保存授权，权限选择使用小号shadcn Select，弹层在触发框下方右对齐，不以选中项覆盖触发框；撤回权限会重新加载同站点页面以停止旧采集。
  更多菜单不提供下载管理入口；网页触发下载仍使用原生保存流程，下载生命周期与关页协商由main管理。
  系统浏览器入口先校验当前HTTP(S)地址；Windows默认浏览器为Microsoft Edge时，仅对百度HTTPS搜索页移除会使外部启动忽略导航的`tn=baidutop10`标记，其他查询字节和片段保留。
  兼容只作用于系统交接地址，不改内置网页、标签和历史；其他默认浏览器接收原URL。系统调用返回仅表示启动交接完成，不代表外部网页已经载入。
  原生popup保留opener/POST语义并随所属标签释放；后台页不能自动创建popup或抢走另一会话的工作区。
  网站透明画布有浏览器白色基底，应用深色主题不把网页原本的黑字变成黑底黑字。
- HTML默认仍可查看源码；显式网页预览通过受管协议执行。浏览器独立clone父文件lease，原文件标签关闭不夺走网页来源。
  当前HTML依赖默认限制在规范所在目录，可通过原生目录选择为当前浏览标签扩大资源根；所选根须包含HTML，
  不接受盘符/文件系统根或应用数据根。入口保留所选根内相对路径，支持`../assets`依赖。
  每次请求与Host登记前后复核根realpath、junction包含、敏感路径及COGENT_HOME/userData排除，父目录授权不能绕过保护根。
  交付HTML只解析同发布清单副本，不从当前源目录补依赖，也不能扩大资源目录。
  每个资源经Host版本化分片读取并释放临时lease；浏览页关闭取消在途读取。
  同一浏览标签成功更换HTML授权后撤销上个入口并释放旧clone；新授权/导航失败保留旧授权，旧入口不作为网页历史恢复来源。
  本地HTML标签在内存保存稳定文件来源，运行期重建时重新acquire并生成预览授权；
  显式扩大目录只在当前预览存活期间有效，关闭后重新打开需再次选择更大资源根。
- Agent claim/DOM操作、终端、diff/快照属于后续独立能力；普通浏览器不预先attach CDP。

## 运行期状态与验证边界

标签、关闭历史、阅读状态、宽度、开态与grant引用全部只留在运行期内存；应用启动默认收起且无标签，
不恢复上次文件、网页地址、阅读位置或最近关闭。启动异步删除旧`cogent-workspace`数据库，不读取旧内容，也不阻塞使用。
工作区不使用IndexedDB读写状态或保存快照，不提供保存失败界面，关窗不等待工作区保存握手。
网页历史随运行期标签保留，正常切换保持已访问guest；运行期重建可按公开URL/标题栈重新导航，
不恢复旧POST或JS history内存。浏览器Cookie、main站点策略和文件授权记录各自由原owner持久化，不属于标签内容。
Host独立重启时，仍由运行期稳定来源与grant引用重建文件context和lease。

自动回归覆盖lease/legacy兼容、无会话来源、根越界、junction变化、交付HTML、取消与多上下文关窗、
分页游标、嵌套忽略、2,001项搜索和可信授权重建；源码级通过不等于全部产品效果或性能达标。
完整产品、响应式、GPU、外站/硬件与平台结果以本批验收记录为准；未运行环境不由Windows模拟结果代替。
当前结果见[多标签工作区验收](../测试用例/多标签工作区.md)。

验收：空白对话可单独预览多个文件、网页，文件列表保持为空；绑定项目后只导航与搜索该项目目录，外部文件仍可独立预览。
排序、收起、设置往返与窄窗切换保持内容身份和阅读状态，
应用重启后工作区收起且无标签、关闭历史、阅读状态或grant引用，全部关闭回收资源。
HTML目录扩大只能来自原生选择，交付字节和敏感路径边界仍有效。
Windows默认Edge可从百度热榜搜索页打开同一搜索词的系统页面；内置地址与历史保持原值，其他默认浏览器收到完整原URL。
