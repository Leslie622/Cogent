# 会话与对话

> 引擎侧会话生命周期：pi Agent 托管、消息收发、流式转译与持久化。
> 落点：`src/agent-service/runtime/session.ts`（SessionManager）、
> `src/agent-service/storage/`（持久化）、`src/renderer/src/stores/chat.ts`（消费侧）。

## SessionManager

```
用户 submit ──► 受理校验（不存在/忙 → 错误帧，run 不启动）
        │
        ▼ （惰性：首条消息才灌转录建 pi Agent）
   pi Agent 流式 ──► StreamingState 缓冲（text/thinking/toolCalls）
        │  turn_end：封段成 ChatMessage + 整文档落盘 ~/.cogent/sessions/
        ▼
   run.completed(messages) ──► store 平铺替换 ──► TurnGroup 渲染分组
```

- 每会话一个 pi Agent，**惰性重建**：启动/恢复只载摘要，首次 submit/messages
  才灌转录建 Agent（省内存、省启动时间）；
- `submit` **同步受理校验**：会话不存在 → 错误帧；会话忙（isStreaming）→
  InvalidRequest（防串话与并发裸奔）；
- `prompt()` 内部启动窗口 catch → `run.failed` 兜底（异步拒绝不外泄成
  unhandledRejection，那会直接崩掉引擎进程）；
- abort：`agent.abort` → pi 流终止，半截文本按 pi 语义留存转录（后续请求可见）；
- 引擎退出时 disposeAll + 杀 bash detached 子进程 + settle 全部挂起审批。

## 流式段化（StreamingState）

- 轮内缓冲：text / thinking 分流累积，toolCalls 收集，turn_end **封段**成一条
  ChatMessage（段 id 带 run 级 messageId 前缀防跨 run 撞 key）；
- `run.completed` 发 `messages`（分段终态数组）+ `message`（聚合兼容：text
  拼接 + toolCalls 合并），历史回查 `toChatMessages` 与流式终态同源投影；
- timestamp 口径：assistant 消息的 timestamp 在 turn_end 覆写为**轮结束时刻**
  （pi 原生是流打开时刻，直接用会漏掉末轮流式段的时长）。

## 持久化

- 落盘 `~/.cogent/sessions/<id>.json`，**存 pi 完整转录**（ChatMessage 只是
  读时投影）；**回合边界整文档写**（非追加），原子写（同目录 tmp + rename）；
- 会话 id = UUID；`create/delete/setPinned/archive/agent_end` 均触发落盘，
  persist 尽力语义（失败记诊断不炸回合）；
- 恢复：损坏文件改名 `.corrupt` 旁置 + 继续恢复其余（单文件损坏不拒启）；
- 归档 = 软删（`archivedAt`）：`session.list` 默认滤掉，`session.listArchived`
  供归档视图，可恢复或彻底删除；
- 置顶 = `pinnedAt` 时间戳（非布尔）。

- 验收：全新会话不发消息则引擎无此会话（新聊天只是视图态）；同会话忙时
  再发得错误帧且引擎存活；杀引擎重启后摘要/转录/置顶/归档状态复原、续聊
  上下文完整；损坏的会话文件被旁置为 .corrupt 且其余会话正常恢复。

## renderer 消费（stores/chat.ts）

- 消息流元素是联合 `MessageItem`：ChatMessage / ToolItem / ApprovalItem /
  CompactionItem（终态痕迹与折叠条也在流里，见 消息呈现.md）；
- 「新聊天」只是 home store 视图态，**不建引擎会话**；`submit` 无活动会话时
  按需 `createSession`（会话只随用户动作物化——空列表/全归档落"新聊天"
  着陆页，不自动建，防幽灵会话）。

## 协议接口

`session.create/list/messages/submit/abort/delete/setPinned/archive/
listArchived/setPermission`（session.create 收 cwd/projectId/permissionMode）；
事件 `message.delta`（kind: text|thinking）、`run.started/completed/failed`。
形状见 `src/protocol/types.ts`，手册见 [../Agent引擎.html](../Agent引擎.html)。
