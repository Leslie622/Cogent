# 审批与权限

> 写类/执行类工具的人工确认机制：判定矩阵、挂起、规则记忆与 UI。
> 落点：`src/agent-service/runtime/{session.ts,approvals.ts}`、
> `src/electron/main/ipc/approval.ts`、
> `src/renderer/src/features/home/{ApprovalPanel,PermissionMenu}.tsx`。

## 判定矩阵（session.ts，挂 createAgent.beforeToolCall）

```
工具调用 ──► 软边界判定（工具层，越界直接 error 结果）
        ├──越界──► error（带可写根提示）          ← 规则表永不覆盖
        └──界内──► ask? ──► 规则表命中？──是──► 放行
                        │              └─否──► 发 approval.request 挂起
                        └─plan/auto/autonomous──► 按 mode 矩阵
```

| ToolKind \ mode | ask（默认） | plan | auto | autonomous |
| --- | --- | --- | --- | --- |
| 只读 | 放行 | 放行 | 放行 | 放行 |
| 写 | **发 approval.request 挂起** | block | 放行 | 放行（文件写信任） |
| exec | **发 approval.request 挂起** | block | 放行 | **逐次询问** |

- mode 读会话 summary 活引用，运行中切换即生效；
- 判定优先序：**软边界（工具执行层）> 工作区规则表放行 > mode 矩阵** ——
  规则永不放行越界写，双保险。

- 验收：ask 态写类触发面板、允许后工具结果正常回灌；「始终允许」后同根
  同类零审批、杀引擎重启规则仍在；越界写即使命中规则也被软边界拦下；
  运行中切 mode 立即生效且转录通告单条不堆积（切回 ask 零残留）；
  附言拒绝后模型的下轮请求体可见该附言。

## 工作区规则表（runtime/approvals.ts，ApprovalRegistry）

- `~/.cogent/approvals.json`（不走 driver collection，自写 tmp+rename 原子写）；
- 「始终允许此工作区」= roots×kind 快照，**只存位置不存内容**；判定 = 会话根
  与规则任一根交集；add 幂等；损坏旁置 .corrupt 按空表继续；
- 无绑定根会话发 always → InvalidParams（防主目录全放行的最后一道闸）。

## 挂起语义

- pendingApprovals 表 + 三路收尾（abort signal listener / 会话删除
  settleApprovals / disposeAll）；重复裁决 → InvalidParams；
- 裁决 `approval.respond`：allow / deny + `message` 附言（→ block reason →
  工具 error 结果回灌模型，2000 字符截断）+ `always: 'workspace'`（允许并落规则）；
- 走 main 专属通道 `approval:respond` IPC（不经 renderer 通用代理）。

## 权限通告（transcript 内 system 消息）

- mode 语义变化以单条 system 通告注入转录（`[cogent:permission]` 前缀识别，
  **替换式更新**防来回切换堆积）；切回 ask 零残留；新会话物化即 plan/auto
  场景由 ensureAgent 补建；
- 通告不进 buildSystemPrompt（leading 固化后运行中切不动），走 transcript
  是官方改提示词通道且不打断 toolUse/toolResult 配对。

## renderer

- **ApprovalPanel 替换输入区**（输入草稿提升父层持防丢）：竖排选项列表
  （序号 + 主文案 + 说明，↑↓/Tab 移动、Enter/点击执行）—— 允许 / 始终允许
  此工作区（无绑定根不显）/ 完全访问（respond + setPermission 两步串）/
  拒绝 / 附言（无框浅灰输入条）；
- PermissionMenu（输入区触发钮）：四档真选项 + 当前项勾选；auto 态红胶囊警示；
- 会话级挂起表 `pendingApprovalsBySession`（数组形态，pi 并行执行会并发多个
  请求）；侧栏行尾「等待确认」tag 占动作钮簇位置常显；
- 已裁决落终态痕迹行进消息流（用户裁决痕迹，转录无对应物）。

## 协议接口

`approval.request`（事件）、`approval.respond`、`session.setPermission`、
`session.create` 带 permissionMode；`PermissionMode = 'ask'|'plan'|'auto'|
'autonomous'`（stdio 侧有值域守卫防未定义新值）。
