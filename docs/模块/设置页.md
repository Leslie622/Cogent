# 设置页

> 分区行清单、偏好存储分层与各件的消费链路。视觉配方见 [UI布局](../UI布局.md)。

## 分区与行清单

- **常规**：「默认权限」（开关，D6 两态 ask↔auto）、「发送快捷键」（Enter /
  Shift+Enter / Ctrl+Enter 三档，kbd 键帽呈现）、「关闭窗口时」（最小化到托盘 /
  退出 / 每次询问）、「Chrome 硬件加速」（开关，重启生效）。
- **外观**：「界面样式」一组 —— 深色浅色（浅/深/跟随系统）、强调色（Themd 取色器、
  恢复默认）、界面字号、内容字体、代码字体、代码字体大小、对话内容（Themd 主题包
  导入/切换/删除）、「默认」= 内置 Theme-Leslie 令牌集、显示代码行号、
  长行自动换行。
  用户字体/代码字号在其用途内优先于主题及附加 CSS；换主题与明暗不重置选择，
  恢复默认清除覆盖并重新跟随当前主题。实现与验收见[消息呈现](消息呈现.md)。

## 偏好存储分层（判定标准：谁消费）

| 层 | 宿主 | 内容 |
| --- | --- | --- |
| `~/.cogent/settings.json`（main 单写者，字段合并） | main 或跨进程行为 | 发送快捷键（renderer keydown）、关闭行为（main close 拦截）、硬件加速（main 启动期）、默认权限、模型/思考偏好、externalMcp |
| localStorage persist（纯 renderer 视觉） | renderer | `cogent-appearance`（深浅色/行号/换行/字号/字体/强调色）、`cogent-themes`（主题包档） |

引擎侧无设置同步通道，localStorage 跨设备不同步是接受的墙（视觉偏好可再生）。

## 各件机制

- **发送快捷键**：`SendShortcut` 三档落 settings.json；消费点是 HomeChat 的
  `isSendKey`（纯函数，`tests/renderer/features/home/send-key.test.ts` 钉行为）：
  选中组合发送、其余 Enter 组合换行、IME 组词中恒不发送。缺省 `enter` = 首发
  行为。
- **关闭窗口时**：[window-close.ts](../../src/electron/main/window-close.ts) 拦截
  窗口 close（自绘 X / Alt+F4 / 任务栏全覆盖），每次读盘即时生效。`minimize`
  = preventDefault + hide + 托盘常驻（图标取 `app.getFileIcon(execPath)`，
  点击恢复/右键退出；隐藏期 host 继续跑）；`ask` = 推事件给 renderer 弹自绘
  询问弹窗（CloseAskDialog），裁决经 `window:confirm-close` 回传，「不再询问」
  由 renderer 落盘（设置写入单一通道）；`quitting` 标志让退出流程中的 close
  放行，`before-quit` 兜底置位。缺省 `ask`（首启即问一次）。
- **Chrome 硬件加速**：`disableHardwareAcceleration()` 只准在 app ready 前调 ——
  main 启动期读盘消费，设置页只落盘，改后重启生效。缺省开。
- **深色浅色**：appearance store 三档 → 共享 `bindAppearanceDom` 切 `html.dark`
  （system 档挂 matchMedia 监听）；main.tsx createRoot 前同步挂并订阅。正文
  Shiki 传 `[github-light, github-dark]` 双主题随 `.dark` 切；主题包 dark 令牌
  套经 ChatTheme 换套编译进同一容器 inline style（单管道，门控天然一致）。
- **用户覆盖管道**：`buildUserTokens` 把字号/字体/档位翻译成主题令牌，ChatTheme
  在明暗选套之后合并 —— 优先级 **用户 > 主题包（含默认 Leslie）> 消费表回落**；
  「跟随主题」档不写键。聊天代码优先消费主题 `--t-code-size`，未指定时使用
  Themd 的正文相对值 0.875em；控制台和工具输出使用公共代码值。
- **字号**：界面基准 11–16px、默认14px，四档阶梯见 [UI布局](../UI布局.md)。
  代码 8–24px 共用一个数值，覆盖聊天代码块、工具输出、控制台 CodeMirror/原文；
  「跟随主题」时聊天采用主题值，其余代码默认14px，行内代码保持正文相对排版。
  `cogent-appearance` 存储偏好，`bindAppearanceDom` 在所有窗口首帧应用并订阅 store；
  同源窗口经 storage 事件重读，独立控制台同步更新。内容作用域不随界面字号变化。
  缺失或非法界面值回14px，非法代码值回主题档，旧12–18px偏好保持有效。
- **字体选择**：内容、代码各有中英文字体槽，分别在各自弹窗里编辑草稿，弹窗内预览，
  点击「保存」一次写入整组；取消、关闭或 Escape 丢弃草稿。默认档按当前「对话内容」
  样式和明暗套回显字体名，附「默认」标识与样式名称；未指定族名时显示「系统默认」。
  每槽可选预设、本机字体或默认；默认槽保持随样式变化，不固化为当前显示的族名。
  旧组合预设拆成两槽，旧单族选择保留为英文槽。
  两个弹窗共用按需读取的系统字体族列表，只保存族名；读取失败时预设和当前值仍可用。
  浏览器先查英文字体，该字体缺字时再查中文字体和后备栈；英文槽宜选择不含汉字的字体。
- **强调色**：Themd 色板、拖拽、HEX 和 RGBA 输入共用颜色。亮暗共用选色；透明度
  作用于分屏光带和预览色块，模式文字保持不透明。修改即时覆盖 `--chrome-accent`
  并保存到本地；「恢复默认」清除覆盖。实现对照见
  [强调色选择](../技术笔记/强调色选择.md)。

验收：常规三件按上述缺省生效（enter / ask / 硬件加速开），改后即时或重启生效
符合各行描述；外观各档切换即时生效、重启留存、深色不闪白；内容与代码字体弹窗
打开不抢搜索焦点，搜索框填满内容区；两种语言均可搜索、预览，保存后应用且重启留存，
取消和关闭不改偏好；默认槽回显具体族名并随样式明暗更新，恢复一槽默认不清掉另一槽；
强调色从 Themd 色板点选、拖动或输入合法 HEX / RGBA 都即时更新，重启留存，恢复默认回到品牌蓝；
界面字号切换保留层级，聊天内容不联动；代码各正文与原文随统一数值响应，已打开控制台同步；
send-key 单测钉快捷键行为契约。字号手测见 [设置页](../测试用例/设置页.md)。
