# 设置页

> 分区行清单、偏好存储分层与各件的消费链路。视觉配方见 [UI布局](../UI布局.md)。

## 分区与行清单

- **常规**：「默认权限」（开关，D6 两态 ask↔auto）、「发送快捷键」（Enter /
  Shift+Enter / Ctrl+Enter 三档，kbd 键帽呈现）、「关闭窗口时」（最小化到托盘 /
  退出 / 每次询问）、「Chrome 硬件加速」（开关，重启生效）。
  「对话」组包含「输出详细程度」（简洁 / 详细，默认详细）与
  「显示过程请求详情」（开关，默认关闭）与
  「耗时显示格式」（整数 / 1 位小数 / 2 位小数，默认 2 位），以及
  「自动生成会话名称」（开关，默认开）。
- **外观**：「界面样式」一组（应用级）—— 深色浅色（浅/深/跟随系统）、界面主题色、界面字号、
  强调色（Themd 取色器、恢复默认）；「对话」一组（内容区）—— 内容字体、代码字体、
  代码字体大小、Markdown 主题（Themd 主题包导入/切换/删除，「默认」= 内置 Cogent
  主题包令牌集）、显示代码行号、长行自动换行。
  用户字体/代码字号在其用途内优先于主题及附加 CSS；换主题与明暗不重置选择，
  恢复默认清除覆盖并重新跟随当前主题。实现与验收见[消息呈现](消息呈现.md)。
- **存储**：「空间占用」（总量行带刷新钮重扫 + 分类分段条/图例 + 可折叠
  明细 —— 明细只两档：会话转录单列 + 「其他」聚合，不铺内部条目清单）与
  「数据文件夹」（存储根绝对路径 + 浏览开资源管理器）。

## 偏好存储分层（判定标准：谁消费）

| 层 | 宿主 | 内容 |
| --- | --- | --- |
| `~/.cogent/settings.json`（main 单写者，字段合并） | main 或跨进程行为 | 发送快捷键（renderer keydown）、关闭行为（main close 拦截）、硬件加速（main 启动期）、默认权限、模型/思考偏好、externalMcp |
| localStorage persist（纯 renderer 视觉） | renderer | `cogent-appearance`（输出详细程度/过程请求详情/耗时精度/深浅色/界面主题色/行号/换行/字号/字体/强调色）、`cogent-themes`（主题包档） |
| `~/.cogent/session-title.json`（Host 单写者） | Host 会话域 | 自动标题开关 |

自动标题业务配置归 Host 会话域所有，单写者为 Host 的标题配置服务，存于
`~/.cogent/session-title.json`（v1）。Host 构造期加载完成才接受请求；缺文件时
默认开启，损坏文件报错。设置页通过 `session.titleSettings.get/set` 读写，保存成功才
更新生效值；首条输入受理时冻结开关，后续设置变更作用于新任务。标题固定使用首条
输入实际使用的模型，不提供独立选择。旧文件和旧客户端的可选 `model` 字段仍校验形状，
但不参与生效配置或返回值；读取不改文件，下次保存只写 `enabled`。
localStorage 跨设备不同步是接受的墙（视觉偏好可再生）。

## 各件机制

- **会话名称**：`SessionTitleSettings` 首次只读 Host，不回写初始化值；保存期间禁用控件，
  成功后回显，失败原位显示原因、保留旧值，可重新读取。界面只提供启停开关，保存
  请求只携带 `enabled`。任务机制见[会话与对话](会话与对话.md#会话自动标题)。

- **对话显示**：`outputVerbosity` / `durationPrecision` 由 appearance store 持久化，
  缺失或非法值分别回详细 / 2 位小数；设置控件与消息组件直接订阅，即时作用于
  流式与历史内容，重启留存。工具 / 思考 / 统计的可见范围、耗时单位与进位口径见
  [消息呈现](消息呈现.md)，原理对照见[对话显示偏好](../技术笔记/对话显示偏好.md)。
- **过程请求详情**：`showProcessUsage` 归 renderer 呈现偏好，单写者为 appearance
  store，存于 `cogent-appearance`，由 persist 初始化读取；缺失或非法值为关闭。
  设置页开关写入后，流式过程与历史过程中的单次请求 token、缓存、成本和耗时
  即时显隐，重启保留；无需等待 Host。简洁档优先隐藏统计，详细档再按此开关
  决定过程明细可见性；最终回合汇总不消费此开关，原始用量与计费不受影响。
- **发送快捷键**：`SendShortcut` 三档落 settings.json；消费点是 HomeChat 的
  `isSendKey`（纯函数，`tests/renderer/features/home/send-key.test.ts` 钉行为）：
  选中组合发送、其余 Enter 组合换行、IME 组词中恒不发送。缺省 `enter` = 首发
  行为。
- **关闭窗口时**：[window-close.ts](../../src/electron/main/window-close.ts) 拦截
  窗口 close（自绘 X / Alt+F4 / 任务栏全覆盖），每次读盘即时生效。`minimize`
  = preventDefault + hide + 托盘常驻（图标取 `app.getFileIcon(execPath)`，
  点击恢复/右键退出；隐藏期 host 继续跑）；`ask` = 推事件给 renderer 弹自绘
  询问弹窗（CloseAskDialog），裁决经 `window:confirm-close` 回传，「不再询问」
  由 renderer 落盘（设置写入单一通道）；`quitting` 标志让退出流程中的 close
  放行，`before-quit` 兜底置位。缺省 `ask`（首启即问一次）。
- **Chrome 硬件加速**：`disableHardwareAcceleration()` 只准在 app ready 前调 ——
  main 启动期读盘消费，设置页只落盘，改后重启生效。缺省开。
  Windows 的 main 启动策略固定使用 CPU 栅格化以改善 SVG 路径边缘，GPU 合成仍可用；
  此策略不另存用户配置，硬件加速总开关关闭时仍禁用全部硬件加速。
  验收：完整重启后 Windows 的 rasterization 为 `disabled_software`；具备 GPU 合成能力的
  环境中，开关开启时合成保持 `enabled`，关闭后为 `disabled_software`。
- **深色浅色**：appearance store 三档 → 共享 `bindAppearanceDom` 切 `html.dark`
  （system 档挂 matchMedia 监听）；main.tsx createRoot 前同步挂并订阅。正文
  Shiki 传 `[github-light, github-dark]` 双主题随 `.dark` 切；主题包 dark 令牌
  套经 ChatTheme 换套编译进同一容器 inline style（单管道，门控天然一致）。
- **界面主题色**：明暗下方的缩略单选卡提供森林 / 薄荷 / 蜜蜂 / 羊皮纸 / 海盐 / 暮紫，
  默认薄荷；`interfaceSkin` 与 `colorMode` 独立持久化，旧档缺失或非法值回薄荷。
  `bindAppearanceDom` 首帧与订阅更新时按实际明暗取同一主题色的色板，投影头部、应用
  侧栏的渐变与内容侧栏实色；深色和跟随系统均响应换肤。同源窗口经 storage 重读。
  缩略图共用应用色板，切明暗同步预览；正文底色、Markdown 主题与强调色各自独立。
  视觉配方见 [UI布局](../UI布局.md)，原理对照见[界面主题色](../技术笔记/界面主题色.md)。
- **用户覆盖管道**：`buildUserTokens` 把字号/字体/档位翻译成主题令牌，ChatTheme
  在明暗选套之后合并 —— 优先级 **用户 > 主题包（含默认 Leslie）> 消费表回落**；
  「跟随主题」档不写键。聊天代码优先消费主题 `--t-code-size`，未指定时使用
  Themd 的正文相对值 0.875em；控制台和工具输出使用公共代码值。
- **字号**：界面基准 11–16px、默认14px，四档阶梯见 [UI布局](../UI布局.md)。
  代码 8–24px 共用一个数值，覆盖聊天代码块、工具输出、控制台 CodeMirror/原文；
  「跟随主题」时聊天采用主题值，其余代码默认14px，行内代码保持正文相对排版。
  `cogent-appearance` 存储偏好，`bindAppearanceDom` 在所有窗口首帧应用并订阅 store；
  同源窗口经 storage 事件重读，独立控制台同步更新。内容作用域不随界面字号变化。
  缺失或非法界面值回14px，非法代码值回主题档，旧12–18px偏好保持有效。
- **字体选择**：内容、代码各有中英文字体槽，分别在各自弹窗里编辑草稿，弹窗内预览，
  点击「保存」一次写入整组；取消、关闭或 Escape 丢弃草稿。默认档按当前 Markdown
  主题样式和明暗套回显字体名，附「默认」标识与样式名称；未指定族名时显示「系统默认」。
  每槽可选预设、本机字体或默认；默认槽保持随样式变化，不固化为当前显示的族名。
  旧组合预设拆成两槽，旧单族选择保留为英文槽。
  两个弹窗共用按需读取的系统字体族列表，只保存族名；读取失败时预设和当前值仍可用。
  浏览器先查英文字体，该字体缺字时再查中文字体和后备栈；英文槽宜选择不含汉字的字体。
- **强调色**：Themd 色板下方提供「主题色」分区，六个具名色块复用界面主题色的
  当前明暗套点缀色；点选与拖拽、HEX、RGBA 共用更新管道并保留透明度。
  仅保存当下色值，不改界面主题色 ID；候选随明暗换套，已选强调色保持原值。透明度
  作用于分屏光带和预览色块，模式文字保持不透明。修改即时覆盖 `--chrome-accent`
  并保存到本地；「恢复默认」清除覆盖。实现对照见
  [强调色选择](../技术笔记/强调色选择.md)。
- **分区切换防抖**：技能 / MCP 列表带模块级缓存（stale-while-revalidate：
  命中先渲染旧值、挂载即后台刷新，仅每作用域首访出加载卡）；设置内容区滚动
  容器挂 `scrollbar-gutter-stable` 常驻滚动条空间（居中列不横跳），切分区
  显式回顶（useLayoutEffect，绘制前归零）—— 三者合力消除切换时
  「加载卡塌陷再弹起 + 滚动条出现/消失横跳 + 钳位乱跳」。
- **存储占用统计**：main 的 `storage:usage` IPC 只读扫描存储根顶层条目
  （目录递归累计字节，扫描期条目消失按 0 计，根不存在 = 0 字节事实）；
  快照模块级缓存 stale-while-revalidate（MCP 同款）。归类成展示分类
  （会话转录 / 附件 / 观测日志 / 引擎数据 / 配置与其他）、明细两档聚合与
  字节格式化在 `storage-view.ts` 纯函数（单测钉口径），壳契约只报
  字节数事实。
  「浏览」走 `shell:open-path`。

验收：对话组默认详细 / 2 位小数，两项切换即时生效且重启留存；简洁档工具仅保留
名称与执行状态，思考不显示摘要或全文，底部用量统计整行隐藏；详细档可重新查看
原内容；整数、1 位、2 位秒小数在各可见耗时位置一致。
过程请求详情默认隐藏，开启后详细档的过程可见单次请求统计，关闭后只隐藏过程
统计；最终回合汇总与工作头条均不受此开关影响，重启保留选择。
自动名称只提供开关，直接读写 Host、重启保留，失败不假报保存成功；开启时标题跟随
首条实际模型，旧独立模型选择不生效；关闭后新会话只用原文临时标题，手动名称不被
覆盖。自动回归见 `session-title.render.test.tsx`。
常规行为按上述缺省生效（enter / ask / 硬件加速开），改后即时或重启生效
符合各行描述；外观各档切换即时生效、重启留存、深色不闪白；六套主题色在浅色、深色
及跟随系统下均作用于头部与两级侧栏，切明暗保留选择，预览对应当前明暗；卡片
可鼠标与键盘单选，400px 窗口不横向溢出。主窗口与控制台的
聚焦轮廓随明暗主题切换，视觉配方见 [UI布局](../UI布局.md)；内容与代码字体弹窗
打开不抢搜索焦点，搜索框填满内容区；两种语言均可搜索、预览，保存后应用且重启留存，
取消和关闭不改偏好；默认槽回显具体族名并随样式明暗更新，恢复一槽默认不清掉另一槽；
强调色从 Themd 色板或六个主题色点选、拖动或输入合法 HEX / RGBA 都即时更新，
点选主题色保留透明度，重启留存，恢复默认回到品牌蓝；
界面字号切换保留层级，聊天内容不联动；代码各正文与原文随统一数值响应，已打开控制台同步；
send-key 单测钉快捷键行为契约。分区切换不闪加载卡、内容列不左右横跳（含
技能 ↔ MCP 反复切换与带滚动条的长列表）。存储页总量与明细随 ~/.cogent 实际
内容变化，浏览打开资源管理器，刷新重扫。字号与存储手测见
[设置页](../测试用例/设置页.md)。
