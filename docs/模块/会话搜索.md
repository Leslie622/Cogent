# 会话搜索

落点：`src/host/runtime/search/`、`src/host/kernel/transcript.ts`、
`src/host/runtime/message-projection.ts`、`src/shared/{session-search,search-text}.ts`、
`src/renderer/src/features/home/search/`、`src/renderer/src/stores/search.ts`。
取舍与参照见[技术笔记](../技术笔记/会话搜索.md)，实际验证范围见[验收册](../测试用例/会话搜索.md)。

## 入口、范围与结果

- 侧栏搜索钮与主窗口 Ctrl+K / Cmd+K 打开同一 shadcn Nova Command；
  侧栏折叠时快捷键仍可用，CodeMirror 自身的 Ctrl+K 不被接管。
- 空查询按最近活动列聊天；有查询匹配标题或同一条用户/助手呈现消息的正文。
  浮层搜索全部未归档会话，不提供项目或归档筛选；已移除项目的会话仍保留。
- 多个空白分隔词为 AND，引号表示连续短语；不区分大小写，中文一、二字可搜。
  `%/_/OR/*` 是字面字符；未闭合引号按普通文本处理，不执行正则或 FTS 运算语法。
- 标题完整匹配、标题词项命中、正文命中依次排序，同档按活动时间及 ID 排序。
  每页默认 30 个会话，统一显示在“聊天”分区；每会话一个可选项，标题下内嵌首条
  命中摘要，不把用户/助手或更多命中单独成项。打开后由聊天内导航查看、翻页更多命中。
  空查询只列标题及实际项目名，不显示未归类或时间；有正文命中才展示摘要。
  相近命中窗口合并，标题与摘要高亮均为纯文本。
- 语料包含压缩前保留正文、正文代码及附件/目录名称；系统注入、内部续写指令、
  思考、工具返回的文件内容和压缩摘要不参与默认召回。未封口 token 不进入持久化索引。
- 浮层不显示归档聊天；HostApi 的 `projectId` / `includeArchived` 范围参数仍可由其他消费者显式使用。
  删除会话不从孤儿 JSONL 复活。

验收：浮层跨项目检索且排除归档，旧历史、中文短词和符号可搜；只有标题命中时不伪造正文命中。

## 索引所有权与读取

```text
owner: Host = 会话可见目录；搜索 worker = 派生库单写者；renderer = 查询/导航意图
打开搜索 -> 180ms防抖/IME结束 -> session.search -> Host摘要目录+固定piCwd
   -> worker逐会话核对文件指纹 -> 共用只读转录/正文投影 -> 事务替换派生文档
   -> trigram候选/短词instr -> 字面验证/摘要/分页 -> 当前查询身份接收
```

- 索引为 `COGENT_HOME ?? ~/.cogent` 下的 `search/sessions-v1.sqlite`，不是转录真源。
  worker 惰性启动、复用一个 `node:sqlite` 连接；同步查询与文件读取不占 Host 事件循环。
  来源按路径、大小、mtime/ctime 对账，未变化正文不重复解析；元数据独立更新。
- 较长词项使用 `trigram case_sensitive 1` 获取候选；短词用唯一字符/相邻双字符的无正文 FTS 候选索引；两者都以
  `instr`、同一大小写规范化和原文区间映射作最终验证。按呈现消息索引，不截断长聊天后半段。
- 读取 JSONL 使用公开解析器与 `SessionManager.inMemory(...).getBranch()`，
  迁移只在内存进行；历史回查也用此路径，不调用可能重写旧文件的 `open()`。
  来源损坏显式报告不完整，失败会话的旧索引移除，其他结果仍可用。
- Cogent v1 未导入 pi 时，摘要修改继续保存 v1 转录；真正导入后才写 v2。
  无 pi 文件的 v2 空会话合法；已有转录损坏不当作空聊天。
- 索引校验应用 ID 与 schema 版本；错误显示重试/重建。显式重建先保留旧库及
  WAL/SHM 为 `.previous-*`，下次查询重建，不覆盖会话文件或删除旧库。
- 游标绑定查询、范围、分页大小、worker 数据库实例与索引世代；数据变化返回明确失效。
  worker 故障拒绝在途请求，下次可重新创建；单请求 60 秒超时，诊断走 stderr。

验收：不变查询复用索引，元数据/正文变化可见，搜索不装配模型或调用工具；
损坏不能显示成完整空结果，重建后原转录保持原样。

## 来源锚点、导航与异步边界

```text
pi append提交 -> 来源entryId -> 历史投影/直播source事件与终态段
选择聊天行 -> 搜索操作身份 -> 打开会话/读取消息
   -> 当前桶来源映射 -> 展开过程 -> scroller释放吸底 -> 原文定位/CSS高亮
切会话/新搜索/删除 -> 旧意图失效；关闭高亮 -> 移除CSS范围
```

消息 `sources` 保存来源 ID 与正文区间，续写合并同步平移区间，不改 UI id/React key。
旧 Cogent v1、旧 pi v1 使用内容修订与条目序号锚点；真实迁移后旧锚点须重新查询。
`message.source` 只为可见用户输入和助手正文补来源，不把内部续写或纯工具轮挂到旧正文。

选择与翻页均约束本次操作身份；消息读取删除后失效，不能重建旧桶。
聊天内提供上/下一个命中和关闭。过程正文只自动展开一次，继续尊重手动开合；
CSS Highlight 跨文本/代码节点标记，不改 Markdown 源、DOM 和用户选区。
匹配只在原始 Markdown 语法或附件名称时定位所属消息并给出说明。

验收：已加载直播桶与重启历史桶均按来源定位，过程展开后可见；
用户切会话后迟到结果不抢导航，关闭高亮释放范围，不因后续 token 持续拉回视口。

协议：`session.search` 为 readonly，`session.search.rebuild` 为 admin；
沿用 HostApi 方法注册、main 白名单与壳共享合同，不另开端口，不自动给模型历史检索工具。
