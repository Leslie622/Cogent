# 测试

> Vitest 三层测试体系与 CI。
> 落点：`vitest.config.ts`、`tests/integration/`、co-located `*.test.ts(x)`、
> `.github/workflows/ci.yml`。

## 三层（vitest 三 project）

| 层 | project | 测什么 | 形态 |
| --- | --- | --- | --- |
| 单元（引擎） | `node` | compaction 纯函数、toChatMessages 投影 | co-located（src 内），直读源码不 build |
| 单元+组件（渲染） | `web`（jsdom） | groupTurns、flat 管道、TurnGroup 渲染分支（RTL）、chat store 事件驱动（window.cogent 可编程 stub，测真实接线） | co-located |
| 集成 | `integration` | 黑盒引擎协议：mock SSE 端点 + 真构建产物 `out/main/host.js` + 协议断言 | tests/integration 四套（tools 39 / compaction 29 / approval-upgrade 18 / ps-utf8 双跑） |

- co-located 清单：`runtime/{compaction,session}.test.ts`、
  `stores/{chat,chat-store}.test.ts`、`features/home/turn-group*.test.ts(x)`；
- **global-setup 自动补 build**（发现构建产物缺失/过期先 build，改引擎不用
  记得先构建）；临时 `COGENT_HOME` 隔离每套场景；
- 集成测试保持 stdin 打开（引擎 stdin close 即退出杀掉进行中请求）。

## 原则

- **回归钉为主**：每个翻过车的 bug 一条测试，钉行为不追数字；
- 覆盖率不设门槛（报告观察用）；不做 E2E（GUI 人工验收承担）；
- 新逻辑模块随实现带单测；修 bug 的提交里就有回归测试，不等以后补
  （约定.md 测试义务）。

## 跑法与 CI

- `npm test`（全量）/ `npm run test:watch`（开发循环，只跑 node+web）/
  `npx vitest run --project integration <文件>`（单套）；
- Actions CI（.github/workflows/ci.yml，windows 单 job）：lint + typecheck +
  build + test 四关。

- 验收：删掉 out/ 后直接 `npm test` 仍全绿（global-setup 自动补 build）；
  集成测试期间引擎 stdin 保持打开；动了 `*.test.ts` 跑到通过才算完成
  （根 AGENTS.md 硬规则 1）。
