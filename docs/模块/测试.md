# 测试

> 应用测试与夹具在根 `tests/`，独立文档站测试在 `docs/架构地图/tests/`。
> 应用配置为 `vitest.config.ts`，CI 入口为 `.github/workflows/ci.yml`。

## 目录与执行环境

| 目录 | project / 环境 | 职责 |
| --- | --- | --- |
| `tests/host/` | `node` / Node | Host 纯函数、服务、HTTP 与源码级 pi 接线 |
| `tests/electron/` | `node` / Node | 壳侧可独立执行的逻辑，如 Node 运行时定位 |
| `tests/shared/` | `node` / Node | 壳契约相关的纯逻辑与 guest SDK |
| `tests/renderer/` | `web` / jsdom | 数据转换、store 事件序列、hooks 与组件交互 |
| `tests/integration/` | `integration` / Node | mock SSE、MCP 夹具与真实构建产物的黑盒协议链路 |
| `tests/setup-web.ts` | `web` 公共准备 | jest-dom、RTL 清理与默认 Web Animations 桩 |
| `tests/run-tests.mjs` | 测试启动器 | 优先使用 `COGENT_NODE_BIN`，否则选满足 pi 版本要求的当前 Node 或自带运行时 |

域内目录镜像 `src/` 的职责划分，renderer 省略其源码目录中额外的 `src/` 层。
测试直接导入产品源码；renderer 使用 `@/`、共享模块使用 `@shared/` 别名。
Vitest 的 `include` 与两个 TypeScript 工程均显式包含对应测试目录。

## 测试边界

- 源码级测试不依赖 build；准备期停止测试通过真实 SessionManager、pi 工厂和
  loopback SSE 验证接线，仍属于 `node` project。
- 文件链接身份回归使用真实文件软链接。Windows 进程缺少建链权限时使用目录联接，验证完整路径改变后拒绝旧文件标识，重新登记后读取新目标。
- 黑盒集成测试运行 Host、MCP 和三种 worker 构建入口。global-setup 在入口缺失或旧于引擎源码、构建脚本、依赖清单时执行 build。各套用临时 `COGENT_HOME`。
  冷启动回归记录握手前真实依赖量，再复制到新文件路径验证启动；图片资源回归观测
  真实 SDK worker，防止合并后静默退回主线程。
- 集成服务用动态回环端口，暂保留文件串行以隔离 pi 工具缓存和环境。子进程按流解码 UTF-8，
  RPC 与事件各有限时，退出时结束等待。测试通过关闭 stdin 停止 Host，等进程和管道关闭后清理或重启。
- PowerShell 回归从 pi 实际启动的进程读取版本与文件名，分别验证 5.1 和已安装的 7。缺少 PowerShell 7 时报告跳过。
- renderer 的桥接桩由场景自带，store 测试发送真实事件并检查状态；不复制实现。
- jsdom 验证 DOM 身份、交互与时序；真实布局、像素和动效观感由
  [手测用例](../测试用例/消息呈现.md)承担，不以类名或模拟几何替代真机结论。
- `*.browser.html` 是独立 Vite 验收页，不由 Vitest 自动发现；统一使用
  `tests/browser-harness.config.ts`。主题、聊天布局与菜单分隔线等页有隐藏 Electron 驱动，其余页按各模块手测册打开。
- Windows CI 的 Electron 冒烟从构建后的主窗口通过 preload 读取隔离 Host 的会话，再正常关窗，检查自有进程退出。独立浏览器页和产品探针继续承担布局、像素和原生控件验收。
- 应用 Vitest 用例从 `tests/fixtures/附件兼容/` 读取一像素 PNG、中文 PDF 和 Office 兼容样本，或在临时目录合成文档。PNG 与 PDF 是本项目合成的样本，PDF 使用 `UniGB-UCS2-H` 离线 CMap。应用全量测试无需 `reference/`。
- 本地环境前提：`TEMP`/`TMP` 路径不得包含以 `.` 开头的隐藏目录（如某些沙箱的 `.t3`），否则网页预览敏感目录守卫会拦截临时夹具；无外网代理时运行 `tests/integration/tools.test.ts` 需确保 `rg`/`fd`（如 `~/.cogent/pi/bin`）在 `PATH` 中，避免下载超时。
- 独立的正文文件与文档渲染 Electron 探针仍使用参照仓样本，按[参照仓说明](../架构.md#reference-源码参照)准备。

## 运行与验收

日常验证范围与完整四关触发条件见[约定](../约定.md#14-验证范围)，建议使用 Node 24。常用定向命令如下：

| 检查 | 命令 |
| --- | --- |
| diff 与空白 | `git diff --check -- <变更文件>`，并阅读 diff |
| 文档链接、锚点与入口 | `node scripts/check-docs.mjs`（扫描仓库文档） |
| 变更的 TS/TSX 文件 | `npx eslint <变更文件>` |
| 变更的渲染层字号 | `node scripts/check-typography.mjs <变更的渲染层文件>` |
| Node 侧类型 | `npx tsc --noEmit --composite false -p tsconfig.node.json` |
| 渲染层类型 | `npx tsc --noEmit --composite false -p tsconfig.web.json` |
| 定向行为测试 | `node tests/run-tests.mjs run --project <node或web或integration> <测试文件或目录>` |

共享代码或协议变化按消费者选择受影响的 TypeScript 工程。纯 CSS 无需交给 ESLint；布局与像素变化使用对应专项验收。
定向源码测试无需先 build；集成产物的新鲜度由[测试边界](#测试边界)所述 global-setup 负责。

PR 与 main push 的全量检查由 CI 执行。需要完整本地验收时，按以下顺序执行；安装步骤仅在依赖未就绪或变化时运行，专项探针按改动范围选择：

```powershell
npm ci
npm --prefix docs/架构地图 ci
npm run lint
npm run typecheck
npm run build
npm test
node scripts/check-workspace-close-electron.mjs --smoke
node scripts/check-authorization-electron.mjs
node scripts/check-project-roots-electron.mjs
npm --prefix docs/架构地图 test
npm --prefix docs/架构地图 run build
```

根 lint 先跑字号检查和文档检查（`scripts/check-docs.mjs`），再检查架构地图源码。文档检查核对链接、锚点、
入口可达性和带文档名的章节引用，缺失即失败；行数超出约定 §4 的预算只提示，指向 `reference/` 的链接不检查。
架构地图有独立类型检查、布局测试和构建，生成的 `dist/` 不参与 lint。
实现交付及补测义务见[约定](../约定.md#13-交付自检)，上述命令清单不作为每次小改的必跑列表。

- 全量：`npm test`；日常监听：`npm run test:watch`（node + web）。
- 单层：`node tests/run-tests.mjs run --project web`；单文件在命令末尾追加路径。
- 覆盖率：`npm run coverage`，只观察，不设数字门槛。
- 主题基准：`npm run theme:check`；真实 Electron 样式：`npm run test:theme-browser`，
  驱动自行启动并关闭临时 Vite、窗口和 profile，不访问用户偏好。字号与输入按钮的浏览器
  入口见[设置页手测](../测试用例/设置页.md)与[消息呈现手测](../测试用例/消息呈现.md)。
- 聊天真实布局：`npm run test:chat-layout-browser`，隔离运行完整 HomeChat 的响应式布局与工作行
  可见性回归；包含偏离窗口原点的面板、长短内容、码表走时、阅读切换与终态清理。
- 侧栏开合：`npm run test:sidebar-animation-browser`，真实 Electron 逐帧检查导航行高与反向开合，
  并在完整 AppShell 连续绘制中比对静止图标像素，验证 300 条会话的屏外渲染、滚动与聚焦恢复；
  `--profile` 独立输出前后性能对照，矩阵与手动边界见[工作区与项目验收](../测试用例/工作区与项目.md)。
- 文件完整链路：build 后执行 `npm run test:file-links-electron`，隔离运行产品 main/preload/renderer/Host，
  本地模拟模型产生正文链接，验证实际文件预览、PDF 页面、Office 与响应式；证据和人工边界见[正文文件链接验收](../测试用例/正文文件链接.md)。
- 提示音输出：`npm run test:notify-sounds-browser`，隔离验证开发与构建file页的实际解码、
  输出预热与挂起恢复；驱动静音，蓝牙设备听感仍需按[设置页手测](../测试用例/设置页.md)验证。
- 菜单像素：`node scripts/check-menu-separators-browser.mjs`，按四档 DPR 比较实际截图的线宽与颜色；
  覆盖范围与参数见[菜单分隔线笔记](../技术笔记/菜单分隔线.md)。
- 输入控件：`node scripts/check-input-group-browser.mjs`，核对三档字号按钮尺寸与明暗两套聚焦边界，
  包括自定义项目名称输入、审批/询问/方案卡及其内嵌输入无描边，普通表单与卡内按钮保留描边，
  内嵌输入的上下键仍交还卡体焦点。真实鼠标点击聊天空白后按 Shift，视口保持无描边，
  PageUp 仍能滚动，消息内按钮保留焦点提示。
- 运行时升级的浏览器验收使用实际 Electron：聊天走时夹具取近期时间戳；皮肤宽窄场景
  显式给出预期列数，避免小时档省秒或分数 DPR 的视口舍入造成误报。
- 打包与产物冒烟：`tests/electron/packaging/packaging.test.ts` 与 `app-paths.test.ts` 校验配置 Schema、闭包收口与路径分流；`node packaging/build.mjs --win-only --smoke` 对实际 `win-unpacked` 执行隔离冷启动冒烟（验证 Host 使用随包 Node 22 及 preload IPC）。
- 会话搜索：`node scripts/check-session-search-electron.mjs` 跑生产产品链，
  `resources/runtime/win-x64/bin/node.exe scripts/check-session-search-capacity.mjs` 跑合成磁盘容量；
  覆盖和未测范围见[搜索验收](../测试用例/会话搜索.md)。
