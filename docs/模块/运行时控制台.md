# 运行时控制台

> 引擎运行时的观测基础设施：pi hooks 旁路记录、独立回看窗口与落盘。
> 落点：`src/host/runtime/inspector.ts`、
> `src/host/storage/inspect-store.ts`、
> `src/electron/main/ipc/console.ts`、`src/renderer/src/features/console/`。

## 观测通道（四层）

- 接口层：pi 原生 hooks（onPayload 发送前厂商请求对象 / onResponse 响应头 /
  onProviderStreamEvent 归一化前已解析厂商事件）经 AgentOptions 透传；它们
  不提供实际 HTTP 方法、URL、请求头、SDK 重试明细或线上 SSE 原始字节。
  POST 是展示标签，首块延迟是首个可观察事件的延迟，并非首个正文 token 延迟；
  onPayload先等待原回调的异步变换，附件额度检查通过后记录有效请求对象；超额不记为已发送请求。
- 引擎层 / 工具层 / 会话层：translateEvent 旁路（turn/tool/run 边界 +
  AgentState.systemPrompt）。

## 记录器（SessionInspector，常开）

- 摘要 ring 500 条 + 详情 ring 150 条；JSON 序列化块在 300K 字符处截断并
  在原文尾部标记，提示词文本与聚合分片没有同一截断限制。大 payload 不走
  摘要事件流，按需拉详情；详情被淘汰时明确返回缺失错误，不返回伪造的空块；
- 落盘 `~/.cogent/inspect/<id>.jsonl` 追加式（尾部 500 条可回看，重启接续
  seq/run 编号）；记录器惰性建。

## 窗口

- 独立 DevTools 窗口（`ipc/console.ts` 单例 + `console:open` IPC）；渲染
  入口 main.tsx 按 hash `#console` 分流到 features/console；
- 主窗口左下角设置菜单的“运行时控制台”项调用 `openConsole`；
- 重复打开复用原窗口；最小化时先恢复再聚焦，普通或最大化时直接聚焦；关闭后可重建；
- 引擎事件转发 getAllWindows 广播（控制台窗口与主窗口共用消费）；
  window 域 IPC 按 event.sender 寻址（两窗口共用窗口控制）。

## UI（features/console）

- [会话侧栏 | run 分组时间线 | 详情面板] 两级分栏；时间线按 run 分组独立折叠、
  四层过滤、实时跟随。Run 状态从未过滤记录判断，缺少终态且未观察到实时运行
  时显示“未见终态”；首条 seq > 1 时提示仅留存尾部。初载快照与实时事件按 seq
  归并去重，避免快照晚到时丢失历史；Run 状态位于折叠按钮内，点击状态也能开合；
- 详情将概览、说明和记录标识集中进“记录信息”，字段和值统一用两列表格展示，
  类别与时间也归入表格，长值可换行；有详情时默认收起；数据块独立折叠，
  切条目重置开合。长代码与原文在块内滚动，搜索栏留在编辑器顶部，滚动到边缘
  不带动详情页；详情页负责区块间导航。高度配方见[UI布局](../UI布局.md)；
- `turn.completed` 从已留存的 assistant JSON 提取正文，按原字符展示为“完整回复”，
  可搜索、复制，保留换行、反引号和 Markdown 写法；思考独立折叠，存在正文时原始 JSON
  默认收起。截断或格式不符时明确提示无法提取，原始记录仍可查看；
- `run.completed` 入口复用同 run、完成记录之前最后一个 `turn.completed` 的详情，
  显示来源编号，旧记录同样可读；不跨 run、不回退到更早一轮冒充最终回复。
  源详情缺失照常报错，快照没有对应轮终记录时只展示概览。
  ```text
  owner: console store（选择与详情缓存），ConsoleDetail（展示）
  选择 run.completed → 定位同 run 最后轮终 → inspect.entry(source.seq)
    → 缓存源详情 → 正文 / 思考 / 原始 JSON（完成条目仍保持选中）
  切条目 / 会话 → 迟到错误不覆盖新选择；跨会话响应不入缓存
  ```
- JSON/文本共用按需加载的只读 CodeMirror；JSON 节点折叠、层级菜单、
  搜索、换行开关、原文视图和复制都作用于留存字符串，不经 JSON 数值转换。
  JSON 默认展开2层，根对象/数组算第1层，可选展开1–5层或全部展开/折叠；
  未闭合的截断容器保持展开，采集尾标不参与 JSON 层级解析。
  标题行集中层级/搜索/复制，更多菜单显示字符数、行数与格式并切换原文/自动换行；
  折叠内容保留挂载以保留搜索与折叠状态。识别采集截断标记并提示复制只含留存部分，
  复制失败原位显示。记录 seq/run/kind/时间戳可对账；
- 整窗 select-text（观测内容可复制）。
- 界面文字遵循公共字号阶，代码查看与原文共用外观设置的代码字号；窗口首次加载及
  主窗口改设置时由公共外观投影同步，搜索/复制等工具栏仍使用界面字号。

## 协议接口

`inspect.event`（实时摘要流）/ `inspect.entries` / `inspect.entry`（按需详情）。

- 验收：杀引擎重启后控制台能回看落盘条目（seq/run 编号接续）；大 payload
  只在详情面板按需出现、时间线摘要流不卡；四层过滤各只剩本层条目；
  主窗口与控制台窗口的窗口控制钮都作用于自己；控制台最小化后，点击左下角设置菜单入口
  能恢复并聚焦原窗口。
- 验收：POST 请求体和 turn 终态 JSON 可逐节点或按层级折叠、搜索、复制；
  长分片在块内滚动，搜索末尾命中时搜索栏仍可见，最后一行能完整滚入可视区；
  点击 run 完成能直接查看、复制最后一轮完整正文，历史记录与新记录同口径；
  状态与Run折叠条一体，过滤会话层不改变终态。
  自动与手动步骤见 [运行时控制台验收](../测试用例/运行时控制台.md)。
