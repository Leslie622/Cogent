# 运行时控制台

> 引擎运行时的观测基础设施：pi hooks 旁路记录、独立回看窗口与落盘。
> 落点：`src/agent-service/runtime/inspector.ts`、
> `src/agent-service/storage/inspect-store.ts`、
> `src/electron/main/ipc/console.ts`、`src/renderer/src/features/console/`。

## 观测通道（四层）

- 接口层：pi 原生 hooks（onPayload 厂商原生请求体 / onResponse 响应头 /
  onProviderStreamEvent 归一化前 SSE 分片）经 AgentOptions 透传，零魔改；
- 引擎层 / 工具层 / 会话层：translateEvent 旁路（turn/tool/run 边界 +
  AgentState.systemPrompt）。

## 记录器（SessionInspector，常开）

- 摘要 ring 500 条 + 详情 ring 150 条 + 单块截断 300K（大 payload 不走
  事件流，按需拉详情）；
- 落盘 `~/.cogent/inspect/<id>.jsonl` 追加式（尾部 500 条可回看，重启接续
  seq/run 编号）；记录器惰性建。

## 窗口

- 独立 DevTools 窗口（`ipc/console.ts` 单例 + `console:open` IPC）；渲染
  入口 main.tsx 按 hash `#console` 分流到 features/console；
- 引擎事件转发 getAllWindows 广播（控制台窗口与主窗口共用消费）；
  window 域 IPC 按 event.sender 寻址（两窗口共用窗口控制）。

## UI（features/console）

- [会话侧栏 | run 分组时间线 | 详情面板] 两级分栏；时间线按 run 分组折叠 +
  四层过滤 + 实时跟随；详情 = 学习注释（kinds.ts 呈现映射）+ 概览表 + 数据块；
- 整窗 select-text（观测内容可复制）。

## 协议接口

`inspect.event`（实时摘要流）/ `inspect.entries` / `inspect.entry`（按需详情）。

- 验收：杀引擎重启后控制台能回看落盘条目（seq/run 编号接续）；大 payload
  只在详情面板按需出现、时间线摘要流不卡；四层过滤各只剩本层条目；
  主窗口与控制台窗口的窗口控制钮都作用于自己。
