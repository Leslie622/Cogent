# 消息呈现

> 对话流的功能呈现层：回合分组两态、消息渲染、工具卡与各类轨迹行。
> 落点：`src/renderer/src/features/home/{TurnGroup,MessageRow,HomeChat}.tsx`、
> `src/renderer/src/components/ui/{run-trace,tool,markdown,reasoning}.tsx`。

## 回合分组与两态（TurnGroup）

- **渲染期分组**（store 保持平铺）：`groupTurns` 相邻分组、`splitTurn` 把回合
  切成过程段与终答段（末条有正文 = 终答，其 thinking/usage 剥入过程）、
  `sumUsage` 回合聚合用量；
- 两态：**live** = 过程摊开直播 + 输出位置常驻「工作中」行（spinner + 每秒
  计时）；**done** = 过程收进「已工作 Xs」头条 + 终答常驻 + 聚合用量一行
  （时长不双记）；终答开流即折叠（不等 run.completed），正文后再来工具调用
  则回直播态；
- 无过程回合（单段纯文本）不挂头条，直出；
- 末回合相位由会话级运行位推导：live > stopped > failed > done；历史回合恒 done；
- 中止不是错误：占位改名封存半截正文 + 「已停止」头条（默认展开防半截被藏）；
  真失败 = 错误条 + 「出错了」头条；
- 压缩条自起无头组，在 summarizedUntil 锚处**原位中插**（保留式，历史不删），
  见 [上下文压缩.md](上下文压缩.md)；
- 验收：中止的回合显「已停止」且半截正文保留（无错误条）；失败回合显
  「出错了」；同型工具一运行一完成时无需悬停可区分；无过程回合无头条
  直出；切换会话再回来分组与用量行不重算错位。

## 单条消息（MessageRow）

- memo 挡历史消息逐 token 重解析；用户消息灰气泡 + 时间戳/复制，助手平铺；
- UsageLine：`↑ 输入 · ↓ 输出 · 缓存读/写 · $ 成本 · 时长`（零值省略、
  tabular-nums、时长 `(ms/1000).toFixed(2)s` 单一实现 formatDuration、
  目录估价带 ≈ 前缀），见 [用量与成本.md](用量与成本.md)；
- 思考（Reasoning 组件）：思考中自动展开 + shimmer，正文开始自动收起，
  手动开合以用户为准；完成态「深度思考」标题可折叠。

## Markdown 渲染（components/ui/markdown.tsx）

- Streamdown 封装（base-luma 无此件故手写）：remend 修复流式未闭合块 +
  块级 memo；Shiki 高亮语言懒加载分包；@streamdown/cjk CJK 友好解析；
- 链接点击改道 `window.open` 走 setWindowOpenHandler 守卫（Electron 裸 `<a>`
  窗口内导航无人拦）；等宽字体 JetBrains Mono 走 `--font-mono`。

## 工具卡（components/ui/tool.tsx）

- 四态：运行中 = 单行 shimmer 不可折叠（+ progress 直播尾行，100ms 节流的
  尾部快照）；完成/失败 = 可折叠 CodeBlock 展示输出（失败 destructive 变体）；
  拒绝 = 置灰单行；edit 工具带 +绿−红 DiffBlock；
- 数据形状 `ToolCallRecord`（kind/summary/status/resultSummary/diff），
  流式与历史回查双路径同源。

## 审批呈现

- 待审批：ApprovalPanel **替换输入区**（五件套竖排选项列表，见
  [审批与权限.md](审批与权限.md)）；
- 已裁决：终态痕迹行（approved/denied/cancelled 的 TraceLine）留存消息流
  （转录无对应物，纯 UI 痕迹）。
