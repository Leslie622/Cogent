# 正文文件链接

聊天正文、已知文件名和工具明确路径共用 FileLink，点击打开当前文件。产物申报和交付副本见[产物文件卡片](产物文件卡片.md)；工作区快照和改动列表不属于本模块。
原理和上游对照见[文件引用笔记](../技术笔记/文件引用与改动追踪.md) §9，人工步骤见[验收册](../测试用例/正文文件链接.md)。

## 来源与路径

- 用户 submit 的 inputId 同时作为 turnId，纯文本与附件均绑定真实 pi user entry；内部续写不新建来源。
  factory 在 appendMessage 返回后写 `cogent.file-context.v1`，保存 entry、cwd、根集合和平台。
  会话域的可选 piCwd 固定转录目录锚点；项目根变化不改这个锚点。
- 历史读 JSONL 时把来源关联到相应用户与助手段，保留原 u-N/a-N、压缩和附件投影。
  无元数据的旧相对链接按当前工作区解析并提示；有 turnId 却没有记录则报错，不猜来源。
- 成功 read/write/edit 的结构参数经实际工具 cwd 解析，`cogent.file-refs.v1` 按 callId 保存；
  直接与嵌套结果均可观测，父工具汇集子调用引用。失败不登记，不从 shell/MCP 文本或摘要猜路径。
- `shared/file-target.ts` 拆 URI、定位和单次百分号解码；`host/runtime/files/paths.ts` 按原平台解析。
  支持相对路径、Home、盘符、UNC、file URI、行列和行范围；`:2:3`、`#L2C3`、`#L2:C3`、`#L2:3` 等价，裸 //host/path 保持网页语义。

验收：纯文本、附件和准备期停止均能回读实际 entry/cwd；重启后的 read 引用与实时事件一致。
异平台绝对路径、坏转义和未知来源明确失败，无效位置保留文件预览与原因。

## 渲染与当前文件服务

- Markdown 完整默认 remark/rehype 管线保留；本地目标在 URL 清洗前变成内部片段载荷。
  Windows destination 用原文切片和 CommonMark 反转义校验恢复，支持 title/尖括号。
  本地图片先变内部链接，清洗后交给 FileImage 按 ID 取 Blob；不放宽默认图片 URL 策略。
- 反引号匹配本回合成功read/write/edit及有效产物声明的精确路径或唯一文件名，支持字面百分号等字符；围栏、未知项和歧义保留。
  产物声明词表随完整替换/清空更新，已有read/write/edit引用保留；正文链接仍打开当前原件。
  词表插件有独立缓存身份，词表变化经 Streamdown 的 data 属性触发重解析，不更换正文 key；流式、终态和历史使用同一规则。
  FileLink 在点击时 resolve，悬停/键盘聚焦按需取完整路径提示，不逐 token 探测磁盘。
  HTTP(S) 交系统浏览器，脚注保留文内跳转，未知协议与未完成流式链接不可打开。
- `FileService` 按会话登记随机 fileId 和服务代次，登记别名与真实目标；每次读取/原生动作复核会话与符号链接。
  分片前后及文件句柄校验版本，变化即中止；链接读取当前文件，不保存历史内容。
- `files.resolve/readText/readChunk/parseDocument/cancel` 只经主窗口顶层帧白名单；
  main 专用 `files.actionTarget` 不暴露给 renderer；HTTP/WS 拒绝整个 files 域。
- 同时最多两个读取任务，分片 256 KiB；文本 20 MiB、图片 20 MiB/4000 万像素、PDF/Office/媒体 100 MiB。
  UTF-8/UTF-16 跨片字符完整解码，二进制和未知编码报错；文档 worker 沿用两路与 30 秒超时。

验收：真实 Streamdown 的相对路径、Windows/UNC、脚注、流式闭合和既有渐显回归通过；
跨会话借用 ID、坏载荷、版本变化、取消和 HTTP/guest 越界均被拒绝。

## 预览与桌面动作

文本使用只读 CodeMirror，支持搜索、行列/范围定位并显示已确认的位置；JSON、JavaScript/TypeScript 语法按需加载。
Markdown 可切源码/渲染，本地依赖相对源文件目录，外部图片不自动加载。
图片支持缩放/适配；PDF.js 逐页绘制并附离线 CMap/字体/WASM；Office 明确标注结构内容预览并提供工作表/范围/分页。
音视频使用预算内 Blob 与原生控件，不能解码时提示系统打开；HTML/脚本只看源码。

```text
owner: Host = 来源/目标/有界读取；main = 原生动作；file-preview store = 当前预览与请求代次
点击 → resolve → fileId/version → 文本、worker 或 Blob → 右栏（≤1100px 为 Dialog）
切文件/会话、关闭 → 换代 + cancel + 回收 URL；迟到结果不回写
Host 关闭 → main 发 files.invalidated → 关闭旧预览；正文下次点击重新 resolve
原生动作 → 主窗口/载荷校验 → Host 复核 fileId → 固定动作
```

复制使用已解析的绝对路径；定位、系统打开、另存、编辑器打开走独立 IPC。
另存取消返回 canceled；系统打开错误原样显示。编辑器在文件菜单选择 VS Code/Cursor 可执行文件，
路径存 settings.fileEditor，使用固定 spawn 参数数组且不开 shell，确认进程启动即返回。

验收：真实产品 Electron 可打开源码、Markdown 本地图片、图片、PDF 页面、三类 Office、WAV 和目录，
400px 的三档缩放使用 Dialog，宽窗恢复右栏且不残留遮罩；原生应用、目标 Linux 与人工阅读观感另按验收册验证。
