## 按任务追链

| 从哪里遇到问题 | 沿哪条链查 | 代表性验证 |
| --- | --- | --- |
| 启动遮罩、Host 启动或握手失败 | [应用启动](应用启动.md) → `HostManager.start` → `host-main.ts` 的 `initialize` | [启动集成测试](../../tests/integration/host-startup.test.ts) |

| 搜索结果遗漏或跳不到原消息 | [会话搜索](会话搜索.md) → 搜索 worker → `stores/search.ts` → Home 搜索面板 | [搜索集成测试](../../tests/integration/session-search.test.ts) · [搜索手测](../测试用例/会话搜索.md) |
| 模型连通性或 Provider 配置 | [凭据与模型目录](凭据与模型目录.md#模型连通性测试) → `stores/engine.ts` → `runtime/model-connectivity.ts` | [连通性集成测试](../../tests/integration/model-test.test.ts) · [设置手测](../测试用例/设置页.md) |
| MCP 配置或外部 Agent 调用 | 配置工具服务查 [MCP 座](MCP座.md) 与 `mcp-config.ts`。外部 Agent 调 Cogent 查[对外 MCP](对外MCP.md)与 `mcp-server/`，再追 [HTTP 通道](HTTP通道.md) | [消费外部工具](../../tests/integration/mcp.test.ts) · [对外工具](../../tests/integration/external-mcp.test.ts) |
| 文件打不开、预览错位或权限异常 | [正文文件链接](正文文件链接.md)或[产物文件卡片](产物文件卡片.md) → [工作区上下文与租约](多标签工作区.md#文件上下文与lease) → [文件预览](文件预览渲染.md) | [正文文件链路](../../scripts/check-file-links-electron.mjs) · [文件预览手测](../测试用例/文件预览渲染.md) |

| 目标图节点、流程或布局 | [交互图说明](../架构地图/README.md) → C4 模型、视图布局、模块说明与网格路由 | [布局与保真测试](../架构地图/tests/布局适配.test.ts) · [浏览器验收](../../scripts/check-architecture-browser.mjs) |

## 常见改动配方

| 改动类型 | 最小修改链（按顺序） | 守卫与验收 |
| --- | --- | --- |
| 新增 RPC 方法 | `src/protocol/domains.ts` 或 `types.ts` → `src/protocol/method-access.ts`（编译期必补）→ `src/host/host-main.ts`（边界校验 + 注册）→ `src/renderer/src/env.d.ts`（若对 UI 开放） | `npm run typecheck` + `tests/shared/method-access.test.ts` |
| 新增 Electron 特权 IPC | `src/shared/ipc.ts` → `src/electron/main/ipc/`（经 `handleTrusted` 注册，校验角色与参数）→ `src/electron/preload/index.ts` → `src/renderer/src/env.d.ts` | `tests/electron/main/ipc/trusted.test.ts` |
| 新增设置项 | 先定归属：界面/壳偏好走 `main/ipc/settings.ts`；业务默认/供应商走 `host/runtime/business-config.ts`，不得双写 | [业务配置](业务配置.md) · [设置页](设置页.md) |
| 拆解或修改 Host 存储 | 保持 `StorageDriver` 同步契约与 `${file}.tmp` 故障注入约定（单写者由 `acquireStorageLease` 保证） | `tests/integration/create-persistence.test.ts` |
