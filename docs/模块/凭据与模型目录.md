# 凭据与模型目录

> API key 的存取链路与模型目录的自定义体系（内置目录 / override / 自定义 provider）。
> 落点：`src/electron/main/credentials/store.ts`、
> `src/agent-service/runtime/{credentials,custom-providers}.ts`、
> `src/renderer/src/features/settings/`（ModelsSection）、
> `src/renderer/src/features/home/{ModelMenu,ThinkingSlider}.tsx`。

## 凭据链路

- main 侧 safeStorage 加密落盘 `~/.cogent/credentials.json`；握手时全量注入引擎；
- 引擎内存表（runtime/credentials.ts）：key 只进不出；
- 协议：`credentials.set`（写入+进表）/ `list`（批量只回布尔位）/ `get`
  （按 provider 单取**明文**，设置页字段全量回显用——脱敏方案被否，点眼睛
  看明文）/ `remove`（真删，「清除」不是写空串）。

## 自定义 provider（runtime/custom-providers.ts）

- `createProvider` 构建 OpenAI-compatible provider（id `custom/<slug>`）+
  `setProvider` 运行时注入 + 内置 provider baseUrl 覆盖（闭包委托原实例）；
- 三方言：`openai-completions` / `openai-responses` / `anthropic`；baseUrl
  规则：openai 系带 `/v1`、anthropic 根地址；
- 定义落盘 `~/.cogent/custom-providers.json`（明文，与 key 分离）；
- 协议 `providers.custom.sync`（全量替换语义；renderer 写路径唯一化走
  custom-providers:set，防盘上/内存态分叉）。

## 模型自定义（ModelDef / override）

- `ModelDef`：id/name/contextWindow/maxTokens/input/reasoning/thinkingLevels；
- 内置目录 override：`ProviderOverrideDef.models`（用户新增，与目录并存）+
  `disabledModels`（目录禁用）+ baseUrl 空串 = 只调模型不动端点；
- 同 id 覆盖 = **merge 语义**（目录基底 + 用户显式字段覆盖，cost 永远继承
  目录、全新 id 诚实 0）；目录行可编辑（shadow 目录同名项，可删除还原）；
- 同名模型跨 provider 歧义：`agent.submit` 带 optional `provider`，引擎
  `getModel(provider, id)` 双键限定；
- **显示一律模型 id**（目录营销名不参与呈现，所见即所传）；
  `ModelSummary.userDefined` 标用户自建；默认（目录原生）模型编辑时 id 只读；
- 上下文窗口滑杆：线性轴 200K/400K/1M 三档吸附（ContextWindowSlider =
  components/StopSlider 通用件的域适配层）。

- 验收：同一模型在聊天菜单、设置页两处显示完全一致（均为 id）；key 输入
  后字段全量回显、清空 = 真删（remove）；同名模型跨 provider 不串（带
  provider 双键）；自定义 provider 三方言各能走通对应端点（baseUrl 规则
  注释与行为一致）；编辑目录原生模型时 id 不可改。

## 思考（Reasoning）档位

- `ThinkingLevelWithOff`（支持档不含 off 的口径区分）；引擎按目录
  thinkingLevelMap 判定真实可用档（getSupportedThinkingLevels）；
- 滑杆按支持档渲染（不支持档置灰+删除线）、切模型就近 clamp（先高后低）；
  会话级 thinkingLevel 随 agent.submit 下发。

## 聊天页模型菜单（ModelMenu）

- 厂商子列表**钻入式**（DropdownMenuSub：厂商行 → 模型子面板，点模型提交
  并全关）；只展示配了 key 的 provider 的模型；思考力度渐变滑杆同菜单。

## 协议接口

`credentials.*` / `providers.custom.sync` / `models.list`；类型
`ModelDef / ProviderOverrideDef / CustomProviderDef / ModelSummary /
ThinkingLevel(WithOff)` 见 `src/protocol/types.ts`。
