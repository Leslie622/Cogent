# 工具系统

> 引擎侧文件/shell 工具族：注册、路径边界、输出护栏与并发安全。
> 落点：`src/agent-service/tools/`。

## 注册表（tools/index.ts）

- `buildTools(toolRoots)` 按基根现建：绑定根 ?? 用户主目录 —— 任何会话都有
  工具（主目录 = 桌面应用语境的 launch cwd）；
- pi AgentTool 无 kind 字段，包 `CogentTool{tool, kind, summarize}`；
  `TOOL_METAS` 静态元数据表（kind/摘要）供历史回查投影，不依赖活实例；
- 系统提示词恒带工具段（相对路径基根声明，无绑定时明示主目录 + 写入规则）。

## 工具清单与路径边界

| 工具 | kind | 边界 |
| --- | --- | --- |
| read / glob / grep / ls | 只读 | **不限界**（双口径 resolveAgainstBase，绝对路径可读工作区外） |
| write / edit | 写 | 软限界 `resolveWithinRoots`（越界返回 error 结果带可写根提示，模型可自我纠正） |
| bash | exec | 平台路由（tools/shell.ts）：Windows = PowerShell 系统必有，unix = bash；description 按平台声明方言 |

- path.ts：`~` 展开；小写化前缀比对补 sep（防 `work` 误放行 `work-x`）；
- walk.ts 共用枚举器：BFS + 尊重 .gitignore/.ignore（`ignore` 包层叠 + 嵌套
  仓边界 + 祖先 up-walk）+ node_modules/.git/AppData 等忽略 + 2 万文件截断。

## 输出护栏三件套

- `truncate.ts`：head/tail/line 双上限统一截断器（30KB 总量封顶、显式
  [truncated] 标注）—— read/grep/glob 的零散上限已迁移统一到这；
- `output-accumulator.ts`：bash 流式滚动窗口，超限转存临时文件（尾部保留）；
- `output-files.ts`：临时转存文件 0o600/wx 收口。

- 验收：绝对路径读工作区外成功（只读不限界）；越界写得到 error 结果且
  带可写根提示（非静默失败）；同批 4 个并发写同文件内容不交错；
  node_modules 与 .gitignore 命中项不出现在 glob/grep 结果；超长 bash
  输出被截断且标注 [truncated]、转存文件 0o600；abort 后无孤儿进程。

## 并发与进程安全

- `file-mutation-queue.ts`：realpath 键的 Promise 链 —— write/edit 落盘段
  入队，pi 并行执行同批工具时同文件写串行化（不同文件不互斥）；
- bash：killProcessTree（taskkill /T / 进程组 SIGKILL）+ detached 登记 +
  引擎退出清场钩子；超时杀树（exit code 128+信号号语义）；abort 杀树。

## edit（tools/edit.ts + edit-diff.ts）

- LF 归一化匹配 + 模糊匹配回退 + CRLF 偏移映射写回 + 窗口化 diff；
- diff 进协议（ToolCallRecord.diff? + tool.completed diff?），工具卡渲染。

## 协议接口

事件 `tool.started / tool.progress（尾部 2000 字符快照，100ms 节流）/
tool.completed（含 diff?）`；投影 `ToolCallRecord`。审批拦截不在这层 ——
工具只管执行，判定矩阵在 session 层（见 [审批与权限.md](审批与权限.md)）。
