# 工具系统

> 工具执行面 = **pi 内置 8 工具选 7**（阶段 1.3，D6 自研工具删除）；
> Cogent 侧只剩策略投影：工具名 allowlist、ToolKind 协议投影、写类软边界。
> 落点：`src/host/kernel/pi-session-factory.ts`（装配）、
> `src/host/runtime/{tool-meta,write-boundary}.ts`（策略）、`session.ts`（审批接线）。

## 工具集与命名映射（runtime/tool-meta.ts）

- `COGENT_TOOL_NAMES` = read / **powershell（win）或 bash（其他）** / edit /
  write / grep / find / ls —— 经 createAgentSession 的 `tools` allowlist 显式
  指定（替换 pi 默认的 read/bash/edit/write 四件）；
- 自研名 → pi 名：**glob → find**；bash 在 win 由 powershell 替代（无 Git
  Bash 的 win 机不再依赖系统 bash）。旧转录里的 `glob` toolCall 块由静态
  表的历史条目兜住（kind 同只读）；
- ToolKind 是 Cogent 的产品语义 + 协议兼容投影（`tool.*` 事件与
  ToolCallRecord 都带 kind）：read/grep/find/ls → read，write → write，
  edit → edit，bash/powershell → exec。pi 内置工具不带 annotations
  （D8 勘误：上游无此信息），静态表是唯一 kind 源 —— 未装配内核的惰性
  会话历史回查也依赖它（那时无工具实例可查）。

## 与自研时代的语义对照（迁移要点沉淀）

| 维度 | 自研（已删） | pi 内置（现行） |
| --- | --- | --- |
| 文件搜索 | glob（walk.ts，node 遍历） | find（spawn fd；PATH → `PI_CODING_AGENT_DIR/bin` 自动下载） |
| 全文搜索 | grep（node 扫描） | grep（spawn rg，同上获取链） |
| 读截断 | 64KB / 2000 行自研文案 | 50KB / 2000 行，`[Showing lines … Use offset=…]` 续读指引 |
| grep 长行 | 同款 `... [truncated]` | 500 字符上限同款标注（上游同源） |
| shell 平台路由 | bash 名下路由 PowerShell | win 就叫 powershell（工具名即方言） |
| 输出护栏 | truncate/accumulator/output-files 三件套 | pi OutputAccumulator（尾保留 + 转存临时文件 + `Full output` 提示） |
| 并发写队列 | file-mutation-queue | pi withFileMutationQueue（同设计） |
| 写边界 | 工具执行层 resolveWithinRoots | **审批层**（见 [审批与权限.md](审批与权限.md)，判定优先序不变） |
| 引擎退出清场 | detached 登记杀树 | 无（pi 只管 abort/超时杀；unix 上引擎退出时在跑命令留孤儿是上游语义） |

## 外部二进制依赖（fd / rg，部署事实）

- find/grep 分别 spawn `fd` / `rg`：先查 PATH（fd 兼容 `fdfind`），没有则从
  GitHub releases 下载进 `PI_CODING_AGENT_DIR/bin`（Host 启动时把该 env 归位
  到 `<COGENT_HOME>/pi`，Host 保持 `~/.cogent` 唯一写者；`PI_OFFLINE=1` 关闭
  下载）；
- 两者皆不可得时工具返回 error 结果（`fd is not available…`），引擎不崩，
  其余工具（纯 node 实现）不受影响 —— 降级可见，不静默；
- 信创内网 GitHub 资产域不可达 = find/grep 不可用：缓解 = 分发期预置
  fd/rg（zcode 同款 SHA 固定下载思路，列后期批次），风险登记见计划 §9。

- 验收：win 上 shell 工具名为 powershell 且 UTF-8/#8842 语义正确
  （ps-utf8 冒烟对 pi 工具端到端）；read 截断带 offset 续读指引；同批并发写
  同文件内容不交错；越界写/edit 被审批层软边界拦下（auto 模式仍恒拒）；
  abort 后无孤儿进程；fd 不可达时 find 返回 error 结果且引擎存活。

## 协议接口

事件 `tool.started / tool.progress（pi onUpdate 快照，尾 2000 字符）/
tool.completed（含 diff?——pi edit 的 details.diff）`；投影 `ToolCallRecord`
（kind/摘要取静态元数据表，历史名兜只读）。审批拦截不在工具层 ——
判定矩阵在 session 层（见 [审批与权限.md](审批与权限.md)）。
