# 技能座

> Host 侧管理多源技能目录（7 级发现 / 合并 / 两级启停 / 无损编辑 / 安全导入导出），
> 清单经 `before_agent_start` 段钩子**回合边界热刷新**，正文经**专用 `skill` 工具**与
> 用户显式触发统一由 `loadForExecution` 加载并完成非机密模板变量替换。原理与对照见
> [../技术笔记/技能座.md](../技术笔记/技能座.md)。

## 是什么 / 在哪

- store：`src/host/runtime/skill-store.ts` —— 7 级多源发现（bundled 内置垫底 + 用户/项目 `.cogent`/`.agents`/`.claude` + 向上扫至 `.git` 根 + 自定义额外目录，复用 pi `loadSkillsFromDir` 校验/ignore，同文件按 `realpathSync.native` 去重）+ 两级启停求值 + `save` 无损合并 frontmatter + `loadForExecution`（100KB UTF-8 截断、附属资源列举、变量替换、`<skill_content>` 外壳）+ `fflate` 安全目录/zip 导入与 zip 导出；
- 变量引擎：`src/host/runtime/template-vars.ts` —— 表驱动单遍替换 `${COGENT_SKILL_DIR}`/`${CLAUDE_SKILL_DIR}`、`${COGENT_PROJECT_DIR}`、`${COGENT_SESSION_ID}`、`$ARGUMENTS`/`$N` 等，正文恒 `allowSensitive: false`；
- 专用工具：`src/host/runtime/skill-tool.ts` —— pi `customTools` 注入 `skill({ name, args? })`，`tool-meta.ts` 归只读免审，前端 `tool.tsx` / `tool-display.ts` 呈现专属「技能」卡片，观测落 `skill.loaded`；
- 清单 formatter：`src/host/runtime/skill-prompt.ts` —— 导语指引调用 `skill` 工具，合并 `when_to_use`（250 字/条），不暴露磁盘 `<location>`，20k 总预算超限降级纯 `names-only` 与截断兜底；
- 打包与内置技能：`resources/skills/skill-creator/SKILL.md`，Electron 主进程经 `COGENT_BUNDLED_SKILLS_DIR` 传入 Host，`packaging/build.mjs` 随 `extraResources` 打包；
- 协议与特权 IPC：`skills.list` / `skills.read` / `skills.save` / `skills.delete` / `skills.setEnabled` 走白名单代理；`skills.import` / `skills.export` / `skills.revealTarget` 设 `rendererAllowed: false`，由 `src/electron/main/ipc/skills.ts` 弹窗选源后直调 Host；
- UI：设置页 `SkillSection.tsx`（作用域切换、高级设置与附带文件、行内警告/错误提示与不可用技能拦截、目录/ZIP 导入导出、打开目录、只读查看）+ 输入框 `ComposerLexicalEditor.tsx`（过滤 `user-invocable: false`，展示来源与 `argument-hint`）。

## 数据与生命周期

```text
resources/skills/<name>/SKILL.md              # bundled 内置层（垫底只读、不可删）
~/.claude/skills · ~/.agents/skills           # user 级生态兼容目录（只读）
~/.cogent/skills/<name>/SKILL.md              # user 级自有技能（可读写）
<祖先至 .git>/.cogent|.agents|.claude/skills   # project 级（近者胜，生态只读）
~/.cogent/skills.json                         # user 级禁用名单 { disabled: [] }
<工作区主根>/.cogent/skills.json               # project 级覆盖 { overrides: {} }
```

```text
skills.save / import / setEnabled（无损合并 + 原子写盘）
      │
每回合起始：before_agent_start → snapshotMany(绑定根) → formatSkillsSection
      │  pi sections diff 增量补丁（无变化保前缀缓存；压缩影子区保留已激活技能名）
      ▼
模型可见 <available_skills>（name + description/when_to_use）
      ├─ 模型匹配 → 调用专用 skill 工具 ──┐
      └─ 用户经 $ / /skill: 显式触发 ────┴─▶ SkillStore.loadForExecution
                                             （100KB 截断 + 变量替换 + 附属清单 + skill.loaded 审计）
```

## 边界

- **Token 安全红线**：`SKILL.md` 正文变量替换恒为 `allowSensitive: false`，Token 绝不替换进 Prompt 或转录；
- **`allowed-tools`**：静态无损解析保留并在详情只读展示，不接运行时审批引擎（审批归权限层，见决定 28）；
- **`` !`cmd` `` 与 `context: fork`**：正文静默跑 shell 违反审批边界不做；`context: fork` 无损保留并提示“主会话兼容”，待子会话座就绪后接通。
