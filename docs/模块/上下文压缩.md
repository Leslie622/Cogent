# 上下文压缩

> 压缩内核 = **pi AgentSession 内置**；Cogent 侧承接执行期 MCP 落盘、
> L1 压力裁剪、L2 中文黑盒摘要委托、压缩后资产恢复、参数自适应、事件转译、
> 预警线与保留式呈现。
> 落点：`src/host/kernel/pi-session-factory.ts`（settings 链式包裹 + 钩子接线）、
> `src/host/runtime/{compaction.ts,tool-spill.ts,session.ts}`、
> `src/renderer/src/features/home/{CompactionBar,ContextIndicator}.tsx`。

## pi 内置内核（发生了什么）

- **触发**：`占用 > ctx − reserve`（阈值路）+ 溢出路（context overflow /
  recoverable length：删失败轮 + 压缩 + continue 重试，**单次闸**）——全部
  发生在 prompt() Promise 生命周期内，`agent_settled` 是单一权威终态；
- **摘要请求**：被摘要消息文本化序列化进 `<conversation>` 标签（防续写
  手法）+ 指令作末条 user；切点从尾累计 chars/4 跨过 keep，user/assistant
  均可为切点，回合中段切点走 turn-prefix 摘要（split-turn）；
- **手动**：`session.compact` → pi compact；忙 / 无可压缩 → pi 拒绝原文
  （InvalidRequest 转译）。

## Cogent 承接面

- **执行期 MCP 大输出落盘**（`tool-spill.ts`）：`afterToolCall` 拦截非错误
  `mcp__*` 超 24K 文本返回，落盘至 `<hostRoot>/tool-outputs/v1/<uuid>.txt`，
  代理对安全保留头 16K + 尾 4K 并附内部读取路径（图片块原样保留，写盘失败降级截断）；
- **L1 零成本工具结果裁剪**（`compaction.ts` `planStaleToolResultPrunes`）：
  `before_agent_start` / `turn_end` 监测，仅达到 85% 压力线（或距阈值 2K）时
  才裁剪 5 轮前的超大非错误 `toolResult`（>8K 裁为头 4K+尾 1K，总节省 <256 tokens
  放弃），经 `appendContextEdit` 落盘，常规轮零破坏 Prefix Cache 且 UI 历史不受影响；
- **L2 中文黑盒摘要委托**（`session_before_compact` + `buildCompactionInstructions`）：
  合并简体中文结构化与黑盒静默约束及可选用户焦点指令，委托 pi 官方 `compact()`，
  凭据缺失时安全回落默认路径；
- **压缩后工作态恢复**（`buildShadowSessionAssetsSection`）：压缩后自动扫描影子区
  `cogent.attachment-input.v1`，经 `cogent_session_assets` 动态段恢复活跃附件与目录引用索引；
  附件记录与原件都在时带上 `path`，压缩后模型仍能用工具读取早期附件；
- **小窗自适应**：factory 链式包裹 `settingsManager.getCompactionSettings`：
  `keep = min(keep, ctx/2)`、`reserve = min(reserve, ctx/4)`（`adaptCompactionToWindow`）；
- **事件转译与预警线**：`compaction_start/end` → `compaction.started/completed`
  （含 `summarizedUntil`、`summaryUsage`）；`piTriggerRatio` 随目录同步引擎真值；
- **手动压缩与续写**：`session.compact` 支持可选 `instructions`（≤2000 字符），
  `ContextIndicator` 悬浮卡提供「压缩上下文」触发入口；`AUTO_CONTINUE` 续写上限 3 次。

## 保留式呈现

- 压缩记录 = pi 会话树 `compaction` 条目（append-only）；历史回查走
  `readPiTranscript` 全量回查（影子区/多代压缩条全保留），**压缩不删除
  被摘要区**，重拉历史不消失；
- 请求组装由 pi 投影裁掉影子区；上下文明细估算的转录整形
  （`convertToLlmMessages`）与预算同口径。

- 验收：压缩后折叠条原位出现、被摘要旧消息仍可滚动；重启回拉不缺内容；
  mock 请求体不含影子区消息；溢出走重试而非 run.failed（再溢出才失败）；
  忙时手动 compact 得 InvalidRequest；20K 小窗成功压缩占比过半即成
  （自适应 keep 生效）。

## 协议接口

事件 `compaction.started（reason）/ completed（summary 全文、tokensBefore、
tokensAfter?、summaryUsage?、summarizedUntil）`；method `session.compact`；
`ChatMessage.role = 'compaction'`（`compaction: { tokensBefore,
summaryUsage? }`）。四家对比见
[../技术笔记/上下文压缩.md](../技术笔记/上下文压缩.md)。
