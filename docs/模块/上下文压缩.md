# 上下文压缩

> 压缩内核 = **pi AgentSession 内置**；Cogent 侧只剩
> 参数自适应、事件转译、预警线与保留式呈现四件承接面。
> 落点：`src/host/kernel/pi-session-factory.ts`（settings 链式包裹）、
> `src/host/runtime/{compaction.ts,session.ts}`、
> `src/renderer/src/features/home/{CompactionBar,ContextIndicator}.tsx`。

## pi 内置内核（发生了什么）

- **触发**：`占用 > ctx − reserve`（阈值路）+ 溢出路（context overflow /
  recoverable length：删失败轮 + 压缩 + continue 重试，**单次闸**）——全部
  发生在 prompt() Promise 生命周期内，`agent_settled` 是单一权威终态；
- **摘要请求**：被摘要消息文本化序列化进 `<conversation>` 标签（防续写
  手法）+ 指令作末条 user；切点从尾累计 chars/4 跨过 keep，user/assistant
  均可为切点，回合中段切点走 turn-prefix 摘要（split-turn）；
- **手动**：`session.compact` → pi compact；忙 / 无可压缩 → pi 拒绝原文
  （InvalidRequest 转译）。

## Cogent 承接面

- **小窗自适应**：pi 默认 reserve/keep 固定（16384/20000），小窗
  （ctx ≤ keep）会「触发线早早响、压缩无可压缩收场」。factory 链式包裹
  `settingsManager.getCompactionSettings`：keep = min(keep, ctx/2)、
  reserve = min(reserve, ctx/4)（compaction.ts `adaptCompactionToWindow`）——
  标准窗零变化，20K 窗 → keep 10000 / reserve 5000，成功压缩显著提前；
- **事件转译**：`compaction_start/end` → 协议 `compaction.started/
  completed`（reason 含 threshold/manual/overflow）；`summarizedUntil` =
  保留区首条时间戳（firstKeptEntryId 反查会话树）；`summaryUsage` =
  摘要调用自身的账（事件侧 + 历史折叠条投影均可见）；
- **预警线 = pi 真实触发线**（compaction.ts `piTriggerRatio`，models.list
  目录随发）：`1 − min(16384, ctx/4)/ctx`（100K 窗 83.6%）—— UI 指示器
  预警线即引擎真值（画线偏离真值 = "未到线就压了"的观感）；
  ModelDef.compaction 用户覆盖为盘上兼容字段（pi 不读、引擎不消费，
  旧盘数据兼容保留）；
- **AUTO_CONTINUE 续写**（session.ts）：贴线 maxTokens 截断（pi 不恢复的
  场景）注入显式续写指令，上限 3 次。

## 保留式呈现

- 压缩记录 = pi 会话树 `compaction` 条目（append-only）；历史回查走
  `readPiTranscript` 全量回查（影子区/多代压缩条全保留），**压缩不删除
  被摘要区**，重拉历史不消失；
- 请求组装由 pi 投影裁掉影子区；上下文明细估算的转录整形
  （`convertToLlmMessages`）与预算同口径。

- 验收：压缩后折叠条原位出现、被摘要旧消息仍可滚动；重启回拉不缺内容；
  mock 请求体不含影子区消息；溢出走重试而非 run.failed（再溢出才失败）；
  忙时手动 compact 得 InvalidRequest；20K 小窗成功压缩占比过半即成
  （自适应 keep 生效）。

## 协议接口

事件 `compaction.started（reason）/ completed（summary 全文、tokensBefore、
tokensAfter?、summaryUsage?、summarizedUntil）`；method `session.compact`；
`ChatMessage.role = 'compaction'`（`compaction: { tokensBefore,
summaryUsage? }`）。四家对比见
[../技术笔记/上下文压缩.md](../技术笔记/上下文压缩.md)。
