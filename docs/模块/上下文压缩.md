# 上下文压缩

> 长会话的上下文预算管理：触发、摘要、裁剪、溢出恢复与保留式呈现。
> 落点：`src/agent-service/runtime/compaction.ts`（纯函数）+
> `session.ts`（I/O 与事件）、
> `src/renderer/src/features/home/{CompactionBar,ContextIndicator}.tsx`。

## 触发（双路）

```
submit ──► 占用 ≥ 阈值? ──否──► 正常请求
              │是（或 session.compact 手动）
              ▼
   摘要生成（真前缀，KV 复用）──► 转录切点原位插 compactionSummary
              ▼
   请求组装：convertToLlm 投影裁掉影子区（历史文件保留不删）
              ▼
   UI：completed 事件 ──► 折叠条原位中插（旧消息不消失）
```

- **阈值自动**：submit 前检查，公式
  `max(ctx×0.5, min(ctx×0.9, ctx−ROOM_FLOOR))` —— 占比与绝对余量取小再兜底
  （小窗下绝对余量先到、大窗下 90% 先到；拆掉小窗 + 推理模型时输出预算被
  饿死的死锁）；支持 ModelDef 按模型覆盖；
- **手动**：`session.compact`（忙 / 无可压缩 → InvalidRequest）。

## 摘要生成

- 结构化 checkpoint 提示词（Goal/Progress/Key Decisions/Next Steps 六节模板
  + UPDATE previous-summary 迭代 + 文件操作 XML 尾缀）；
- 摘要请求 = **主请求真前缀**（被摘要区原消息直传 + 指令内联，KV cache 复用）；
- 摘要模型 = 会话当前模型（Models.completeSimple + 内存表 key）；
- 切点只取 **user 消息边界**（回合原子）；system 消息全保留前置（权限通告
  在转录里，不能随摘要丢）；
- `compacting` 集合护栏：摘要期 pi 不置 isStreaming 的并发裸奔窗口。

## 转录表示（保留式）

- 压缩记录 = 转录内 `compactionSummary` 自定义消息角色（pi
  CustomAgentMessages 声明合并 + convertToLlm 转 user 消息，请求组装/落盘/
  历史回查零特殊分支）；
- **压缩不删除被摘要区**：只在切点原位插入压缩条；影子区（末条压缩条之前
  的历史）不再发给模型（convertToLlmMessages 投影裁剪），但历史回查/落盘/
  重启复原完整保留 —— 重拉历史不因压缩消失。

- 验收：压缩后消息流折叠条原位出现、被摘要区的旧消息仍可滚动查看；
  重启回拉历史不缺被摘要内容；mock 请求体不含影子区消息；可恢复溢出
  走重试而非 run.failed（重试再溢出才失败）；忙时手动 compact 得
  InvalidRequest。

## L1 工具结果裁剪（不摘要的轻量层）

- 全转录超限（8192 code point）的 toolResult **原位改写**（保头 4096 /
  保尾 1024 / middle 换 marker），entries 带字符量对账 → `compaction.pruned`
  事件 → UI「已裁剪 N 处工具输出」副行（PrunedBar，与 completed 配对重插）；
- L1 单独够时不发 compaction.started（零摘要请求）。

## 溢出恢复

- provider 溢出（context overflow）不再直接 run.failed：删失败轮 + 压缩 +
  continue 重试一次，**单次闸**（重试再溢出才发 run.failed）；streaming
  保活单 run 语义。

## 指示器联动

- 90% 预警线 + 越线说明；**回落**：压缩条新于末条 usage → 分子切 tokensAfter
  估算带 ≈，下答切回实报。

## 协议接口

事件 `compaction.started（reason: threshold|manual）/ completed（summary 全文、
前后 token、summarizedUntil 锚）/ pruned`；method `session.compact`；
`ChatMessage.role = 'compaction'`。调研与决策依据见
[../计划/方案-上下文压缩.md](../计划/方案-上下文压缩.md)。
